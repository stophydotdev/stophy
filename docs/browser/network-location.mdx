Choose a country if a site should see a local visitor. Use your own proxy if you need to route the session through it, or go direct to use no proxy. You can change the network without losing tabs or logins.

## Choose a country

Set the country before you open a page that changes by location. Get an API key in the [Quickstart](/quickstart). Send `location.country`, a two-letter code such as `DE` or `JP`. Sites see a visitor from that country. With no choice, the country is the United States.

<CodeGroup>

```bash cURL
curl -X POST https://api.stophy.dev/v1/browser \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "ttl": 300,
    "activityTtl": 60,
    "location": { "country": "DE" }
  }'
```

A country only works with the default network. A session that sends `location.country` with `proxy` set to `direct` or to your own proxy returns `400 invalidRequest`.

## Read where a session appears

Use `GET /v1/browser/{session_id}/proxy` to check how a running session reaches the web. It is free.

```json
{
  "success": true,
  "mode": "managed",
  "country": "de",
  "exitIp": "203.0.113.37"
}
```

`exitIp` is the address sites see, shown here as an example address. Loading `https://api.country.is` in that session answered with the same address and `"country":"DE"`.

| `mode` | What it means | `country` | `exitIp` |
| - | - | - | - |
| `managed` | The default: a country you pick, or the United States | The country, lower case | The address sites see |
| `direct` | No proxy | `null` | The address sites see |
| `custom` | Your own proxy | `null` | `null` |

When the address cannot be read, `exitIp` is `null` and `exitIpError` says so. Send the request again.

## Change it while the session runs

`PATCH /v1/browser/{session_id}/proxy` changes the network of a running session. Open tabs and logins stay. Connections open now end, and new ones use the new network. Send one of these bodies:

| Body | You get |
| - | - |
| `{ "mode": "managed", "country": "JP" }` | A visitor from that country |
| `{ "rotate": true }` | A new address in the current country |
| `{ "mode": "direct" }` | No proxy |
| `{ "mode": "custom", "customProxy": { "host": "proxy.example.net", "port": 8080 } }` | Your own proxy |

After you change the country, read `country` and `exitIp` to check the new route. Rotating keeps the country and changes the IP. Direct returns `country: null`. A body with nothing to change answers as `GET` does.

## Use your own proxy

Send your proxy's address as `proxy` when you open the session. It must be an `http`, `https`, `socks5` or `socks5h` URL on a public host.

To use your proxy in a running session, set `"mode": "custom"` and send `customProxy` with its connection details.

`host` and `port` are required. `protocol` is `http`, `https`, `socks5` or `socks5h`. A host that is not public, such as `localhost`, returns `400 invalidRequest` with `customProxy: host must be a public address.`

## Options

Set the route when you open the session, or send a change to the running session.

| Field | Where | Type | Default | Effect |
| - | - | - | - | - |
| `location.country` | open | `string` | `US` | Two-letter country code. Only with the default network. |
| `proxy` | open | `string` | `residential` | `residential` is the default network, where `location.country` applies. `direct` uses no proxy. A URL uses your own proxy. |
| `mode` | change | string | none | `managed`, `direct` or `custom`. |
| `country` | change | `string` | none | With `managed`: the country to appear in, such as `DE`. |
| `rotate` | change | `boolean` | none | `true` gets a new address in the current country. |
| `customProxy` | change | `object` | none | With `custom`: `host`, `port`, and optional `username`, `password` and `protocol`. |

A profile keeps the country it first used. See [Profiles](/browser/profiles).

## Price

Compare traffic rates before you pick a network. We bill traffic when the session closes, using the rate for the network that carried it.

| Network | Traffic |
| - | - |
| A country, the default | $5 per GB |
| No proxy | $0.20 per GB |
| Your own proxy | $0.20 per GB |

Traffic before and after a change is billed at the rate of its own network. The closing answer's `exitBytes` splits the bytes: `managed` for the default network, `direct` and `custom`. This real session spent 38,137 bytes in Japan and 13,328 bytes with no proxy, and its traffic and time cost $0.006 together.

The network choice does not change the hourly browser price. It is $0.06 without a prompt and $0.84 once you run a prompt. See [Browser sessions](/browser/overview#price).

## Limits and errors

If a network change fails, check the route, country and whether the session is still running.

- `location.country` with `proxy` of `direct` or your own URL returns `400 invalidRequest`: `location.country picks a residential exit. Leave it out with your own proxy or direct.`
- A country that is not two letters returns `400 invalidRequest`: `location.country: Expected a two-letter country code such as DE`.
- A `proxy` that is not `residential`, `direct` or a public URL returns `400 invalidRequest`: `proxy: Expected residential, direct, or your own proxy as an http://, https:// or socks5:// URL on a public host`.
- Reading or changing a session that is not running returns `409 invalidRequest` with `This browser session is not running.`
