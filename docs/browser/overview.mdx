Open a session when you need the same page, tabs or login across calls. For one page read without clicks, use [Scrape](/scrape/overview). You pay for open time, so close every session. See [Pricing](/account/pricing). Sessions need a key.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/browser \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl": 300, "activityTtl": 60}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/browser", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ ttl: 300, activityTtl: 60 }),
});
const session = await response.json();
console.log(session.id, session.cdpUrl);
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/browser",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={"ttl": 300, "activityTtl": 60},
)
session = response.json()
print(session["id"], session["cdpUrl"])
```
</CodeGroup>

Keep `id`: every other call on the session uses it. Opening is free.

| Field | Meaning |
| - | - |
| `cdpUrl` | Where Playwright or Puppeteer connects. It carries a token, so keep it private. |
| `liveViewUrl`, `interactiveLiveViewUrl` | Watch the session, or watch and control it. Left out with `streamWebView: false`. |
| `timeoutAt` | When the session closes by itself if nothing happens |
| `expiresAt` | `ttl` after it opened |

To recover a running session after a dropped answer, send the same `Idempotency-Key` header, key and body: it works for 24 hours after the session opens, and a different body or an ended session returns `409`. If you get `503` with `Retry-After`, retry with the same key.

## Drive it

* Over CDP: `chromium.connectOverCDP(cdpUrl)` in Playwright, or `puppeteer.connect({ browserWSEndpoint: cdpUrl })`. Use the page that is already open. CDP activity counts as a call for `activityTtl`. Disconnecting does not close the session.
* Over HTTP: [run code or a prompt](/browser/execute) in it.

## Lifetime

| Field | Default | Meaning |
| - | - | - |
| `ttl` | `600` | Most seconds the session can live, 30 to 21,600 |
| `activityTtl` | `300` | Seconds with no call before it closes, 10 to 21,600. Each call moves `timeoutAt` forward. |

The session closes at the earlier of `expiresAt` and the idle limit. It bills for the time it was open either way.

## Close, read and list

`DELETE /v1/browser/{session_id}` closes the session and bills it. Closing an already closed session returns the same bill and charges nothing more. The answer has:

* `sessionDurationMs`, and `proxyBytes` split by network in `exitBytes`. See [Network](/browser/network-location).
* `costUsd`, the bill. `creditsBilled` and `creditsUsed` are older fields for the same amount.
* `recordingStatus`, if you asked for a recording.

`GET /v1/browser/{session_id}` is free. A running session lists its `downloads` and `uploads`. A closed one has `status: "destroyed"`, `finishedAt`, and `browserCostUsd`, `proxyCostUsd` and `proxyUsedMb` to tell time from traffic.

`GET /v1/browser` is free and lists sessions, newest first. Run `?status=active` before you stop work to confirm none is open.

| Query | Default | Meaning |
| - | - | - |
| `status` | all | `active` or `destroyed` |
| `metadata` | none | `key` matches any value, `key=value` one. Send it again to narrow. |
| `limit` | `50` | Sessions per page, 1 to 100 |
| `cursor` | none | `nextCursor` from the last page. `hasMore` is `true` while there is one. |

## Options

All fields in the body of `POST /v1/browser` are optional.

| Field | Meaning |
| - | - |
| `ttl`, `activityTtl` | See [Lifetime](#lifetime) |
| `profile` | Cookies and logins saved under a name. See [Profiles](/browser/profiles). |
| `extensionIds` | Up to 3 uploaded extensions. See [Profiles and extensions](/browser/profiles#extensions). |
| `networkPolicyId`, `allowedDomains` | Allow or block domains. See [Network](/browser/network-location#network-policies). |
| `proxy`, `location` | Country, your own proxy, or none. See [Network](/browser/network-location). |
| `recording` | `true` records every tab as an MP4. See [Recordings and replay](#recordings-and-replay). |
| `metadata` | Up to 10 text pairs, keys up to 100 characters, values up to 1,000. They come back with the session and filter the list. |
| `screen` | Window `width` 500 to 6,144 and `height` 320 to 3,456 pixels. Sites still see a 1920x1080 display. |
| `allowResizing` | `false` keeps the window size: resize commands are accepted and change nothing |
| `pdfRenderer` | `true` shows PDFs in the browser viewer. Otherwise a PDF is saved as a download. |
| `solveCaptchas` | Captchas are solved for you. `false` leaves them for you or your user in the live view. |
| `captureConsole` | `true` keeps console messages and page errors for the `console` step of `browserRun` in [Install MCP](/install-mcp#drive-a-browser). Off by default, because a few sites behave differently with it on. |
| `blockAds` | `false` loads ads and trackers |
| `streamWebView` | `false` leaves out the live view links |
| `zeroDataRetention` | Keep nothing, so no replay. Not with `profile` or `recording`. See [Zero data retention](/production/zero-data-retention). |

## Recordings and replay

Both are free. A recording is a video of every tab. A replay lists the pages the session visited and the steps run on each, kept 24 hours after the session closes, and needs no `recording`.

Open the session with `"recording": true`. The answer has `recordingStatus: "recording"`. The video is made after the session closes.

| `recordingStatus` | Meaning |
| - | - |
| `none` | Not recorded, or the video was deleted |
| `recording` | The session is running |
| `processing` | The video is being made, usually within a few minutes |
| `ready` | `recordingUrl` works |
| `failed` | The video was never made and cannot be |

* `GET /v1/browser/{session_id}/recording` returns the status and, when `ready`, `recordingUrl`: an MP4, no key needed, for 15 minutes. Read it again for a new link. It is kept 7 days. `recordingTruncated: true` means the video ends early.
* `DELETE /v1/browser/{session_id}/recording` removes the video at once. The replay stays.
* `GET /v1/browser/{session_id}/replay` returns `pages`, each with `pageId`, `url`, `title`, `at` (milliseconds since 1970) and `steps` (the calls your code made). `GET /v1/browser/{session_id}/replay/{page_id}` adds `screenshot`, a Base64 JPEG. `maxTextLength` cuts text values.

## Errors

* Over the open-session limit: `429 rateLimited` saying how many are open. See [Rate limits](/production/rate-limits).
* A balance too low to cover `ttl`: `402 insufficientCredits`, and no session opens.
* A session that has ended: `410 notFound` `This browser session has ended.` Calls that need a running session, such as listing downloads, return `409 invalidRequest`. An unknown ID: `404 notFound`.
* `allowedDomains` with `networkPolicyId`, `profile` with `zeroDataRetention`, and `recording` with `zeroDataRetention` each return `400 invalidRequest` naming the two fields.
* Deleting a video still being made: `409 invalidRequest`. Wait for `ready` or `failed`. With no video: `404 notFound`.
* A replay page ID that does not exist: `404 notFound`.
