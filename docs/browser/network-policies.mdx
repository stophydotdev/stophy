Use a network policy when several browser sessions should follow the same domain rules. A session opened with a policy can reach only what the policy allows. Edit the policy and every running session that uses it follows within seconds. Policies cost nothing.

## Create a policy

Use an allowlist if the browser should reach only the sites you name. Get an API key in the [Quickstart](/quickstart). Name the policy, then list domains. This one is an allowlist: it blocks everything except `example.com` and `bun.com`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/browser/network-policies \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "docs-only",
    "defaultAction": "block",
    "allow": { "domains": ["example.com", "bun.com"] }
  }'
```
```typescript TypeScript
const response = await fetch(
  "https://api.stophy.dev/v1/browser/network-policies",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      name: "docs-only",
      defaultAction: "block",
      allow: { domains: ["example.com", "bun.com"] },
    }),
  },
);
const policy = await response.json();
console.log(policy.id, policy.version);
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/browser/network-policies",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},

        "name": "docs-only",
        "defaultAction": "block",
        "allow": {"domains": ["example.com", "bun.com"]},
    },
)
policy = response.json()
print(policy["id"], policy["version"])
```

To block a few sites and allow the rest, leave `defaultAction` out, which means `allow`, and list the sites in `block.domains`. A domain such as `example.com` covers itself and every subdomain. When two entries match, the most specific wins. Domains are trimmed, lower-cased and de-duplicated, and a leading `*.` is dropped.

## Apply it to a session

Attach a saved policy when you open the session. Set `networkPolicyId` to the policy's `id`. The session returns that ID and `networkPolicyVersion`, the version it enforces.

To test it, visit an allowed and a blocked site with [Execute](/browser/execute). With the allowlist above, `example.com` opens and `example.org` fails to connect. The policy checks every request, not just the page's address.

For a short list that belongs to one session, set `"allowedDomains": ["example.com"]` instead. You can send up to 100 domains. Do not send it with `networkPolicyId`.

## Change a running session

`PATCH /v1/browser/network-policies/{policy_id}` changes the policy and every running session that uses it. Each field you send replaces the old one, and a list replaces the whole list. To add `example.org`, send `"allow": { "domains": ["example.com", "bun.com", "example.org"] }`. Include the original domains if you still want to allow them.

The response gives the new `version`, `updatedAt`, and counts in `runningSessions` and `appliedSessions`. Read `pendingSessionIds` for any session we could not reach. We retry every few seconds; a session whose `networkPolicyVersion` has not caught up still uses the previous policy. If a change blocks a host, we close its open connections. `closedConnections` counts them.

## Manage policies

List policies to find an ID, or read one to check its current version.

| Action | Call | Notes |
| - | - | - |
| Create | `POST /v1/browser/network-policies` | Free. |
| List | `GET /v1/browser/network-policies` | Newest first. `pageSize` 1 to 100, default 10. `pageNumber` from 1. |
| Read | `GET /v1/browser/network-policies/{policy_id}` | One policy. |
| Change | `PATCH /v1/browser/network-policies/{policy_id}` | Raises `version` by 1. |
| Delete | `DELETE /v1/browser/network-policies/{policy_id}` | Only when no running session uses it. |

## Options

Choose what happens to domains that do not match either list.

| Field | Type | Default | Effect |
| - | - | - | - |
| `name` | `string` | none | 1 to 100 characters. Required to create. |
| `defaultAction` | `string` | `allow` | What happens to a domain no entry matches: `allow` or `block`. Send `block` with `allow.domains` for an allowlist. |
| `allow.domains` | `array of string` | none | Domains the session may reach. |
| `block.domains` | `array of string` | none | Domains the session may not reach. |

## Limits and errors

Send domain names, not URLs, and close any session using a policy before deleting it.

- A policy holds at most 10,000 domains in `allow` and `block` together, and an account at most 100 policies.
- A URL, a path, a port, an IP address, another wildcard, or a domain in both lists returns `400 invalidRequest`. A real answer for a URL: `allow.domains.0: "https://example.com/page": Expected a domain such as example.com. It covers its subdomains too. A leading *. is allowed. URLs, paths, ports, IP addresses and other wildcards are not.`
- Deleting a policy that a running session uses returns `409 invalidRequest`: `1 running browser session uses this policy. Close it or wait for it to end, then delete the policy.`
- An unknown policy id returns `404 notFound`.
