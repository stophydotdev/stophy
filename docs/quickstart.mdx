Send a search with no key and get Google results as JSON. Then add a key to use all 137 endpoints.

## Try it with no key

```bash
curl -X POST https://api.stophy.dev/v1/google/search \
  -H "content-type: application/json" \
  -d '{"query":"postgres jsonb index"}'
```

<Accordion title="Response">
```json
{
  "success": true,
  "data": {
    "results": [
      {
        "type": "web",
        "url": "https://www.postgresql.org/docs/9.6/functions-json.html",
        "title": "PostgreSQL: Documentation: 9.6: JSON Functions and Operators",
        "description": "August 12, 2021 - Some further operators also exist only for jsonb, as shown in Table 9-43. Many of these operators can be indexed by jsonb operator classes.",
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 0,
  "requestId": "e4395adf-cdd4-4bd3-97cb-329e60df032c"
}
```
</Accordion>

`data.results` is page 1 of Google results, and `creditsUsed: 0` means it cost nothing. The endpoints marked `keyless: true` in the [endpoint catalog](https://api.stophy.dev/v1/endpoints) work this way, for the first page only. Past 10 calls a minute or 50 a day, you get `429` with code `freeLimit` and a `signupUrl`.

## Get a key

Sign up at [stophy.dev/signup](https://stophy.dev/signup). New accounts start with $1.50 free, enough for 1,000 calls. Create a key and save it as `STOPHY_API_KEY`.

To use the CLI, install it. It reads `STOPHY_API_KEY`, or you can run `stophy login`.

```bash
curl -fsSL https://stophy.dev/install | bash
```

The response has the same shape and costs $0.0015. Send `page: 2` for the next page.

Every endpoint is a `POST` to `https://api.stophy.dev/v1/` and its id with dots as slashes. `youtube.transcript` is `/v1/youtube/transcript`.
