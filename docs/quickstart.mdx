Get a key, install a client and run your first search. To have your coding agent do it, use the [Agent quickstart](/agent-quickstart).

## 1. Get an API key

Sign up at [stophy.dev/signup](https://stophy.dev/signup), create a key and set it in your server's environment. [Get credentials](/get-credentials) has every way to get one, including from an agent.

```bash
export STOPHY_API_KEY="<your key>"
```

## 2. Install a client

<CodeGroup>
```bash TypeScript
npm install stophy
```
```bash Python
pip install stophy
```
</CodeGroup>

Both [SDKs](/sdks) read `STOPHY_API_KEY`. cURL needs nothing.

## 3. Search the web

This request returns the top three web results for `bun runtime`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "query": "bun runtime", "limit": 3 }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();
const { data } = await stophy.search({ query: "bun runtime", limit: 3 });
console.log(data?.web?.map((result) => result.url));
```
```python Python
from stophy import Stophy

stophy = Stophy()
body = stophy.search(query="bun runtime", limit=3)
print([result["url"] for result in body["data"]["web"]])
```
</CodeGroup>

`data.web` holds the ranked results, each with `url`, `title`, `description` and `position`. Empty fields are left out. The `x-cost-usd` header is what the call cost.

```json
{
  "success": true,
  "data": {
    "web": [
      { "url": "https://en.wikipedia.org/wiki/Bun_(software)", "title": "Bun (software) - Wikipedia", "position": 1 },
      { "url": "https://github.com/oven-sh/bun", "position": 2, "category": "github" }
    ]
  }
}
```

A failed call returns `success: false`, an `error` that says what to do next and a `code`, and costs nothing. See [Errors](/api-reference/errors).
