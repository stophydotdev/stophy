Make a first request and read the result. To have a coding agent set everything up, use the [Agent quickstart](/agent-quickstart).

## 1. Get an API key

Sign up at [stophy.dev/signup](https://stophy.dev/signup) with GitHub or Google. Create a key and set it as `STOPHY_API_KEY` in your server's environment. Never commit it or put it in browser code. See [API keys](/account/api-keys) and [Pricing](/account/pricing).

Search, scrape, map and parse also work with no key, within the [free limits](/production/rate-limits). Leave out the `Authorization` header.

## 2. Install a client

cURL needs nothing. For TypeScript run `npm install stophy`. For Python run `pip install stophy`. Both [SDKs](/sdks) read `STOPHY_API_KEY`.

## 3. Search

This request returns three web results for `bun runtime`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "query": "bun runtime", "sources": ["web"], "limit": 3 }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();
const { data } = await stophy.search({ query: "bun runtime", sources: ["web"], limit: 3 });
console.log(data?.web?.map((result) => result.url));
```
```python Python
from stophy import Stophy

stophy = Stophy()
body = stophy.search(query="bun runtime", sources=["web"], limit=3)
print([result["url"] for result in body["data"]["web"]])
```
</CodeGroup>

`data.web` holds the ranked results, each with a `url`, `title`, `description` and `position`. Empty fields are left out. The `x-cost-usd` header is what the call cost.

```json
{
  "success": true,
  "data": {
    "web": [
      { "url": "https://bun.sh/", "title": "Bun — A fast all-in-one JavaScript runtime", "position": 1 }
    ]
  }
}
```

A failed call returns `success: false`, an `error` that says what to do and a `code`, and costs nothing. See [Errors](/api-reference/errors).
