## Call it with no key

```bash
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Content-Type: application/json" \
  -d '{"url":"https://bun.com/docs/runtime/bunfig"}'
```

## Get a key

Sign up at [stophy.dev/signup](https://stophy.dev/signup). Your account starts with 5,000 free credits, and most calls cost 1 credit. Create a key and save it as `STOPHY_API_KEY`.

An agent can get a key with no human at the keyboard: [Sign up](/api-reference/endpoint/sign-up) returns a link for its person to approve.

## Call it with your key

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"nvidia earnings","sources":["web","news"],"limit":5}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/search", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    query: "nvidia earnings",
    sources: ["web", "news"],
    limit: 5,
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/search",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "query": "nvidia earnings",
        "sources": ["web", "news"],
        "limit": 5,
    },
)
print(response.json())
```

## Read a site as JSON

To get a site's own data, send its page to scrape with a parser:

```bash
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.reddit.com/search/?q=web+scraping&sort=top&t=year","formats":[{"type":"json","parser":"reddit-search"}]}'
```

The posts come back in `data.json`. See [Parsers](/guides/parsers).
