## Call it with no key

```bash
curl -X POST https://api.stophy.dev/v1/google/search \
  -H "content-type: application/json" \
  -d '{"query":"typescript release notes"}'
```

<Accordion title="Response">
```json
{
  "success": true,
  "data": {
    "results": [
      {
        "type": "web",
        "url": "https://www.typescriptlang.org/docs/handbook/release-notes/typescript-6-0.html",
        "title": "TypeScript: Documentation - TypeScript 6.0",
        "description": "6 days ago - While TypeScript 6.0 maintains full compatibility with your existing TypeScript knowledge and continues to be API compatible with TypeScript 5.9, this release introduces a number of breaking changes and deprecations.",
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 0,
  "requestId": "e9eadb92-1a19-4127-b5e0-217da75f4b37"
}
```
</Accordion>

That is page 1 of Google results, and it cost nothing. 27 endpoints answer like this with no key. [Rate limits](/rate-limits) has the free limits.

## Get a key

Sign up at [stophy.dev/signup](https://stophy.dev/signup) and your account starts with $1.50. Create a key and save it as `STOPHY_API_KEY`.
