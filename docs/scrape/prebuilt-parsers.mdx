A parser reads one kind of page on one site and returns its data as JSON. Name it in a `json` format of [scrape](/api-reference/endpoint/scrape). The URL must be the kind of page the parser reads, or the call fails with `invalidRequest`. 114 parsers exist. 17 work without an API key when you send no options.

## Options

Send options in the `options` object of the format, like `{"type": "json", "parser": "youtube-transcript", "options": {"language": "en"}}`. A parser that reads more than one kind of page takes `view`.

| Option | Meaning |
| --- | --- |
| `country` | ISO 3166-1 alpha-2 country code, e.g. us. Any case is accepted. |
| `language` | BCP 47 language tag, e.g. en or pt-BR. Any case is accepted. |
| `page` | Page number, starting at 1. |
| `cursor` | The cursor from the previous response. Send it as is. |
| `currency` | ISO 4217 currency code, e.g. USD. |
| `limit` | Return at most this many apps. You pay $0.001 for each 10 returned. |

## Read the list from code

`GET /v1/parsers` is free and needs no API key. Each entry has `takes`, `example`, `options`, `returns`, `price`, `keyless` and a sample `response`. It is the only place that lists each parser's price. See [Pricing](/account/pricing) for the rest.

```bash
curl -s https://api.stophy.dev/v1/parsers \
  | jq -r '.data.parsers[] | select(.name | startswith("youtube")) | "\(.name): \(.takes)"'
```
