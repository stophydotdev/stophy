A parser reads one kind of page on one site and returns the site's own data as JSON. A Reddit search page comes back as posts, a YouTube video link as its transcript, a Google Maps search as places. There are 114 parsers.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names one parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.youtube.com/watch?v=dQw4w9WgXcQ","formats":[{"type":"json","parser":"youtube-transcript"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "youtube-transcript",
  "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "youtube-transcript",
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
)
print(result)
```
</CodeGroup>

## Options

Each parser has its own options. Send them in the `options` object of the format, like `{"type": "json", "parser": "youtube-transcript", "options": {"language": "en"}}`. A parser's page lists the options it takes. Some parsers read more than one kind of page and list each as a view. Set `options.view` to pick one where the page says so. To read the next page of results, send the `cursor` from the response as the `cursor` option.

## Price

See [Rate limits](/production/rate-limits). Paging and other options need an API key. See [Pricing](/account/pricing).

## Read the list from code

`GET /v1/parsers` returns every parser. It is free and needs no API key.

```bash
curl -s https://api.stophy.dev/v1/parsers \
  | jq -r '.data.parsers[] | select(.name | startswith("youtube")) | "\(.name): \(.takes)"'
```

Each entry has `takes` (the page it reads), an `example` URL, its `options`, the fields it `returns`, its `price`, `keyless: true` when it works without an API key, and a sample `response`. See [List parsers](/api-reference/endpoint/list-parsers).
