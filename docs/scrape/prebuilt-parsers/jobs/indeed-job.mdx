Reads an Indeed job page with a jk key, like indeed.com/viewjob?jk=17c2d37519bd8374, and returns one job as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.indeed.com/viewjob?jk=17c2d37519bd8374","formats":[{"type":"json","parser":"indeed-job"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "indeed-job",
  "https://www.indeed.com/viewjob?jk=17c2d37519bd8374",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "indeed-job",
    "https://www.indeed.com/viewjob?jk=17c2d37519bd8374",
)
print(result)
```
</CodeGroup>

## Read the response

The parser's data is in `data.json`. Its fields include `id`, `url`, `title`, `company`, `location`, `isRemote`, `salary`, `employmentType`, `publishedAt` and `description`. This sample is cut to the first items.

```json
{
  "success": true,
  "data": {
    "json": null
  }
}
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `country` | ISO 3166-1 alpha-2 country code, e.g. us. Any case is accepted. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an Indeed job page with a jk key, like indeed.com/viewjob?jk=17c2d37519bd8374. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
