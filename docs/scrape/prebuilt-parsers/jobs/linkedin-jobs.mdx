Reads a LinkedIn jobs search page with keywords, a location or a company filter, and returns a list of jobs as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.linkedin.com/jobs/search?keywords=software%20engineer&location=United%20States&f_TPR=r604800","formats":[{"type":"json","parser":"linkedin-jobs"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "linkedin-jobs",
  "https://www.linkedin.com/jobs/search?keywords=software%20engineer&location=United%20States&f_TPR=r604800",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "linkedin-jobs",
    "https://www.linkedin.com/jobs/search?keywords=software%20engineer&location=United%20States&f_TPR=r604800",

print(result)
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `company` | One company or up to five: LinkedIn URLs, slugs like google, or company ids. |
| `easyApply` | LinkedIn's own Easy Apply. |
| `fewApplicants` | LinkedIn's own Under 10 applicants. |
| `page` | Page number, starting at 1. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a LinkedIn jobs search page with keywords, a location or a company filter. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
