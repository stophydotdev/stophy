Reads a company job board on Greenhouse, Lever, Ashby, Workday, Workable or SmartRecruiters, like boards.greenhouse.io/figma, and returns a list of jobs as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://boards.greenhouse.io/figma","formats":[{"type":"json","parser":"careers-jobs"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed("careers-jobs", "https://boards.greenhouse.io/figma");
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed("careers-jobs", "https://boards.greenhouse.io/figma")
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `cursor` | The cursor from the previous response. Send it as is. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a company job board on Greenhouse, Lever, Ashby, Workday, Workable or SmartRecruiters, like boards.greenhouse.io/figma. Any other URL fails with `invalidRequest`.
- To read the next page, send the `cursor` from the response as the `cursor` option. Paging needs an API key.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
