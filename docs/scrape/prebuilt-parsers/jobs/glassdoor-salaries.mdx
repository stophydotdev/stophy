Reads a Glassdoor company page (overview, reviews or salaries), and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.glassdoor.com/Overview/Working-at-Google-EI_IE9079.11,17.htm","formats":[{"type":"json","parser":"glassdoor-salaries"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "glassdoor-salaries",
  "https://www.glassdoor.com/Overview/Working-at-Google-EI_IE9079.11,17.htm",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "glassdoor-salaries",
    "https://www.glassdoor.com/Overview/Working-at-Google-EI_IE9079.11,17.htm",

print(result)
```

## Read the response

The parser's data is in `data.json`. Its fields include `jobTitle`, `reports`, `totalPayMin`, `totalPayMedian`, `totalPayMax` and `basePayMin`. This sample is cut to the first items.

```json
{
  "success": true,
  "data": {
    "json": {
      "companyId": "9079",
      "country": "United States",
      "total": 9423,
      "results": [

          "jobTitle": "Software Engineer",
          "reports": 51622,
          "totalPayMin": 242067,

          "basePayMedian": 176776,
          "basePayMax": 196719,
          "payCurrency": "USD",
          "payPeriod": "year"
        }
      ],
      "page": 1
    }
  }
}
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `country` | Country the pay is reported for, as its English name like India or Germany. Defaults to the United States. |
| `page` | Page number, starting at 1. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Glassdoor company page (overview, reviews or salaries). Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
