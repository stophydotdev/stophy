Reads an Indeed job search page with a search q or a place l, like indeed.com/jobs?q=nurse&l=Austin,+TX, and returns a list of jobs as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.indeed.com/jobs?q=software+engineer&l=Austin%2C+TX","formats":[{"type":"json","parser":"indeed-search"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.indeed.com/jobs?q=software+engineer&l=Austin%2C+TX",
    formats: [{ type: "json", parser: "indeed-search" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://www.indeed.com/jobs?q=software+engineer&l=Austin%2C+TX",
        "formats": [{"type": "json", "parser": "indeed-search"}],
    },

print(response.json())
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `country` | ISO 3166-1 alpha-2 country code, e.g. us. Any case is accepted. |
| `distanceMiles` | Indeed's own Distance from the location. 0 is the exact location only. |
| `datePosted` | Indeed's own Date posted. A relisted job keeps its first publishedAt and shows the new date in indexedAt. |
| `remote` | Indeed's own Remote filter: Remote, or Hybrid work. |
| `jobType` | Indeed's own Job type. |
| `experienceLevel` | Indeed's own Experience level. |
| `education` | Indeed's own Education. |
| `sort` | Indeed's own Sort by. |
| `cursor` | The cursor from the previous response. Send it as is. |

## Limits and errors

- The URL must be an Indeed job search page with a search q or a place l, like indeed.com/jobs?q=nurse&l=Austin,+TX. Any other URL fails with `invalidRequest`.
- To read the next page, send the `cursor` from the response as the `cursor` option. Paging needs an API key.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
