Reads an Upwork job page, like upwork.com/jobs/~02.., and returns one job as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://upwork.com/freelance-jobs/apply/React-Developer-Needed-for-Long-Term-Part-Time-Remote-Work_~022099839291870230198","formats":[{"type":"json","parser":"upwork-job"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "upwork-job",
  "https://upwork.com/freelance-jobs/apply/React-Developer-Needed-for-Long-Term-Part-Time-Remote-Work_~022099839291870230198",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "upwork-job",
    "https://upwork.com/freelance-jobs/apply/React-Developer-Needed-for-Long-Term-Part-Time-Remote-Work_~022099839291870230198",
)
print(result)
```
</CodeGroup>

## Read the response

The parser's data is in `data.json`. Its fields include `id`, `url`, `title`, `company`, `location`, `isRemote`, `salary`, `employmentType`, `publishedAt` and `description`. This sample is cut to the first items.

```json
{
  "success": true,
  "data": {
    "json": null
  }
}
```

## Options

This parser takes no options.

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an Upwork job page, like upwork.com/jobs/~02... Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
