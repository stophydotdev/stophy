Reads a Google Play apps search page with the search in q and returns a list of products as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://play.google.com/store/search?q=meditation&c=apps","formats":[{"type":"json","parser":"google-play-search"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "google-play-search",
  "https://play.google.com/store/search?q=meditation&c=apps",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "google-play-search",
    "https://play.google.com/store/search?q=meditation&c=apps",
)
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `country` | ISO 3166-1 alpha-2 country code, e.g. us. Any case is accepted. |
| `language` | BCP 47 language tag, e.g. en or pt-BR. Any case is accepted. |
| `limit` | Return at most this many apps. You pay $0.001 for each 10 returned. |

## Price

$0.001 per 10 apps. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Google Play apps search page with the search in q. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
