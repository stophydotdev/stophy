Reads an App Store app page, like apps.apple.com/us/app/notes/id1110145109, and returns a list of reviews as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. This parser works without an API key when you send no options, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits). To lift the limits, get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://apps.apple.com/us/app/notes/id1110145109","formats":[{"type":"json","parser":"appstore-reviews"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "appstore-reviews",
  "https://apps.apple.com/us/app/notes/id1110145109",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "appstore-reviews",
    "https://apps.apple.com/us/app/notes/id1110145109",
)
print(result)
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `country` | ISO 3166-1 alpha-2 country code, e.g. us. Any case is accepted. |
| `page` | Page number, starting at 1. |

It also takes `sort`.

## Price

$1 per 1,000 calls. Works without an API key, within the free limits. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an App Store app page, like apps.apple.com/us/app/notes/id1110145109. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
