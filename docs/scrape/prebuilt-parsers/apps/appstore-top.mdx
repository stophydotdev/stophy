Reads an App Store top charts page, like apps.apple.com/us/iphone/charts, and returns a list of products as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://apps.apple.com/us/iphone/charts/6002?chart=top-paid","formats":[{"type":"json","parser":"appstore-top"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://apps.apple.com/us/iphone/charts/6002?chart=top-paid",
    formats: [{ type: "json", parser: "appstore-top" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://apps.apple.com/us/iphone/charts/6002?chart=top-paid",
        "formats": [{"type": "json", "parser": "appstore-top"}],
    },
)
print(response.json())
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `limit` | Return at most this many apps. You pay $0.001 for each 10 returned. |

## Price

$0.001 per 10 apps. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an App Store top charts page, like apps.apple.com/us/iphone/charts. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
