Reads an App Store search page, like apps.apple.com/us/iphone/search?term=notes, and returns a list of products as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://apps.apple.com/us/iphone/search?term=notes","formats":[{"type":"json","parser":"appstore-search"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "appstore-search",
  "https://apps.apple.com/us/iphone/search?term=notes",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "appstore-search",
    "https://apps.apple.com/us/iphone/search?term=notes",
)
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `limit` | Return at most this many apps. You pay $0.001 for each 10 returned. |

## Price

$0.001 per 10 apps. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an App Store search page, like apps.apple.com/us/iphone/search?term=notes. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
