### `amazon-search`

An Amazon search page with a search word or a department, like amazon.com/s?k=laptop. Example: `https://www.amazon.com/s?k=laptop&low-price=300&high-price=900&s=review-rank`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `category`
- `minRating`
- `brand`
- `page`

### `amazon-product`

An Amazon product page, like amazon.com/dp/`<ASIN>`. Example: `https://www.amazon.com/dp/B0CX23V2ZK`

Returns `id`, `url`, `title`, `brand`, `description`, `price`, `originalPrice`, `rating`, `reviewCount`, `availability`, `images`, `categories`, `seller`.

Options:
- `country`

### `amazon-reviews`

An Amazon product page. Marketplaces outside the US, like amazon.in/dp/`<ASIN>`, show their top reviews without sign-in, up to 13 for the product page. Amazon US shows reviews only after sign-in, so an amazon.com page returns reviews for few products. Example: `https://www.amazon.in/dp/B0CHX1W1XY`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `country`

### `amazon-bestsellers`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `page`

### `tiktok-shop`

A TikTok Shop search page (/k/), store page (/store/) or product page (/pdp/). Set options.view to reviews on a product page for its reviews. Example: `https://shop.tiktok.com/us/k/gummies`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `view`: `reviews`.
- `cursor`

### `ebay-search`

An ebay.com search page, like ebay.com/sch/i.html?_nkw=iphone. Example: `https://www.ebay.com/sch/i.html?_nkw=iphone+15&_udlo=300&_udhi=800&_sop=15`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `condition`
- `auctionsOnly`: Only auctions. With sort endingSoonest this lists auctions about to end; ebay.item then returns what each one sold for.
- `page`

### `ebay-item`

An eBay item page, like ebay.com/itm/`<item id>`. Example: `https://www.ebay.com/itm/266625967665`

Returns `id`, `url`, `title`, `brand`, `description`, `price`, `originalPrice`, `rating`, `reviewCount`, `availability`, `images`, `categories`, `seller`.

### `facebook-marketplace`

A Facebook Marketplace search page with a city and a query, like facebook.com/marketplace/austin/search?query=bike. Example: `https://www.facebook.com/marketplace/austin/search?query=bike`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `minPrice`: Lowest price in local currency (e.g., 50).
- `maxPrice`: Highest price in local currency (e.g., 500).
- `sort`: Sort order (newest, priceLow or priceHigh), relevance by default.

### `craigslist-search`

A Craigslist search page with a five-digit US ZIP code in postal, like sfbay.craigslist.org/search/sss?query=bike&postal=94103. Example: `https://sfbay.craigslist.org/search/sss?query=bike&postal=94103&search_distance=25`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `minPrice`: Lowest price in US dollars (e.g., 50).
- `maxPrice`: Highest price in US dollars (e.g., 500).
- `limit`: Return at most this many listings. You pay $0.001 for each 10 returned.

### `trustpilot-search`

A Trustpilot search page, like trustpilot.com/search?query=stripe. Example: `https://www.trustpilot.com/search?query=payments`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `page`: Page number, starting at 1. Trustpilot shows 10 pages of 10 companies without an account, so one search reaches at most 100 companies even when total is larger. Make the query more specific to reach the rest.

### `trustpilot-company`

A Trustpilot company page, like trustpilot.com/review/stripe.com. Example: `https://www.trustpilot.com/review/stripe.com`

Returns `id`, `url`, `title`, `brand`, `description`, `price`, `originalPrice`, `rating`, `reviewCount`, `availability`, `images`, `categories`, `seller`.

### `trustpilot-reviews`

A Trustpilot company page, like trustpilot.com/review/stripe.com. Example: `https://www.trustpilot.com/review/stripe.com?stars=1&stars=2&languages=en`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `datePublished`: Only reviews published in the last 30 days, 3, 6 or 12 months.
- `verifiedOnly`: Only reviews Trustpilot marks as verified.
- `search`: Only reviews that mention this word or phrase.
- `page`: Page number, starting at 1. Trustpilot shows 10 pages of 20 reviews without an account; narrow with ratings, language, datePublished or search to reach older reviews.

### `craigslist-listing`

One Craigslist post, like craigslist.org/view/d/hermosa-beach-thule-kayak-carrier-new/2uYpYvcvf6gMZMAkgfgSPg. Example: `https://www.craigslist.org/view/d/hermosa-beach-thule-kayak-carrier-new/2uYpYvcvf6gMZMAkgfgSPg`

Returns `id`, `url`, `title`, `description`, `price`, `pricePeriod`, `status`, `address`, `location`, `bedrooms`, `bathrooms`, `area`, `propertyType`, `rating`, `reviewCount`, `images`, `host`.
