Reads a Crunchbase organization page, like crunchbase.com/organization/stripe, and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.crunchbase.com/organization/stripe","formats":[{"type":"json","parser":"crunchbase-company"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.scrape({
  url: "https://www.crunchbase.com/organization/stripe",
  formats: [{ type: "json", parser: "crunchbase-company" }],
});
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.scrape(
    url="https://www.crunchbase.com/organization/stripe",
    formats=[{"type": "json", "parser": "crunchbase-company"}],
)
print(result)
```
</CodeGroup>

## Limits and errors

- The URL must be a Crunchbase organization page, like crunchbase.com/organization/stripe. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
