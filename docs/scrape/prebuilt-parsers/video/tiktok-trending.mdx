Reads tikTok's Explore page, with an optional region in the link, such as region=DE, for another country's feed, and returns a list of videos as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.tiktok.com/explore","formats":[{"type":"json","parser":"tiktok-trending"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.scrape({
  url: "https://www.tiktok.com/explore",
  formats: [{ type: "json", parser: "tiktok-trending" }],
});
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.scrape(
    url="https://www.tiktok.com/explore",
    formats=[{"type": "json", "parser": "tiktok-trending"}],
)
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `country` | One of the 27 markets TikTok trends covers: ae, ar, au, br, ca, co, de, eg, es, fr, gb, id, il, it, jp, kr, mx, my, ph, sa, sg, th, tr, tw, us, vn, za. Any case is accepted. |

## Price

$0.001 per 10 videos. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be tikTok's Explore page, with an optional region in the link, such as region=DE, for another country's feed. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
