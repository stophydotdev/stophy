Reads a TikTok account's live page and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.tiktok.com/@khaby.lame/live","formats":[{"type":"json","parser":"tiktok-live"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.tiktok.com/@khaby.lame/live",
    formats: [{ type: "json", parser: "tiktok-live" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://www.tiktok.com/@khaby.lame/live",
        "formats": [{"type": "json", "parser": "tiktok-live"}],
    },
)
print(response.json())
```
</CodeGroup>

## Read the response

The parser's data is in `data.json`. Its fields include `userId`, `username`, `userUrl`, `name`, `isVerified` and `isLive`. This sample is cut to the first items.

```json
{
  "success": true,
  "data": {
    "json": {
      "userId": "7600000000000000003",
      "username": "example.streamer",
      "userUrl": "https://www.tiktok.com/@example.streamer",
      "name": "Example Streamer",
      "isVerified": false,
      "isLive": true,
      "roomId": "7000000000000000000",
      "title": "Evening live",
      "viewers": 250,
      "startedAt": "2026-11-17T12:00:00.000Z",
      "coverUrl": "https://example.com/live-cover.webp"

```

## Options

This parser takes no options.

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a TikTok account's live page. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
