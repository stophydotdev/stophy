Reads a TikTok account's live page and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.tiktok.com/@khaby.lame/live","formats":[{"type":"json","parser":"tiktok-live"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.scrape({
  url: "https://www.tiktok.com/@khaby.lame/live",
  formats: [{ type: "json", parser: "tiktok-live" }],
});
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.scrape(
    url="https://www.tiktok.com/@khaby.lame/live",
    formats=[{"type": "json", "parser": "tiktok-live"}],
)
print(result)
```
</CodeGroup>

## Read the response

The parser's data is in `data.json`. Its fields include `userId`, `username`, `userUrl`, `name`, `isVerified` and `isLive`. This sample is cut to the first items.

  "data": {
    "json": {

## Options

This parser takes no options.

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a TikTok account's live page. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
