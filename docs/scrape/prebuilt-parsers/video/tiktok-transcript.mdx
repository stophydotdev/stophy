Reads a TikTok video page or share link and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.tiktok.com/@charlidamelio/video/7137423965982592302","formats":[{"type":"json","parser":"tiktok-transcript"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.tiktok.com/@charlidamelio/video/7137423965982592302",
    formats: [{ type: "json", parser: "tiktok-transcript" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://www.tiktok.com/@charlidamelio/video/7137423965982592302",
        "formats": [{"type": "json", "parser": "tiktok-transcript"}],
    },
)
print(response.json())
```
</CodeGroup>

## Read the response

The parser's data is in `data.json`. Its fields include `startSeconds`, `endSeconds` and `text`. This sample is cut to the first items.

```json
{
  "success": true,
  "data": {
    "json": {
      "videoId": "7137423965982592302",
      "videoUrl": "https://www.tiktok.com/@charlidamelio/video/7137423965982592302",
      "language": "en",
      "isAutoGenerated": true,
      "durationSeconds": 11.12375,
      "transcribedSeconds": 12,
      "text": "First time, first time, first time, look you in your eyes What are you willing to do? Oh, tell me what you're willing…"
    }
  }
}
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `language` | BCP 47 language tag, e.g. en or pt-BR. Any case is accepted. |

It also takes `includeTimestamps`.

## Limits and errors

- The URL must be a TikTok video page or share link. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
