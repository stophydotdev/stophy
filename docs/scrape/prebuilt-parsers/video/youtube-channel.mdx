Reads a YouTube channel link: @handle, /channel/, /c/ or /user/, with an optional tab, and returns one profile as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. This parser works without an API key when you send no options, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits). To lift the limits, get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.youtube.com/@mkbhd","formats":[{"type":"json","parser":"youtube-channel"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
```

```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `tab` | YouTube's own channel tab. Releases are a music channel's albums. |
| `sort` | YouTube's own sort for the videos, shorts and live tabs. |
| `cursor` | The cursor from the previous response. Send it as is. |

## Price

$1 per 1,000 calls. Works without an API key, within the free limits. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a YouTube channel link: @handle, /channel/, /c/ or /user/, with an optional tab. Any other URL fails with `invalidRequest`.
- To read the next page, send the `cursor` from the response as the `cursor` option. Paging needs an API key.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
