Reads a Twitch channel's clips page, like twitch.tv/twitch/clips, and returns a list of videos as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.twitch.tv/twitch/clips","formats":[{"type":"json","parser":"twitch-clips"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed("twitch-clips", "https://www.twitch.tv/twitch/clips");
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed("twitch-clips", "https://www.twitch.tv/twitch/clips")
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `period` | Which clips to rank by views: the last day, week or month, or all time. Matches the range on the channel's clips page. Defaults to week. |
| `limit` | Return at most this many clips. You pay $0.001 for each 10 returned. |

## Price

$0.001 per 10 clips. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Twitch channel's clips page, like twitch.tv/twitch/clips. The range in the link (24hr, 7d, 30d or all) picks the period, and a link with no range gives the last 7 days. options.limit sets how many clips, up to 100. Twitch gives one page of clips, so there is no next page. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
