Reads an Instagram reel or video post and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.instagram.com/reel/DfS8Xbng4MD/","formats":[{"type":"json","parser":"instagram-transcript"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "instagram-transcript",
  "https://www.instagram.com/reel/DfS8Xbng4MD/",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "instagram-transcript",
    "https://www.instagram.com/reel/DfS8Xbng4MD/",

print(result)
```

## Read the response

The parser's data is in `data.json`. Its fields include `startSeconds`, `endSeconds` and `text`. This sample is cut to the first items.

```json
{
  "success": true,
  "data": {
    "json": {
      "videoId": "DfS8Xbng4MD",
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `language` | BCP 47 language tag, e.g. en or pt-BR. Any case is accepted. |

It also takes `includeTimestamps`.

## Price

$2 per 1,000 videos plus $0.24 per hour of audio, up to 5 minutes. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an Instagram reel or video post. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
