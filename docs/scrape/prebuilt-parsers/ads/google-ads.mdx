Reads a Google Ads Transparency Center advertiser page, ad page or search page with a domain, and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. This parser works without an API key when you send no options, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits). To lift the limits, get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://adstransparency.google.com/?region=US&domain=nike.com","formats":[{"type":"json","parser":"google-ads"}]}'
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `view` | Picks one of the answers this parser can give: `advertisers`. |
| `query` | A domain like nike.com. Google's library finds ads by domain or advertiser, not by keyword. |
| `platform` | Google's own Platform filter: where the ad was shown. Google leaves out ads shown before 4 September 2023 when it is set. |
| `shownFrom` | Google's own Date range: ads shown on or after this day. |
| `shownTo` | Google's own Date range: ads shown on or before this day. |
| `cursor` | The cursor from the previous response. Send it as is. |

It also takes `advertiser` and `mediaType`.

## Price

$1 per 1,000 calls. Works without an API key, within the free limits. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Google Ads Transparency Center advertiser page, ad page or search page with a domain. Set options.view to advertisers on a search page to look up advertisers by the domain's name. Any other URL fails with `invalidRequest`.
- To read the next page, send the `cursor` from the response as the `cursor` option. Paging needs an API key.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
