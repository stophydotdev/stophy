Reads a TikTok Ad Library search page with an adv_name keyword or advertiser, or an ad page, and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://library.tiktok.com/ads?region=DE&adv_name=adidas&query_type=1","formats":[{"type":"json","parser":"tiktok-ads"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "tiktok-ads",
  "https://library.tiktok.com/ads?region=DE&adv_name=adidas&query_type=1",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "tiktok-ads",
    "https://library.tiktok.com/ads?region=DE&adv_name=adidas&query_type=1",
)
print(result)
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `advertiser` | An advertiser name. TikTok matches the name exactly, so use it as tiktok.ads.ad gives it, like Nike, Inc. When no listed advertiser has exactly this name, the closest listed name is used. Send this or query, not both. |
| `cursor` | The cursor from the previous response. Send it as is. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a TikTok Ad Library search page with an adv_name keyword or advertiser, or an ad page. Any other URL fails with `invalidRequest`.
- To read the next page, send the `cursor` from the response as the `cursor` option. Paging needs an API key.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
