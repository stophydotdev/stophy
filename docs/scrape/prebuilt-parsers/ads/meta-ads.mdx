Reads a Meta Ad Library search page with a q keyword, a page view with a view_all_page_id, or an ad page with an id, and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=US&q=nike&search_type=keyword_exact_phrase","formats":[{"type":"json","parser":"meta-ads"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "meta-ads",
  "https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=US&q=nike&search_type=keyword_exact_phrase",
);
console.log(result);
```
```python Python
from stophy import Stophy

    "https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=US&q=nike&search_type=keyword_exact_phrase",
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `mediaType` | The Ad Library's own Media type filter: image, video, or text (no image or video). |
| `platforms` | The Ad Library's own Platform filter: only ads shown on at least one of these platforms. |
| `language` | The Ad Library's own Language filter: a two-letter code like en. Only ads written in this language. |
| `shownFrom` | The Ad Library's own Impressions by date: ads shown on or after this day. |
| `shownTo` | The Ad Library's own Impressions by date: ads shown on or before this day. |
| `cursor` | The cursor from the previous response. Send it as is. |

## Price

## Limits and errors

- The URL must be a Meta Ad Library search page with a q keyword, a page view with a view_all_page_id, or an ad page with an id. Any other URL fails with `invalidRequest`.
- To read the next page, send the `cursor` from the response as the `cursor` option. Paging needs an API key.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
