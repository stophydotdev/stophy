Reads any public web page and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.hetzner.com/legal/legal-notice/","formats":[{"type":"json","parser":"phone-numbers"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.hetzner.com/legal/legal-notice/",
    formats: [{ type: "json", parser: "phone-numbers" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://www.hetzner.com/legal/legal-notice/",
        "formats": [{"type": "json", "parser": "phone-numbers"}],
    },
)
print(response.json())
```
</CodeGroup>

## Read the response

The parser's data is in `data.json`. Its fields include `phone` and `pages`. This sample is cut to the first items.

```json
{
  "success": true,
  "data": {
    "json": {
      "url": "https://www.hetzner.com/legal/legal-notice/",
      "phones": [
        {
          "phone": "+1 555 0100",
          "pages": [
            "https://www.hetzner.com/legal/legal-notice/",
            "https://www.hetzner.com/support/",
            "https://www.hetzner.com/unternehmen/ueber-uns/"
          ]
        }
      ]
    }
  }
}
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `country` | Two-letter country code for numbers written without a country prefix, such as DE. Without it the country comes from the page: its numbers with a prefix, its address and its domain ending. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL can be any public web page.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
