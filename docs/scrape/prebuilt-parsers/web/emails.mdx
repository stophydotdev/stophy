Reads any public web page and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.hetzner.com/legal/legal-notice/","formats":[{"type":"json","parser":"emails"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed("emails", "https://www.hetzner.com/legal/legal-notice/");
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed("emails", "https://www.hetzner.com/legal/legal-notice/")
print(result)
```
</CodeGroup>

## Read the response

The parser's data is in `data.json`. Its fields include `email` and `pages`. This sample is cut to the first items.

```json
{
  "success": true,
  "data": {
    "json": {
      "url": "https://www.hetzner.com/legal/legal-notice/",
      "emails": [
        {
          "email": "name@example.com",
          "pages": [
            "https://www.hetzner.com/legal/legal-notice/",
            "https://www.hetzner.com/unternehmen/ueber-uns/"
          ]
        }
      ]
    }
  }
}
```

## Options

This parser takes no options.

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL can be any public web page.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
