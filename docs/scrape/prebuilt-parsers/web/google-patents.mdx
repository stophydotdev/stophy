Reads a Google Patents search page with q, inventor or assignee, and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. This parser works without an API key when you send no options, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits). To lift the limits, get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://patents.google.com/?q=solid+state+battery&assignee=Toyota","formats":[{"type":"json","parser":"google-patents"}]}'
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `office` | Google Patents' own Patent office, like US, EP, WO, CN or JP. |
| `dateType` | Which date before and after compare: Google Patents' own date choice. |
| `litigation` | Google Patents' own Litigation: has related litigation, or no known. |
| `page` | Page number, starting at 1. |

It also takes `inventor`, `language`, `after`, `before`, `status`, `type` and `sort`.

## Price

$1 per 1,000 calls. Works without an API key, within the free limits. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Google Patents search page with q, inventor or assignee. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
