Reads a Google Trends explore page with search terms in q, or the trending now page, and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://trends.google.com/trends/explore?q=bitcoin&geo=US&date=today%2012-m","formats":[{"type":"json","parser":"google-trends"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,

  },

  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},

        "formats": [{"type": "json", "parser": "google-trends"}],

print(response.json())
```

## Read the response

The parser's data is in `data.json`. Its fields include `query` and `value`. This sample is cut to the first items.

```json
{
  "success": true,
  "data": {
    "json": {
      "results": [
        {
          "query": "bitcoin price",
          "value": 100
        }
      ],
      "rising": [
        {
          "query": "spcx",
          "increasePercent": null,
          "isBreakout": true
        }
      ]
    }
  }
}
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `view` | Picks one of the answers this parser can give: `related`, `interest` and `regions`. |
| `searchType` | Google Trends' own search type: web, images, news, shopping or youtube. |
| `category` | Google Trends' own top-level category. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Google Trends explore page with search terms in q, or the trending now page. One term gives its related searches and several terms give their interest over time. Set options.view to related, interest or regions to pick that answer for the terms. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
