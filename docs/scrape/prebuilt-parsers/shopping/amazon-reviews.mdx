Reads an Amazon product page and returns a list of reviews as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.amazon.in/dp/B0CHX1W1XY","formats":[{"type":"json","parser":"amazon-reviews"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed("amazon-reviews", "https://www.amazon.in/dp/B0CHX1W1XY");
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed("amazon-reviews", "https://www.amazon.in/dp/B0CHX1W1XY")
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `country` | ISO 3166-1 alpha-2 country code, e.g. us. Any case is accepted. |

## Price

## Limits and errors

- The URL must be an Amazon product page. Marketplaces outside the US, like amazon.in/dp/`<ASIN>`, show their top reviews without sign-in, up to 13 for the product page. Amazon US shows reviews only after sign-in, so an amazon.com page returns reviews for few products. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
