Reads a Craigslist search page with a five-digit US ZIP code in postal, like sfbay.craigslist.org/search/sss?query=bike&postal=94103, and returns a list of listings as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://sfbay.craigslist.org/search/sss?query=bike&postal=94103&search_distance=25","formats":[{"type":"json","parser":"craigslist-search"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://sfbay.craigslist.org/search/sss?query=bike&postal=94103&search_distance=25",
    formats: [{ type: "json", parser: "craigslist-search" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://sfbay.craigslist.org/search/sss?query=bike&postal=94103&search_distance=25",
        "formats": [{"type": "json", "parser": "craigslist-search"}],
    },
)
print(response.json())
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `minPrice` | Lowest price in US dollars (e.g., 50). |
| `maxPrice` | Highest price in US dollars (e.g., 500). |
| `limit` | Return at most this many listings. You pay $0.001 for each 10 returned. |

## Price

$0.001 per 10 listings. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Craigslist search page with a five-digit US ZIP code in postal, like sfbay.craigslist.org/search/sss?query=bike&postal=94103. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
