Reads an Amazon Best Sellers category page, like amazon.com/Best-Sellers-Electronics/zgbs/electronics, and returns a list of products as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.amazon.com/Best-Sellers-Electronics/zgbs/electronics","formats":[{"type":"json","parser":"amazon-bestsellers"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.amazon.com/Best-Sellers-Electronics/zgbs/electronics",
    formats: [{ type: "json", parser: "amazon-bestsellers" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://www.amazon.com/Best-Sellers-Electronics/zgbs/electronics",
        "formats": [{"type": "json", "parser": "amazon-bestsellers"}],
    },
)
print(response.json())
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `page` | Page number, starting at 1. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an Amazon Best Sellers category page, like amazon.com/Best-Sellers-Electronics/zgbs/electronics. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
