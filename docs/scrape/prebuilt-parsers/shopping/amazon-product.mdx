Reads an Amazon product page, like amazon.com/dp/`<ASIN>`, and returns one product as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.amazon.com/dp/B0CX23V2ZK","formats":[{"type":"json","parser":"amazon-product"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed("amazon-product", "https://www.amazon.com/dp/B0CX23V2ZK");
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed("amazon-product", "https://www.amazon.com/dp/B0CX23V2ZK")
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `country` | ISO 3166-1 alpha-2 country code, e.g. us. Any case is accepted. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an Amazon product page, like amazon.com/dp/`<ASIN>`. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
