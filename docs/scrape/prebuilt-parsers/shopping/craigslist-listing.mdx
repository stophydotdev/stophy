Reads one Craigslist post, like craigslist.org/view/d/hermosa-beach-thule-kayak-carrier-new/2uYpYvcvf6gMZMAkgfgSPg, and returns one listing as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.craigslist.org/view/d/hermosa-beach-thule-kayak-carrier-new/2uYpYvcvf6gMZMAkgfgSPg","formats":[{"type":"json","parser":"craigslist-listing"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.craigslist.org/view/d/hermosa-beach-thule-kayak-carrier-new/2uYpYvcvf6gMZMAkgfgSPg",
    formats: [{ type: "json", parser: "craigslist-listing" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://www.craigslist.org/view/d/hermosa-beach-thule-kayak-carrier-new/2uYpYvcvf6gMZMAkgfgSPg",
        "formats": [{"type": "json", "parser": "craigslist-listing"}],
    },
)
print(response.json())
```

## Limits and errors

- The URL must be one Craigslist post, like craigslist.org/view/d/hermosa-beach-thule-kayak-carrier-new/2uYpYvcvf6gMZMAkgfgSPg. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
