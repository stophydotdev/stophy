Reads a Trustpilot company page, like trustpilot.com/review/stripe.com, and returns a list of reviews as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.trustpilot.com/review/stripe.com?stars=1&stars=2&languages=en","formats":[{"type":"json","parser":"trustpilot-reviews"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "trustpilot-reviews",
  "https://www.trustpilot.com/review/stripe.com?stars=1&stars=2&languages=en",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "trustpilot-reviews",
    "https://www.trustpilot.com/review/stripe.com?stars=1&stars=2&languages=en",
)
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `datePublished` | Only reviews published in the last 30 days, 3, 6 or 12 months. |
| `verifiedOnly` | Only reviews Trustpilot marks as verified. |
| `search` | Only reviews that mention this word or phrase. |
| `page` | Page number, starting at 1. Trustpilot shows 10 pages of 20 reviews without an account; narrow with ratings, language, datePublished or search to reach older reviews. |

## Limits and errors

- The URL must be a Trustpilot company page, like trustpilot.com/review/stripe.com. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
