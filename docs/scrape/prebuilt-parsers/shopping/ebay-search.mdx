Reads an ebay.com search page, like ebay.com/sch/i.html?_nkw=iphone, and returns a list of products as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.ebay.com/sch/i.html?_nkw=iphone+15&_udlo=300&_udhi=800&_sop=15","formats":[{"type":"json","parser":"ebay-search"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "ebay-search",
  "https://www.ebay.com/sch/i.html?_nkw=iphone+15&_udlo=300&_udhi=800&_sop=15",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "ebay-search",
    "https://www.ebay.com/sch/i.html?_nkw=iphone+15&_udlo=300&_udhi=800&_sop=15",
)
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `auctionsOnly` | Only auctions. With sort endingSoonest this lists auctions about to end; ebay.item then returns what each one sold for. |
| `page` | Page number, starting at 1. |

It also takes `condition`.

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an ebay.com search page, like ebay.com/sch/i.html?_nkw=iphone. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
