Reads an eBay item page, like ebay.com/itm/`<item id>`, and returns one product as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.ebay.com/itm/266625967665","formats":[{"type":"json","parser":"ebay-item"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed("ebay-item", "https://www.ebay.com/itm/266625967665");
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed("ebay-item", "https://www.ebay.com/itm/266625967665")
print(result)
```
</CodeGroup>

## Price

## Limits and errors

- The URL must be an eBay item page, like ebay.com/itm/`<item id>`. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
