Reads a Facebook Marketplace search page with a city and a query, like facebook.com/marketplace/austin/search?query=bike, and returns a list of listings as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.facebook.com/marketplace/austin/search?query=bike","formats":[{"type":"json","parser":"facebook-marketplace"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.facebook.com/marketplace/austin/search?query=bike",
    formats: [{ type: "json", parser: "facebook-marketplace" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://www.facebook.com/marketplace/austin/search?query=bike",
        "formats": [{"type": "json", "parser": "facebook-marketplace"}],
    },
)
print(response.json())
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `minPrice` | Lowest price in local currency (e.g., 50). |
| `maxPrice` | Highest price in local currency (e.g., 500). |
| `sort` | Sort order (newest, priceLow or priceHigh), relevance by default. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Facebook Marketplace search page with a city and a query, like facebook.com/marketplace/austin/search?query=bike. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
