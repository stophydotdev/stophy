### `appstore-search`

An App Store search page, like apps.apple.com/us/iphone/search?term=notes. Example: `https://apps.apple.com/us/iphone/search?term=notes`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `limit`

### `appstore-app`

An App Store app page, like apps.apple.com/us/app/notes/id1110145109. Example: `https://apps.apple.com/us/app/notes/id1110145109`

Returns `id`, `url`, `title`, `brand`, `description`, `price`, `originalPrice`, `rating`, `reviewCount`, `availability`, `images`, `categories`, `seller`.

Options:
- `country`

### `appstore-reviews`

An App Store app page, like apps.apple.com/us/app/notes/id1110145109. Example: `https://apps.apple.com/us/app/notes/id1110145109`

Returns `results`, `cursor`, `page`, `total`.

Works without an API key when you send no options.

Options:
- `country`
- `sort`
- `page`
