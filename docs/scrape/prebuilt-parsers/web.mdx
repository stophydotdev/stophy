### `google-patents`

A Google Patents search page with q, inventor or assignee. Example: `https://patents.google.com/?q=solid+state+battery&assignee=Toyota`

Returns `patentId`, `title`, `snippet`, `assignee`, `inventor`, `priorityDate`.

Works without an API key when you send no options.

Options:
- `inventor`
- `office`: Google Patents' own Patent office, like US, EP, WO, CN or JP.
- `language`
- `dateType`: Which date before and after compare: Google Patents' own date choice.
- `after`
- `before`
- `status`
- `type`
- `litigation`: Google Patents' own Litigation: has related litigation, or no known.
- `sort`
- `page`

### `google-trends`

A Google Trends explore page with search terms in q, or the trending now page. One term gives its related searches and several terms give their interest over time. Set options.view to related, interest or regions to pick that answer for the terms. Example: `https://trends.google.com/trends/explore?q=bitcoin&geo=US&date=today%2012-m`

Returns `query`, `value`.

Options:
- `view`: `related`, `interest`, `regions`.
- `searchType`: Google Trends' own search type: web, images, news, shopping or youtube.
- `category`: Google Trends' own top-level category.
- `resolution`, with `view` `regions`: how finely to split the results. country compares countries and cannot be used with a country. region compares the regions of the country, and metro its metro areas; both need a country. Left out, Google picks.

### `emails`

Any public web page. Example: `https://www.hetzner.com/legal/legal-notice/`

Returns `email`, `pages`.

### `phone-numbers`

Any public web page. Example: `https://www.hetzner.com/legal/legal-notice/`

Returns `phone`, `pages`.

Options:
- `country`: Two-letter country code for numbers written without a country prefix, such as DE. Without it the country comes from the page: its numbers with a prefix, its address and its domain ending.
