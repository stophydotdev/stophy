Reads a Booking.com hotel page, like booking.com/hotel/pt/hf-fenix-urban.html, and returns a list of reviews as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.booking.com/hotel/pt/hf-fenix-urban.html","formats":[{"type":"json","parser":"booking-reviews"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "booking-reviews",
  "https://www.booking.com/hotel/pt/hf-fenix-urban.html",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "booking-reviews",
    "https://www.booking.com/hotel/pt/hf-fenix-urban.html",
)
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `sort` | Booking.com's own Sort reviews by: newest, mostRelevant or lowestScore (lowest scores first). Only newest pages without gaps. The other orders change between requests, so a walk through the pages can miss reviews. |
| `cursor` | The cursor from the previous response. Send it as is. |

## Limits and errors

- The URL must be a Booking.com hotel page, like booking.com/hotel/pt/hf-fenix-urban.html. Any other URL fails with `invalidRequest`.
- To read the next page, send the `cursor` from the response as the `cursor` option. Paging needs an API key.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
