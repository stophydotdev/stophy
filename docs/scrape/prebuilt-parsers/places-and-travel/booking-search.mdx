Reads a Booking.com search results page with a place in ss, like booking.com/searchresults.html?ss=Lisbon, and returns a list of listings as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.booking.com/searchresults.html?ss=Lisbon&checkin=2026-12-10&checkout=2026-12-12&group_adults=2&no_rooms=1","formats":[{"type":"json","parser":"booking-search"}]}'
```

```python Python
import os

import requests

response = requests.post(
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `currency` | ISO 4217 currency code, e.g. USD. |
| `sort` | Booking.com's own Sort by: relevance (Our top picks) or distance (closest to the center of the place first). |
| `cursor` | The cursor from the previous response. Send it as is. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Booking.com search results page with a place in ss, like booking.com/searchresults.html?ss=Lisbon. Any other URL fails with `invalidRequest`.
- To read the next page, send the `cursor` from the response as the `cursor` option. Paging needs an API key.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
