Reads an Airbnb search page for a place with checkin and checkout dates, like airbnb.com/s/Lisbon--Portugal/homes?checkin=2026-12-10&checkout=2026-12-12, and returns a list of listings as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.airbnb.com/s/Lisbon--Portugal/homes?checkin=2026-12-10&checkout=2026-12-12&adults=2","formats":[{"type":"json","parser":"airbnb-search"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

console.log(result);
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `minPrice` | Airbnb's own price range minimum: the nightly price after discounts and before taxes, in currency. |
| `maxPrice` | Airbnb's own price range maximum: the nightly price after discounts and before taxes, in currency. |
| `roomType` | Airbnb's own Type of place filter: entireHome (Entire home) or privateRoom (Room). |
| `currency` | Currency of every price in the answer and of minPrice and maxPrice. |
| `cursor` | The cursor from the previous response. Send it as is. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an Airbnb search page for a place with checkin and checkout dates, like airbnb.com/s/Lisbon--Portugal/homes?checkin=2026-12-10&checkout=2026-12-12. Any other URL fails with `invalidRequest`.
- To read the next page, send the `cursor` from the response as the `cursor` option. Paging needs an API key.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
