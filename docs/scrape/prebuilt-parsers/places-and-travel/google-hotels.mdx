Reads a Google Hotels page with a place in q, like hotels in Lisbon, and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.google.com/travel/search?q=hotels%20in%20Lisbon","formats":[{"type":"json","parser":"google-hotels"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {

  }),
});
console.log(await response.json());
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `checkIn` | Defaults to tomorrow. |
| `checkOut` | Defaults to one night after checkIn. |
| `childrenAges` | One age per child, like [7, 12]. |
| `currency` | ISO 4217 currency code, e.g. USD. |
| `minPrice` | Per night. |
| `maxPrice` | Per night. |
| `minRating` | Google Hotels' own Guest rating. |
| `hotelClass` | Google Hotels' own Hotel class, as star counts like [4, 5]. |
| `amenities` | Google Hotels' own Amenities. Every one must be offered. |
| `propertyTypes` | Google Hotels' own Property type. |
| `cursor` | The cursor from the previous response. Send it as is. |

It also takes `adults`, `freeCancellation`, `specialOffers` and `sort`.

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Google Hotels page with a place in q, like hotels in Lisbon. Any other URL fails with `invalidRequest`.
- To read the next page, send the `cursor` from the response as the `cursor` option. Paging needs an API key.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
