Reads an Expedia hotel search page with a destination, like expedia.com/Hotel-Search?destination=Paris, and returns a list of listings as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.expedia.com/Hotel-Search?destination=Paris&startDate=2026-12-10&endDate=2026-12-12&adults=2","formats":[{"type":"json","parser":"expedia-hotels"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "expedia-hotels",
  "https://www.expedia.com/Hotel-Search?destination=Paris&startDate=2026-12-10&endDate=2026-12-12&adults=2",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "expedia-hotels",
    "https://www.expedia.com/Hotel-Search?destination=Paris&startDate=2026-12-10&endDate=2026-12-12&adults=2",
)
print(result)
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `sort` | Expedia's own sort: relevance (Recommended), priceLow (lowest price first) or rating (guest rating). |
| `page` | Page number, starting at 1. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an Expedia hotel search page with a destination, like expedia.com/Hotel-Search?destination=Paris. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
