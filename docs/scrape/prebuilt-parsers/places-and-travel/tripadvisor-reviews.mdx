Reads a Tripadvisor hotel, restaurant or attraction page, and returns a list of reviews as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.tripadvisor.com/Hotel_Review-g186338-d187591-Reviews-The_Ritz_London_Hotel-London_England.html","formats":[{"type":"json","parser":"tripadvisor-reviews"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "tripadvisor-reviews",
  "https://www.tripadvisor.com/Hotel_Review-g186338-d187591-Reviews-The_Ritz_London_Hotel-London_England.html",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

    "tripadvisor-reviews",
    "https://www.tripadvisor.com/Hotel_Review-g186338-d187591-Reviews-The_Ritz_London_Hotel-London_England.html",
)
print(result)
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `travelerTypes` | Tripadvisor's own Traveler type filter: families, couples, solo, business or friends. Only reviews from these travelers. |
| `months` | Tripadvisor's own Time of year filter: marMay, junAug, sepNov or decFeb. Only reviews written in these months of the year. |
| `sort` | Tripadvisor's own Sort by: mostRecent (Most recent) or detailed (Detailed reviews, ordered by recency and how much they say). |
| `page` | Page number, starting at 1. |

It also takes `language` and `ratings`.

## Limits and errors

- The URL must be a Tripadvisor hotel, restaurant or attraction page. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
