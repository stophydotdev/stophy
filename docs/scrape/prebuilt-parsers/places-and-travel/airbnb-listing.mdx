Reads an Airbnb listing page, like airbnb.com/rooms/18249319, and returns one listing as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.airbnb.com/rooms/18249319","formats":[{"type":"json","parser":"airbnb-listing"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed("airbnb-listing", "https://www.airbnb.com/rooms/18249319");
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "airbnb-listing",
    "https://www.airbnb.com/rooms/18249319",
)
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `checkIn` | First night, as YYYY-MM-DD. Send it with checkOut to get the price. |
| `checkOut` | Day you leave, as YYYY-MM-DD. Send it with checkIn to get the price. |
| `guests` | Number of guests. Only stays that fit this many. |
| `currency` | Currency of every price in the answer and of minPrice and maxPrice. |

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an Airbnb listing page, like airbnb.com/rooms/18249319. With check_in, check_out and adults in the link it also returns the price for those dates. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
