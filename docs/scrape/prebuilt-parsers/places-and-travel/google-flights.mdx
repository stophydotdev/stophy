Reads a Google Flights search page, from the address bar or with a q of IATA airport codes and a date, like Flights to JFK from LHR on 2026-12-15, and returns its data as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.google.com/travel/flights?q=Flights%20to%20JFK%20from%20LHR%20on%202026-12-15","formats":[{"type":"json","parser":"google-flights"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "google-flights",
  "https://www.google.com/travel/flights?q=Flights%20to%20JFK%20from%20LHR%20on%202026-12-15",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "google-flights",
    "https://www.google.com/travel/flights?q=Flights%20to%20JFK%20from%20LHR%20on%202026-12-15",
)
print(result)
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `currency` | ISO 4217 currency code, e.g. USD. |
| `stops` | Google Flights' Stops filter. |
| `airlines` | Google Flights' Airlines filter, as airline codes like KQ or EK. |
| `carryOnBags` | Google Flights' Bags filter: prices include this many carry-on bags. |
| `checkedBags` | Google Flights' Bags filter: prices include this many checked bags. |
| `maxPrice` | Google Flights' Price filter, in currency for all adults. |
| `departureTime` | Google Flights' Times filter for the outbound departure. |
| `arrivalTime` | Google Flights' Times filter for the outbound arrival. |
| `maxDurationHours` | Google Flights' Duration filter. |

It also takes `returnDate`, `adults` and `cabin`.

## Limits and errors

- The URL must be a Google Flights search page, from the address bar or with a q of IATA airport codes and a date, like Flights to JFK from LHR on 2026-12-15. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
