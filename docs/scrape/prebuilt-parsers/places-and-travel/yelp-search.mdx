Reads a Yelp search page with both what and where, like yelp.com/search?find_desc=pizza&find_loc=Austin%2C+TX, and returns a list of places as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.yelp.com/search?find_desc=plumber&find_loc=Austin%2C+TX","formats":[{"type":"json","parser":"yelp-search"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed(
  "yelp-search",
  "https://www.yelp.com/search?find_desc=plumber&find_loc=Austin%2C+TX",
);
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed(
    "yelp-search",
    "https://www.yelp.com/search?find_desc=plumber&find_loc=Austin%2C+TX",
)
print(result)
```
</CodeGroup>

## Options

This parser takes no options.

## Price

$1 per 1,000 calls. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Yelp search page with both what and where, like yelp.com/search?find_desc=pizza&find_loc=Austin%2C+TX. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
