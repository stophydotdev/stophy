Reads an X community page, like x.com/i/communities/`<id>`. Send options view posts for the community's top posts, with no cursor for more, and returns one profile as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. This parser works without an API key when you send no options, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits). To lift the limits, get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://x.com/i/communities/1699807431709041070","formats":[{"type":"json","parser":"x-community"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://x.com/i/communities/1699807431709041070",
    formats: [{ type: "json", parser: "x-community" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://x.com/i/communities/1699807431709041070",
        "formats": [{"type": "json", "parser": "x-community"}],
    },
)
print(response.json())
```

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `view` | Picks one of the answers this parser can give: `posts`. |

## Price

$1 per 1,000 calls. Works without an API key, within the free limits. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an X community page, like x.com/i/communities/`<id>`. Send options view posts for the community's top posts, with no cursor for more. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
