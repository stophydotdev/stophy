Reads a Linktree, Komi, Linkbio or Linkme page, like linktr.ee/name, name.komi.io, linkbio.co/name, linkme.bio/name or link.me/name, and returns one profile as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://linktr.ee/selenagomez","formats":[{"type":"json","parser":"link-in-bio"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed("link-in-bio", "https://linktr.ee/selenagomez");
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed("link-in-bio", "https://linktr.ee/selenagomez")
print(result)
```
</CodeGroup>

## Limits and errors

- The URL must be a Linktree, Komi, Linkbio or Linkme page, like linktr.ee/name, name.komi.io, linkbio.co/name, linkme.bio/name or link.me/name. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
