Reads a Bluesky profile page, like bsky.app/profile/bsky.app, and returns one profile as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://bsky.app/profile/bsky.app","formats":[{"type":"json","parser":"bsky-profile"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed("bsky-profile", "https://bsky.app/profile/bsky.app");
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed("bsky-profile", "https://bsky.app/profile/bsky.app")
print(result)
```
</CodeGroup>

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `view` | Picks one of the answers this parser can give: `posts`. |
| `limit` | With `view` `posts`: return at most this many posts. You pay $0.001 for each 10 returned. |
| `cursor` | With `view` `posts`: the cursor from the previous response. Send it as is. |

## Price

$1 per 1,000 calls. The `posts` view costs $0.001 per 10 posts. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Bluesky profile page, like bsky.app/profile/bsky.app. Set options.view to posts for the profile's posts, and options.cursor from the last answer for the next page. A page can be empty with a cursor, so keep paging until the cursor is null. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
