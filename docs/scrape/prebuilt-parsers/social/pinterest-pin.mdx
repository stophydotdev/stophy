Reads a Pinterest pin page or a pin.it short link and returns one post as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. This parser works without an API key when you send no options, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits). To lift the limits, get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.pinterest.com/pin/32088216099796013/","formats":[{"type":"json","parser":"pinterest-pin"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

);
console.log(result);
```

## Options

This parser takes no options.

## Price

$1 per 1,000 calls. Works without an API key, within the free limits. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be a Pinterest pin page or a pin.it short link. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
