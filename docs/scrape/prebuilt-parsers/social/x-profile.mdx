Reads an X profile page, like x.com/nasa, and returns one profile as JSON.

## Make a request

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. This parser works without an API key when you send no options, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits). To lift the limits, get an API key in the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://x.com/nasa","formats":[{"type":"json","parser":"x-profile"}]}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.parsed("x-profile", "https://x.com/nasa");
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.parsed("x-profile", "https://x.com/nasa")
print(result)
```
</CodeGroup>

## Read the response

## Options

Send options in the `options` object of the `json` format.

| Option | What it does |
| --- | --- |
| `view` | Picks one of the answers this parser can give: `posts`. |
| `cursor` | With `view` `posts`: the cursor from the previous response. Send it as is. |

## Price

$1 per 1,000 calls. Works without an API key, within the free limits. The `posts` view needs an API key. See [Pricing](/account/pricing).

## Limits and errors

- The URL must be an X profile page, like x.com/nasa. Set options.view to posts for the profile's posts. Any other URL fails with `invalidRequest`.
- The answer comes back in `data.json`. If the page cannot be read, the call fails with an error code from [Errors](/api-reference/errors).
