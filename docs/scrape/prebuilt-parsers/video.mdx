### `youtube-search`

A YouTube search results page with the search in search_query. Example: `https://www.youtube.com/results?search_query=lofi+beats`

Returns `results`, `cursor`, `page`, `total`.

Works without an API key when you send no options.

Options:
- `type`: Leave out for videos, channels and playlists. Use shorts for Shorts.
- `duration`
- `uploadDate`
- `features`
- `prioritize`
- `cursor`

### `twitch-profile`

A Twitch channel page, like twitch.tv/twitch. Gives the channel's name, description, followers, whether it is live now (with the stream's title, game, viewers and start time) and its 10 newest past broadcasts. Example: `https://www.twitch.tv/twitch`

### `twitch-clips`

A Twitch channel's clips page, like twitch.tv/twitch/clips. The range in the link (24hr, 7d, 30d or all) picks the period, and a link with no range gives the last 7 days. options.limit sets how many clips, up to 100. Twitch gives one page of clips, so there is no next page. Example: `https://www.twitch.tv/twitch/clips`

Returns `results`, `cursor`, `page`, `total`.

Options:
- `period`: Which clips to rank by views: the last day, week or month, or all time. Matches the range on the channel's clips page. Defaults to week.
- `limit`: Return at most this many clips. You pay $0.001 for each 10 returned.
