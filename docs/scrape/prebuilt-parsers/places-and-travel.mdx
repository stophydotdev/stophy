### `google-maps`

A Google Maps search page that names a place after in, near or around. Example: `https://www.google.com/maps/search/dentists+in+Ljubljana`

Returns `results`, `cursor`, `page`, `total`.

Works without an API key when you send no options.

Options:
- `minRating`
- `openNow`: Google Maps' own Hours filter, Open now: only places open at the moment of the search.
- `country`
- `language`
- `page`

### `google-flights`

A Google Flights search page, from the address bar or with a q of IATA airport codes and a date, like Flights to JFK from LHR on 2026-12-15. Example: `https://www.google.com/travel/flights?q=Flights%20to%20JFK%20from%20LHR%20on%202026-12-15`

Returns `isBest`, `price`, `priceCurrency`, `airlines`, `stops`, `durationSeconds`.

Options:
- `returnDate`
- `adults`
- `cabin`
- `currency`
- `stops`: Google Flights' Stops filter.
- `airlines`: Google Flights' Airlines filter, as airline codes like KQ or EK.
- `carryOnBags`: Google Flights' Bags filter: prices include this many carry-on bags.
- `checkedBags`: Google Flights' Bags filter: prices include this many checked bags.
- `maxPrice`: Google Flights' Price filter, in currency for all adults.
- `departureTime`: Google Flights' Times filter for the outbound departure.
- `arrivalTime`: Google Flights' Times filter for the outbound arrival.
- `maxDurationHours`: Google Flights' Duration filter.

### `google-hotels`

A Google Hotels page with a place in q, like hotels in Lisbon. Example: `https://www.google.com/travel/search?q=hotels%20in%20Lisbon`

Returns `name`, `hotelId`, `hotelUrl`, `price`, `totalPrice`, `priceCurrency`.

Options:
- `checkIn`: Defaults to tomorrow.
- `checkOut`: Defaults to one night after checkIn.
- `adults`
- `childrenAges`: One age per child, like [7, 12].
- `currency`
- `minPrice`: Per night.
- `maxPrice`: Per night.
- `minRating`: Google Hotels' own Guest rating.
- `hotelClass`: Google Hotels' own Hotel class, as star counts like [4, 5].
- `amenities`: Google Hotels' own Amenities. Every one must be offered.
- `propertyTypes`: Google Hotels' own Property type.
- `freeCancellation`
- `specialOffers`
- `sort`
- `cursor`

### `airbnb-listing`

An Airbnb listing page, like airbnb.com/rooms/18249319. With check_in, check_out and adults in the link it also returns the price for those dates. Example: `https://www.airbnb.com/rooms/18249319`

Returns `id`, `url`, `title`, `description`, `price`, `pricePeriod`, `status`, `address`, `location`, `bedrooms`, `bathrooms`, `area`, `propertyType`, `rating`, `reviewCount`, `images`, `host`.

- `guests`: Number of guests. Only stays that fit this many.
- `currency`: Currency of every price in the answer and of minPrice and maxPrice.
