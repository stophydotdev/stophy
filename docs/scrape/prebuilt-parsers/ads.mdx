### `meta-ads`

A Meta Ad Library search page with a q keyword, a page view with a view_all_page_id, or an ad page with an id. Example: `https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=US&q=nike&search_type=keyword_exact_phrase`

Returns `adId`, `adUrl`, `pageId`, `pageName`, `pageUrl`, `pageAvatarUrl`.

Options:
- `mediaType`: The Ad Library's own Media type filter: image, video, or text (no image or video).
- `platforms`: The Ad Library's own Platform filter: only ads shown on at least one of these platforms.
- `language`: The Ad Library's own Language filter: a two-letter code like en. Only ads written in this language.
- `shownFrom`: The Ad Library's own Impressions by date: ads shown on or after this day.
- `shownTo`: The Ad Library's own Impressions by date: ads shown on or before this day.
- `cursor`

### `google-ads`

A Google Ads Transparency Center advertiser page, ad page or search page with a domain. Set options.view to advertisers on a search page to look up advertisers by the domain's name. Example: `https://adstransparency.google.com/?region=US&domain=nike.com`

Returns `adId`, `adUrl`, `advertiserId`, `advertiserName`, `advertiserUrl`, `domain`.

Works without an API key when you send no options.

Options:
- `view`: `advertisers`.
- `query`: A domain like nike.com. Google's library finds ads by domain or advertiser, not by keyword.
- `advertiser`
- `mediaType`
- `platform`: Google's own Platform filter: where the ad was shown. Google leaves out ads shown before 4 September 2023 when it is set.
- `shownFrom`: Google's own Date range: ads shown on or after this day.
- `shownTo`: Google's own Date range: ads shown on or before this day.
- `cursor`
- `limit`, with `view` `advertisers`: how many advertisers to ask Google for, 1 to 100. Google ranks the list for the count you ask, so a larger limit is not the same list with more rows added, and there are no further pages. Fewer come back when Google has fewer matches.

### `tiktok-ads`

A TikTok Ad Library search page with an adv_name keyword or advertiser, or an ad page. Example: `https://library.tiktok.com/ads?region=DE&adv_name=adidas&query_type=1`

Returns `adId`, `adUrl`, `advertiserName`, `headline`, `firstShownAt`, `lastShownAt`.

Options:
- `advertiser`: An advertiser name. TikTok matches the name exactly, so use it as tiktok.ads.ad gives it, like Nike, Inc. When no listed advertiser has exactly this name, the closest listed name is used. Send this or query, not both.
- `cursor`

### `linkedin-ads`

A LinkedIn Ad Library search page with a keyword or accountOwner, or an ad page or lnkd.in share link. Example: `https://www.linkedin.com/ad-library/search?keyword=software&countries=DE`

Returns `adId`, `adUrl`, `creativeType`, `format`, `advertiserName`, `advertiserUrl`.

Options:
- `advertiser`
- `within`: Only ads shown in the last 30 days or the last year.
- `cursor`
