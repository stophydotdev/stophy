`branding` reads the look of a page: its colors, fonts, type scale, spacing, button and input styles, and its logo and brand images.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request reads the look of a home page.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com",
    "formats": ["branding"]
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.scrape({
  url: "https://bun.com",
  formats: ["branding"],
});
console.log(data.branding?.colors);
console.log(data.branding?.fonts);
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.scrape(
    url="https://bun.com",
    formats=["branding"],
)["data"]
print(data["branding"]["colors"])
print(data["branding"]["fonts"])
```
</CodeGroup>

Colors are hex values. A field the page does not show is left out, so check that a field is there before you use it.

| Field | What it holds |
| - | - |
| `colorScheme` | `light` or `dark`. |
| `logo` | The URL of the logo. |
| `colors` | `primary`, `secondary`, `accent`, `background`, `textPrimary`, `textSecondary`, `link`, `success`, `warning` and `error`. |
| `fonts` | The font families the page uses. |
| `typography` | Font families, sizes, weights and line heights. |
| `spacing` | Base unit, border radius, padding and margins. |
| `components` | Styles of `buttonPrimary`, `buttonSecondary` and `input`. |
| `images` | `logo`, `favicon` and `ogImage`. |
| `icons`, `animations`, `layout`, `personality` | Other style facts, when the page shows them. |

## Options

| Field | Type | Default | Effect |
| - | - | - | - |
| `formats` | `array` | `["markdown"]` | Add `"branding"` to return the look of the page. |

## Limits and errors

- The page is read in a browser and never from a stored copy, so the call takes a few seconds.
- A PDF comes back as Markdown only. Asking for `branding` on a PDF returns `400 invalidRequest`.
- A page that answers with a 404 or 410 status, or cannot be read, costs nothing.

## Price

$1 per 1,000 pages, the same as any page. `branding` adds nothing.
