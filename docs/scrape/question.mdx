Use `question` when you need a short answer from one page, not the full text. We answer only from that page.

## Ask a question

Get an API key in the [Quickstart](/quickstart). Send `question` as an object. This request asks a documentation page for the name of its configuration file.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com/docs/runtime/bunfig",
    "formats": [
      { "type": "question", "question": "What is the name of Bun'\''s configuration file?" }
    ]
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://bun.com/docs/runtime/bunfig",
    formats: [
      { type: "question", question: "What is the name of Bun's configuration file?" },
    ],
  }),
});
const { data } = await response.json();
console.log(data.answer);
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://bun.com/docs/runtime/bunfig",
        "formats": [
            {"type": "question", "question": "What is the name of Bun's configuration file?"},
        ],
    },
)
data = response.json()["data"]
print(data.get("answer"))
```
</CodeGroup>

## Read the response

Read `data.answer` for one to four plain sentences. Check that the field is present before using it.

```json
{
  "success": true,
  "data": {
    "answer": "Bun's configuration file is named bunfig.toml.",
    "metadata": {
      "costUsd": 0.004
    }
  }
}
```

When the page does not state the answer, `answer` is left out of `data`, `data.warning` says `The page does not state an answer to the question.`, and the $3 is not charged. Check that `answer` is there before you use it.

## Options

Put the question in the format object, not in the top-level `query` field.

| Field | Type | Default | Effect |
| - | - | - | - |
| `type` | `string` | none | `"question"`. Required. |
| `question` | `string` | none | The question, such as `What is the refund window?`. Required, 1 to 10,000 characters. |

## Limits and errors

Keep the request to one question. For multiple answers or names your code can rely on, use JSON.

- Each request answers one question. To ask several, send several requests, or use [JSON](/scrape/json) with one field per question.
- The answer is made from the first 50,000 characters of the page's Markdown.
- A call without `question` returns `400 invalidRequest`.

## Price

$4 per 1,000 pages: $1 for the page and $3 for the answer. A page that does not state the answer costs $1 per 1,000 pages.
