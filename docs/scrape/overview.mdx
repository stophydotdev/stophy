Use Scrape when you know the URL of the page you want to read. You can ask for more than one output in `formats`. Without `formats`, you get Markdown.

## Make a request

Get an API key in the [Quickstart](/quickstart), and install the SDK with `npm install stophy` or `pip install stophy`. This request returns the main content of a docs page as Markdown, plus every link on it.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com/docs/runtime/bunfig",
    "formats": ["markdown", "links"],
    "onlyMainContent": true
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.scrape({
  url: "https://bun.com/docs/runtime/bunfig",
  formats: ["markdown", "links"],
  onlyMainContent: true,
});
console.log(data.metadata.title);
console.log(data.markdown);
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.scrape(
    url="https://bun.com/docs/runtime/bunfig",
    formats=["markdown", "links"],
    only_main_content=True,
)["data"]
print(data["metadata"]["title"])
print(data["markdown"])
```
</CodeGroup>

You can try Scrape without an API key, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits).

## Read the response

Look in `data` for the formats you asked for. Here, `markdown` holds the page text and `links` lists addresses from the whole page.

```json
{
  "success": true,
  "data": {
    "markdown": "# bunfig.toml\n\nConfigure Bun's behavior using its configuration file bunfig.toml\n\n…",
    "links": [
      "https://bun.com/docs/runtime/bunfig",
      "https://bun.com/",
      "https://bun.com/docs"
    ],
    "metadata": {
      "title": "bunfig.toml | Bun Docs",
      "costUsd": 0.001
    }
  }
}
```

`metadata` describes the page whatever formats you ask for: its title, description, language, status code and social tags. See [Page metadata](/scrape/page-metadata). `metadata.costUsd` is what the call cost, and `metadata.scrapeId` names this read. To read the same result again within 24 hours, send `GET /v1/scrape/{id}` with the `scrapeId`. The `X-Request-ID` header holds the request id to give support. See [Freshness and caching](/scrape/freshness-and-caching).

## Formats

Pick a format based on what you will do with the page. Use Markdown for text, or a schema if your code needs named fields.

| Format | What you get | Guide |
| - | - | - |
| `markdown` | The page text as markdown | [Markdown](/scrape/markdown) |
| `html`, `rawHtml` | The cleaned page, or the page as sent | [HTML](/scrape/html) |
| `screenshot` | A link to a JPEG of the page, kept for 7 days | [Screenshot](/scrape/screenshot) |
| `links` | Every link on the page | [Links](/scrape/links) |
| `images` | Every image URL on the page | [Images](/scrape/images) |
| `rawBase64` | The bytes the site sent, Base64 encoded | [Bytes](/scrape/bytes) |
| `json` with `parser` | A site's own data, like a video, a listing or a profile | [Pre-built parsers](/scrape/prebuilt-parsers) |
| `summary` | A short summary of the page | [Summary](/scrape/summary) |
| `highlights` | The passages that best match a query | [Highlights](/scrape/highlights) |
| `question` | The answer to one question. Left out, with a warning, when the page does not state one | [Question](/scrape/question) |
| `json` with `schema` or `prompt` | An object in the shape you describe | [JSON](/scrape/json) |
| `product`, `menu` | A product with its variants, or a menu with prices | [Product](/scrape/product) |
| `branding` | The page's colors, fonts, logo and styles | [Branding](/scrape/branding) |
| `changeTracking` | What changed since you last read the page | [Change tracking](/scrape/change-tracking) |
| `network` | The JSON the page loaded while it rendered | [Network](/scrape/network) |

## Shape the page visit

Change how we read the page when the default response leaves out what you need. Use [browser actions](/scrape/browser-actions) for a click before the read, or [Interact](/scrape/interact) if you want to decide the next step after seeing the result. Use [waiting and rendering](/scrape/waiting-and-rendering) for a page that loads late.

Use [content filtering](/scrape/content-filtering) to keep only part of a page. Set [location and headers](/scrape/location-and-headers) when the site shows different content by country or language. Send a [PDF or document URL](/scrape/pdfs-and-documents) to read its text.

Set [freshness and caching](/scrape/freshness-and-caching) if a stored copy is too old. Use [safety options](/scrape/safety) to scan for prompt injection or hide personal data. See [timeouts and errors](/scrape/timeouts-and-errors) when a read fails, and the [API reference](/api-reference/endpoint/scrape) for every field.

## Price

$1 per 1,000 pages. A page that comes back with a 404 or 410 status, or cannot be read, costs nothing. `json` with a schema or a prompt, `summary`, `highlights`, `question`, `product`, `menu` and `changeTracking` in `json` mode each add $3 per 1,000 pages when they return something. Browser actions and CSS rules add nothing. See [Pricing](/account/pricing).

## Choose another API

Use a different call when you do not have a single page URL or need to read pages in bulk.

- [Map](/map/overview) lists the pages of a site without reading them.
- [Crawl](/crawl/overview) reads every page of a site in the background.
- [Batches](/batches/overview) read a list of URLs in the background.
- [Search](/search/overview) finds pages from a query and can read each result.
- [Extract](/extract/overview) pulls the fields you name from one or more pages, each checked against the page.
- [Parse documents](/parse/overview) turns a file you upload into Markdown.
