Scrape reads one URL and returns the formats you ask for. Without `formats` you get Markdown.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com/docs/runtime/bunfig",
    "formats": ["markdown", "links"],
    "onlyMainContent": true
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.scrape({
  url: "https://bun.com/docs/runtime/bunfig",
  formats: ["markdown", "links"],
  onlyMainContent: true,
});
console.log(data.metadata.title);
console.log(data.markdown);
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.scrape(
    url="https://bun.com/docs/runtime/bunfig",
    formats=["markdown", "links"],
    only_main_content=True,
)["data"]
print(data["metadata"]["title"])
print(data["markdown"])
```
</CodeGroup>

Scrape also works without a key, within the keyless limits in [Rate limits](/production/rate-limits). Fields marked "key" below need one.

```json
{
  "success": true,
  "data": {
    "markdown": "# bunfig.toml\n\nConfigure Bun's behavior using its configuration file bunfig.toml\n\n…",
    "links": ["https://bun.com/docs/runtime/bunfig", "https://bun.com/"],
    "metadata": { "title": "bunfig.toml | Bun Docs", "costUsd": 0.001 }
  }
}
```

`data` holds one field per format. `data.metadata` comes with every format: see [Page metadata](/scrape/page-metadata). Send `GET /v1/scrape/{id}` with `metadata.scrapeId` to read a result again for 24 hours. See [Freshness and caching](/scrape/freshness-and-caching).

## Formats

Send `formats` as 1 to 20 entries. Each is a string, or an object when the format has fields, such as `{ "type": "highlights", "query": "refund policy" }`.

| Format | What you get | Page |
| - | - | - |
| `markdown` (default) | The page text | [Formats](/scrape/formats) |
| `html`, `rawHtml` | The cleaned page, or the page as sent | [Formats](/scrape/formats) |
| `links`, `images` | Every link or image URL on the page | [Formats](/scrape/formats) |
| `rawBase64` | The bytes the site sent, Base64 encoded | [Formats](/scrape/formats) |
| `screenshot` | A link to a JPEG of the page | [Formats](/scrape/formats) |
| `network` | The JSON the page loaded while it rendered | [Formats](/scrape/formats) |
| `branding` | Colors, fonts, logo and styles | [Formats](/scrape/formats) |
| `audio`, `video` (key) | A YouTube video's audio or video file | [Formats](/scrape/formats) |
| `summary` (model) | A short summary | [Summary, highlights and question](/scrape/summary) |
| `highlights` | The passages that best match a query | [Summary, highlights and question](/scrape/summary) |
| `question` (model) | One answer from the page | [Summary, highlights and question](/scrape/summary) |
| `json` with `schema` or `prompt` (key, model) | An object in the shape you describe | [JSON](/scrape/json) |
| `json` with `rules`, `attributes` | CSS rules or attribute values, no model | [JSON](/scrape/json) |
| `product`, `menu` (model) | A product with variants, or a menu with prices | [JSON](/scrape/json) |
| `json` with `parser` | A site's own data | [Pre-built parsers](/scrape/prebuilt-parsers) |
| `changeTracking` (key) | What changed since your last read | [Change tracking](/scrape/change-tracking) |

Formats marked "model" can add a fee. See [Pricing](/account/pricing).

## Options

All fields sit next to `url`, except the ones inside a format.

| Field | What it does | Page |
| - | - | - |
| `onlyMainContent`, `onlyCleanContent` (key), `includeTags`, `excludeTags`, `removeBase64Images` | Choose which part of the page is read | [Content filtering](/scrape/content-filtering) |
| `linkStyle`, `maxChars`, `offset`, `query` | Shape and page through the Markdown | [Content filtering](/scrape/content-filtering) |
| `waitFor` (key), `mobile`, `fastMode`, `blockAds`, `proxy`, `profile` (key) | Choose how the page loads | [Rendering and location](/scrape/rendering-and-location) |
| `location`, `headers`, `skipTlsVerification` | Choose what the site shows you | [Rendering and location](/scrape/rendering-and-location) |
| `actions` (key) | Click, scroll, type or capture before the read | [Browser actions](/scrape/browser-actions) |
| `parsers` | PDF modes and layout | [PDFs and documents](/scrape/pdfs-and-documents) |
| `maxAge`, `minAge`, `lockdown`, `storeInCache` | Accept or refuse stored copies | [Freshness and caching](/scrape/freshness-and-caching) |
| `checkPromptInjection` (key), `redactPII` (key) | Scan or clean text before a model reads it | [Safety](/scrape/safety) |
| `zeroDataRetention` | Keep nothing from the call | [Zero data retention](/production/zero-data-retention) |
| `timeout` | Milliseconds to keep trying. Default `60000`, 1,000 to 300,000 | Below |

To keep working on a scraped page, see [Interact](/scrape/interact). The [API reference](/api-reference/endpoint/scrape) has every field.

## Timeouts, warnings and errors

- A read that runs out of time fails with `504 sourceTimeout` and costs nothing. A page that needs a browser needs at least 5 seconds. Waits and actions use the same time, so set your client timeout a few seconds above `timeout`. See [Timeouts](/production/timeouts).
- A page that answers 404 or 410 comes back as a page with that `metadata.statusCode` and an `error`. It costs nothing.
- `403 siteNotRead` means Stophy does not read that site as a page. Use a [parser](/scrape/prebuilt-parsers) or [Search](/search/overview).
- A body with `urls` returns `400 invalidRequest`. Read many pages with [Batches](/batches/overview).
- A problem that does not fail the call adds a `warning`. It says that a browser action failed, that `maxChars` cut the text (with the `offset` to read on from), or that `onlyCleanContent` or `checkPromptInjection` did not finish.
- A page over 8 MB of text, or a file over 20 MB, returns `400 invalidRequest`.

Every error has the shape in [Errors](/api-reference/errors). Retries are in [Troubleshooting](/production/troubleshooting).
