Every Scrape response has a `data.metadata` object, whatever you list in `formats`. It describes the page itself: its title, description, language, social preview tags, status code, and what the call cost. A field is left out when the page does not have it, so check that a field is there before you use it.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request reads a docs page. It asks for `markdown` so the response has something besides `metadata`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/404",
    "formats": ["markdown"]
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/404",
    formats: ["markdown"],
  }),
});
const { data } = await response.json();
console.log(data.metadata.title);
console.log(data.metadata.ogImage);
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/404",
        "formats": ["markdown"],
    },
)
metadata = response.json()["data"]["metadata"]
print(metadata["title"])
print(metadata.get("ogImage"))
```

The same tag can appear twice: once under a plain name such as `ogTitle`, and once under the tag's own name such as `og:title`. Use the plain names when they exist.

## Fields

| Field | Type | What it holds |
| - | - | - |
| `title` | `string` | The page title. |
| `description` | `string` | The page description. |
| `language` | `string` | The page language, such as `en-US`. |
| `ogImage` | `string` | The preview image the page names. |
| `favicon` | `string` | The page icon. |
| `sourceURL` | `string` | The URL you sent. |
| `url` | `string` | The URL the page ended up at after redirects. |
| `statusCode` | `number` | The HTTP status the page answered with. |
| `contentType` | `string` | What the page is, such as `text/html`, `application/pdf` or `text/csv`. |
| `cacheState` | `string` | `hit`, `miss` or `stale`. See [Freshness and caching](/scrape/freshness-and-caching). |
| `cachedAt` | `string` | When the stored copy was made. Only on `hit` and `stale`. |
| `scrapeId` | `string` | The id of this read. Use it with `GET /v1/scrape/{id}`. |
| `costUsd` | `number` | What the call cost, in dollars. |
| `creditsUsed` | `number` | The same charge as a whole number, one for each $0.002. Read `costUsd` instead. |
| `numPages`, `totalPages`, `ocrPages` | `number` | For a PDF: the pages read, the pages in the file, and the pages read from their picture. See [PDFs and documents](/scrape/pdfs-and-documents). |
| `error` | `string` | Set when the page answered with a status of 400 or more, such as `The page answered with status 403.` |
| `keywords`, `robots`, `publishedTime`, `modifiedTime`, `articleSection`, `articleTag` | `string` or `array of string` | From the page's `keywords`, `robots` and `article:*` tags. |
| `ogTitle`, `ogDescription`, `ogUrl`, `ogLocale`, `ogLocaleAlternate`, `ogSiteName`, `ogVideo`, `ogAudio`, `ogDeterminer` | `string` or `array of string` | From the page's Open Graph tags. |
| `dcDate`, `dcDateCreated`, `dcDescription`, `dcSubject`, `dcType`, `dcTermsCreated`, `dcTermsKeywords`, `dcTermsSubject`, `dcTermsType`, `dcTermsAudience` | `string` or `array of string` | From the page's Dublin Core tags. |

Every other meta tag on the page also comes back under its own name, such as `twitter:card` or `viewport`. A tag that appears several times comes back as an array of strings.

## Limits and errors

- `metadata` is always an object. A page with no meta tags still has `sourceURL`, `url`, `statusCode`, `contentType` and `cacheState`.
- A YouTube link has no meta tags to read. Its `title`, `description` and `ogImage` come from the video. See [YouTube](/scrape/youtube).
- A page that answers with a 404 or 410 status comes back with that `statusCode` and an `error`, and costs nothing. See [Timeouts and errors](/scrape/timeouts-and-errors).
