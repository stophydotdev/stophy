Use `rawBase64` to save the file a site sent without converting it to text. For HTML you want to read as text, use [HTML](/scrape/html) instead.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request returns the bytes of a small page.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "formats": ["rawBase64"]
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://example.com",
    formats: ["rawBase64"],
  }),
});
const { data } = await response.json();
console.log(data.metadata.contentType);
console.log(Buffer.from(data.rawBase64, "base64").toString("utf8"));
```
```python Python
import base64
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://example.com",
        "formats": ["rawBase64"],
    },
)
data = response.json()["data"]
print(data["metadata"]["contentType"])
print(base64.b64decode(data["rawBase64"]).decode("utf-8"))
```
</CodeGroup>

## Read the response

Decode `data.rawBase64` before you write it to a file. It is a Base64 string without a `data:` prefix. `data.metadata.contentType` says what the bytes are. This real response is cut. The full string was 3,164 characters and decodes to the page's HTML, starting with `<!DOCTYPE html>`.

```json
{
  "success": true,
  "data": {
    "rawBase64": "PCFET0NUWVBFIGh0bWw+PGh0bWwgbGFuZz0iZW4iPjxoZWFkPjxtZXRhIGNoYXJzZXQ9InV0Zi04Ij48…",
    "metadata": {
      "contentType": "text/html",
      "costUsd": 0.001
    }
  }
}
```

## Options

Choose this format instead of the default Markdown when you need bytes.

| Field | Type | Default | Effect |
| - | - | - | - |
| `formats` | `array` | `["markdown"]` | Add `"rawBase64"` to return the bytes the site sent. |

## Limits and errors

Plan for a live read even if you recently requested the same URL.

- The page is always read live. Stophy never answers `rawBase64` from a stored copy, whatever `maxAge` says.
- A page that answers with a 404 or 410 status, or cannot be read, costs nothing.

## Price

$1 per 1,000 pages. `rawBase64` adds nothing to the price of the page.
