`highlights` returns the passages of a page that best match a query. Use it to give a model only the part of a long page that matters.

## Make a request

Get an API key in the [Quickstart](/quickstart). Send `highlights` as an object with your query. This request asks for the three best passages.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com/docs/runtime/bunfig",
    "formats": [
      {
        "type": "highlights",
        "query": "global config file location",
        "count": 3
      }
    ]
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.scrape({
  url: "https://bun.com/docs/runtime/bunfig",
  formats: [
    {
      type: "highlights",
      query: "global config file location",
      count: 3,
    },
  ],
});
console.log(data.highlights);
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.scrape(
    url="https://bun.com/docs/runtime/bunfig",
    formats=[
        {
            "type": "highlights",
            "query": "global config file location",
            "count": 3,
        },
    ],
)["data"]
print(data["highlights"])
```
</CodeGroup>

## Read the response

`data.highlights` is one string. The passages are separated by a blank line, and a table row keeps its header.


## Options

| Field | Type | Default | Effect |
| - | - | - | - |
| `type` | `string` | none | `"highlights"`. Required. |
| `query` | `string` | none | What you are looking for, such as `refund policy`. Required, 1 to 10,000 characters. |
| `count` | `number` | `5` | How many passages to return, best match first. From 1 to 20. |

The top-level `query` field of the request is a different option. It shortens the Markdown of a long page. See [Content filtering](/scrape/content-filtering).

## Limits and errors

- A page with no matching text returns an empty string, `""`, and costs only the page.
- Highlights are chosen from the page's Markdown after content filtering. With `redactPII`, they come from the redacted text.
- A call without `query` returns `400 invalidRequest`.

## Price

$4 per 1,000 pages: $1 for the page and $3 for highlights. When nothing matches, the $3 is not charged.
