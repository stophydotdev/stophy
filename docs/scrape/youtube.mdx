Send a YouTube video link to Scrape and `markdown` returns a short document about the video: its title, channel, publish date, length, views, likes and description. Add `audio` or `video` to also get the file.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request reads a video and asks for its audio.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
    "formats": ["markdown", "audio"]
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
    formats: ["markdown", "audio"],
  }),
});
const { data } = await response.json();
console.log(data.markdown);
console.log(data.audio);
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
        "formats": ["markdown", "audio"],
    },
)
data = response.json()["data"]
print(data["markdown"])
print(data["audio"])
```

## Options

| Format | What you get |
| - | - |
| `markdown` | The video document: title, channel, publish date, length, views, likes and description. |
| `summary`, `json` | A summary or fields in your own shape, made from that document. See [Summary](/scrape/summary) and [JSON](/scrape/json). |
| `audio` | A link to the audio as an M4A file, in the best quality available. The link works for 1 hour. |
| `video` | A link to the video as an MP4 file with sound, in the best single-file quality available. The link works for 1 hour. |

Supported links are `watch?v=`, `youtu.be/`, `/shorts/`, `/embed/` and `/live/` URLs, on `youtube.com`, `www.youtube.com`, `m.youtube.com` and `music.youtube.com`.

## More from a video

A scrape returns the document above, not the transcript, the comments or the channel. For those, use the YouTube parsers, which return a video's transcript, comments, channel, playlist and search results as data. See [Pre-built parsers](/scrape/prebuilt-parsers).

## Limits and errors

- `audio` and `video` need an API key. Without one, the call returns `401 apiKeyRequired`.
- `audio` and `video` work only for a YouTube video link. Any other URL returns `400 invalidRequest` with a message that starts `formats: audio and video are available for YouTube video links`.
- An audio file larger than 40 MB, or a video file larger than 100 MB, returns `400 invalidRequest` and says what to send instead.
- `audio` and `video` with `zeroDataRetention` return `400 invalidRequest`, because the file is kept for an hour.
- If YouTube does not provide a video's file, the call fails with `503 sourceUnavailable`. Nothing is charged, and you can retry.

## Price

$1 per 1,000 videos. `audio` and `video` add nothing to the price.
