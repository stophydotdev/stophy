Use `network` to read the JSON a page loads instead of pulling fields from the rendered HTML.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request reads a package page and collects the JSON responses it loads.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.npmjs.com/package/zod",
    "formats": ["network"]
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.npmjs.com/package/zod",
    formats: ["network"],
  }),
});
const { data } = await response.json();
for (const call of data.network) {
  console.log(call.method, call.status, call.url);
}
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://www.npmjs.com/package/zod",
        "formats": ["network"],
    },
)
data = response.json()["data"]
for call in data["network"]:
    print(call["method"], call["status"], call["url"])
```
</CodeGroup>

## Read the response

Read `data.network` in the order responses arrived. Look at each `url` and `status` to find the call you need. Parse its `body` as JSON. The body below is shortened.

```json
{
  "success": true,
  "data": {
    "network": [
      {
        "url": "https://www.npmjs.com/package/zod/v/4.6.7/provenance",
        "method": "GET",
        "status": 200,
        "contentType": "application/json",
        "body": "{\"summary\":{\"subjectAlternativeName\":\"https://github.com/colinhacks/zod/.github/workflows/…"
      }
    ]
  }
}
```

| Field | What it holds |
| - | - |
| `url` | The URL that was called, with its query string. |
| `method` | `GET`, `POST` and so on. |
| `status` | The status code of the response. |
| `contentType` | The content type of the response. |
| `body` | The response body, as a string. Parse it as JSON. |

## Options

Ask for `network` when you need request results, and add other formats only if you need them.

| Field | Type | Default | Effect |
| - | - | - | - |
| `formats` | `array` | `["markdown"]` | Add `"network"` to return the JSON the page loaded. |

Use `waitFor` or [browser actions](/scrape/browser-actions) when the data loads after a click or a delay.

## Limits and errors

Check whether the page loaded JSON and whether any responses were too large to return.

- Only `fetch` and `XMLHttpRequest` responses with a JSON content type are kept. Images, scripts and styles are not.
- At most 30 responses are returned. A body larger than 256 KB is left out, and the bodies together are capped at 2 MB. `data.networkDropped` counts the responses left out. It is left out when no response was dropped.
- A page that loads no JSON returns no entries.
- The page is read in a browser and never from a stored copy.

## Price

$1 per 1,000 pages, the same as any page. `network` adds nothing.
