Use `images` to get URLs you can download or inspect. To see the pictures in the layout of the page, ask for a [screenshot](/scrape/screenshot).

## Make a request

Get an API key in the [Quickstart](/quickstart). This request lists the images of a home page.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com",
    "formats": ["images"]
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.scrape({
  url: "https://bun.com",
  formats: ["images"],
});
console.log(data.images);
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.scrape(
    url="https://bun.com",
    formats=["images"],
)["data"]
print(data["images"])
```
</CodeGroup>

## Read the response

Read `data.images` for the absolute URLs. The response lists the addresses, not the image files.

```json
{
  "success": true,
  "data": {
    "images": [
      "https://bun.com/logo.svg",
      "https://bun.com/bun-homepage-cc-boris-poster.webp",
      "https://bun.com/bun-homepage-midjourney-cheng-poster.webp"
    ],
    "metadata": {
      "costUsd": 0.001
    }
  }
}
```

Each URL comes from the `src` of an `img` tag on the whole page. Relative URLs are made absolute, each URL appears once, and only `http` and `https` URLs are kept. The list leaves out images set in CSS and images that carry their data in the URL (`data:image`). A page with no images returns an empty array.

## Options

Add `images` to `formats` to get URLs alongside any other format you need.

| Field | Type | Default | Effect |
| - | - | - | - |
| `formats` | `array` | `["markdown"]` | Add `"images"` to return every image URL on the page. |

## Limits and errors

Use this format on web pages. It does not extract pictures from PDF files.

- A PDF comes back as Markdown only. Asking for `images` on a PDF returns `400 invalidRequest`.
- A page that answers with a 404 or 410 status, or cannot be read, costs nothing.

## Price

$1 per 1,000 pages. `images` adds nothing to the price of the page.
