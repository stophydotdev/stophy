Use `links` to collect the links on one page as absolute URLs in page order. Use [Map](/map/overview) instead to list pages across a site.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request lists the links of a small page.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.iana.org/help/example-domains",
    "formats": ["links"]
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.scrape({
  url: "https://www.iana.org/help/example-domains",
  formats: ["links"],
});
console.log(data.links?.length);
console.log(data.links?.slice(0, 5));
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.scrape(
    url="https://www.iana.org/help/example-domains",
    formats=["links"],
)["data"]
print(len(data["links"]))
print(data["links"][:5])
```
</CodeGroup>

## Read the response

Read `data.links` as an array of URLs. This request found 26 links. Here are the first four.

```json
{
  "success": true,
  "data": {
    "links": [
      "https://www.iana.org/",
      "https://www.iana.org/domains",
      "https://www.iana.org/protocols",
      "https://www.iana.org/numbers"
    ],
    "metadata": {
      "costUsd": 0.001
    }
  }
}
```

Links come from the whole page, so the list includes menus, headers and footers even when `onlyMainContent` is `true`. Links inside the Markdown follow `linkStyle` instead. See [Content filtering](/scrape/content-filtering).

## Options

Ask for `links` when you need a separate list, even if you leave URLs out of the Markdown.

| Field | Type | Default | Effect |
| - | - | - | - |
| `formats` | `array` | `["markdown"]` | Add `"links"` to return every link on the page. |

## Limits and errors

Use this format on web pages, not PDF files.

- A PDF comes back as Markdown only. Asking for `links` on a PDF returns `400 invalidRequest`.
- A page that answers with a 404 or 410 status, or cannot be read, costs nothing.

## Price

$1 per 1,000 pages. `links` adds nothing to the price of the page.
