Use these settings before you pass scraped text to a model. `checkPromptInjection` scans the text for instructions aimed at a model. `redactPII` hides personal data. Both need an API key. Set `lockdown` if the request must never reach the site.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request scans a page for prompt injection and hides names, emails and phone numbers in the text.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.w3.org/People/Berners-Lee/",
    "checkPromptInjection": true,
    "redactPII": { "entities": ["PERSON", "EMAIL", "PHONE"], "replaceStyle": "tag" },
    "maxChars": 900
  }'
```

## Prompt injection

Set `"checkPromptInjection": true` before passing scraped text to a model. It scans the page text for instructions aimed at an AI model before anything is built from it. A page that has them is refused with `403 promptInjectionDetected`, and the message quotes the text as evidence. Nothing is returned and nothing is charged. Send `checkPromptInjection` as `false` to read that page anyway.

The scan reads the first 150,000 characters of the page. A longer page, or one the scan cannot finish, comes back with a `warning` that it was not fully checked, and the scan is not charged.

## Redact personal data

`redactPII` hides personal data in the Markdown and in everything made from it: `summary`, `question`, `highlights` and `json`. Links, `html` and `rawHtml` are not changed. Send `true` for the defaults, or an object. For example, use `"redactPII": { "entities": ["PERSON", "EMAIL"], "replaceStyle": "tag" }` to replace names and email addresses with tags such as `<PERSON>` and `<EMAIL>` in `data.markdown`.

## Read only what is stored

`lockdown: true` answers only from a stored copy of the page, of any age, and never reads it live. Use it when nothing must reach the site. A page with no stored copy returns `404 notFound`.

The error says we have no stored copy and suggests removing `minAge` or `lockdown` to read live. Leave the setting on if the request must not reach the site.

On a page that is stored, the same call returns the page with `cacheState` `hit` and costs $0.001.

## Options

Choose which checks to run and what to replace in the returned text.

| Field | Type | Default | Effect |
| - | - | - | - |
| `checkPromptInjection` | `boolean` | `false` | Scan the page text for instructions aimed at an AI model. Needs an API key. |
| `redactPII` | `boolean` or `object` | `false` | Hide personal data. `true` uses the defaults below. Needs an API key. |
| `redactPII.mode` | `string` | `"accurate"` | `accurate` finds names and places with a model and the rest by pattern. `aggressive` adds guesses that catch more and may hide a little too much. `fast` uses patterns only, so it finds no ordinary names or places. |
| `redactPII.entities` | `array of string` | all six | What to hide: `PERSON`, `EMAIL`, `PHONE`, `LOCATION`, `FINANCIAL`, `SECRET`. |
| `redactPII.replaceStyle` | `string` | `"tag"` | `tag` writes `<EMAIL>`, `mask` writes `*` for each character, and `remove` deletes the text. |
| `lockdown` | `boolean` | `false` | Answer only from a stored copy and never read live. The same as `minAge: 0`. |

## Limits and errors

An incomplete injection scan and a failed redaction have different outcomes. Check the warning or error before using the result.

- A page the model cannot scan is refused, not returned unredacted. This happens for `PERSON` and `LOCATION` on a page longer than 300,000 characters. The call returns `400 invalidRequest`, and nothing is charged. Use `mode: "fast"`, or leave those two out of `entities`.
- `checkPromptInjection`, `redactPII` and `onlyCleanContent` without an API key return `401 apiKeyRequired`.
- `lockdown` on a page with no stored copy returns `404 notFound`.

## Price

`checkPromptInjection` adds $2.50 per 1,000 pages when the scan runs. `redactPII` and `lockdown` add nothing. The page itself is $1 per 1,000 pages. A page that is refused as injected, and a page that cannot be read, cost nothing.
