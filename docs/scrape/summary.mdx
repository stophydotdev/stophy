Use `summary` to get the main points of a page without returning all its text. For a specific question, use [Question](/scrape/question).

## Make a request

Get an API key in the [Quickstart](/quickstart). This request summarizes a documentation page.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com/docs/runtime/bunfig",
    "formats": ["summary"]
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.scrape({
  url: "https://bun.com/docs/runtime/bunfig",
  formats: ["summary"],
});
console.log(data.summary);
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.scrape(
    url="https://bun.com/docs/runtime/bunfig",
    formats=["summary"],
)["data"]
print(data["summary"])
```
</CodeGroup>

## Read the response

Read `data.summary` as a string. Check `data.metadata.costUsd` for the price of the page and the summary together.

```json
{
  "success": true,
  "data": {
    "summary": "bunfig.toml is Bun's optional configuration file for Bun-specific settings, placed in the project root, with a global version also readable by package manager commands. …",
    "metadata": {
      "costUsd": 0.004
    }
  }
}
```

## Options

Ask for `summary` alone, or add `markdown` if you also need the source text.

| Field | Type | Default | Effect |
| - | - | - | - |
| `formats` | `array` | `["markdown"]` | Add `"summary"` to return a short summary of the page. |

`onlyMainContent`, `onlyCleanContent`, `includeTags` and `excludeTags` decide which text is summarized. See [Content filtering](/scrape/content-filtering). With `redactPII`, the summary is made from the redacted text. See [Safety](/scrape/safety).

## Limits and errors

A summary of a long page covers its beginning, not what comes after the character limit.

- The summary is made from the first 50,000 characters of the page's Markdown. A longer page is summarized from its start.
- When no summary can be made, the call returns `503 sourceUnavailable` and costs nothing. Try again after a few seconds.
- A PDF can be summarized.

## Price

$4 per 1,000 pages: $1 for the page and $3 for the summary. If you ask for `markdown` too, it adds nothing.
