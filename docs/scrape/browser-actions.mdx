`actions` runs steps on the page, in order, before Scrape reads it. Use them to load more results, open a tab, fill a search box, or capture a screenshot at the right moment. Actions need an API key.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request scrolls a news front page, clicks its "More" link, waits a second, takes a screenshot, and then reads the page it ends on.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://news.ycombinator.com",
    "formats": ["markdown", "links"],
    "actions": [
      { "type": "scroll", "direction": "down", "amount": "viewport" },
      { "type": "click", "selector": "a.morelink" },
      { "type": "wait", "milliseconds": 1000 },
      { "type": "screenshot" }
    ]
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.scrape({
  url: "https://news.ycombinator.com",
  formats: ["markdown", "links"],
  actions: [
    { type: "scroll", direction: "down", amount: "viewport" },
    { type: "click", selector: "a.morelink" },
    { type: "wait", milliseconds: 1000 },
    { type: "screenshot" },
  ],
});
console.log(data.metadata.url);
console.log(data.actions?.screenshots?.[0]);
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.scrape(
    url="https://news.ycombinator.com",
    formats=["markdown", "links"],
    actions=[
        {"type": "scroll", "direction": "down", "amount": "viewport"},
        {"type": "click", "selector": "a.morelink"},
        {"type": "wait", "milliseconds": 1000},
        {"type": "screenshot"},
    ],
)["data"]
print(data["metadata"]["url"])
print(data["actions"]["screenshots"][0])
```
</CodeGroup>

## Action types

| Type | Fields | What it does |
| - | - | - |
| `wait` | `milliseconds`: 1 to 60,000 | Pauses. |
| `wait` | `selector`: a CSS selector | Waits until an element matching the selector appears, for up to 30 seconds. |
| `click` | `selector`: a CSS selector | Clicks the first match. It looks for the element for up to 5 seconds. `all` is accepted only as `false`. |
| `write` | `text`: the text to type | Types the text. |
| `press` | `key`: up to 40 characters, such as `Enter` | Presses a key. |
| `scroll` | `direction`: `down` (default), `up`, `left` or `right`. `amount`: pixels from 1 to 100,000, `"viewport"` or `"max"`. `maxScrolls`: 1 to 50. `selector`: an inner scroll container. | Scrolls. `"max"` keeps scrolling until the page stops growing, for feeds that load as you go. |
| `screenshot` | `fullPage`: boolean. `quality`: 1 to 100. `viewport`: `{ width, height }`, 200 to 3,840 by 200 to 2,160. | Takes a JPEG. The link comes back in `actions.screenshots`. |
| `scrape` | none | Captures the page at this point. The URL and HTML come back in `actions.scrapes`. |
| `executeJavascript` | `script`: up to 20,000 characters | Runs the script on the page for up to 5 seconds. What it returns comes back in `actions.javascriptReturns` as `{ type, value }`. |
| `pdf` | `format`: `Letter`, `Legal`, `Tabloid`, `Ledger` or `A0` to `A6`. `landscape`: boolean. `scale`: 0.1 to 2. | Prints the page to a PDF. The link comes back in `actions.pdfs`. |
| `perform` | `action`: a step in plain words, 1 to 500 characters | A step such as `Click the Load more button`. It can take up to 5 browser steps on the page, up to 30 seconds, and never leaves the site. |

Captures come back in the order the steps ran.

## A failed action

When a step fails, you still get the page as it stood, and the actions after the failed one do not run. The response has a `warning` that names the step and says why. The call is still billed as one page. This request body clicks a button that does not exist.

```json
{
  "url": "https://example.com",
  "actions": [
    { "type": "click", "selector": "button.does-not-exist" }
  ]
}
```

```json
{
  "success": true,
  "data": {
    "markdown": "This domain is for use in documentation examples without needing permission. …",
    "warning": "PageAction 1 (click) failed: nothing matched button.does-not-exist. This is the page as it stood before that action, and the actions after it did not run.",
    "metadata": {
      "title": "Example Domain",
      "sourceURL": "https://example.com/",
      "url": "https://example.com/",
      "statusCode": 200,
      "cacheState": "miss",
      "costUsd": 0.001
    }
  }
}
```

Always read `warning` when you send actions. To work out which selector to use, open the page in a [browser session](/scrape/interact) and try it there.

## Options

| Field | Type | Default | Effect |
| - | - | - | - |
| `actions` | `array of object` | none | 1 to 50 steps, run in order before the page is read. At most 5 can be `perform`. |

## Limits and errors

- Actions need an API key. Without one, the call returns `401 apiKeyRequired`.
- A step that does not fit the table returns `400 invalidRequest` and names the step.
- With `zeroDataRetention`, `screenshot` and `pdf` steps return `400 invalidRequest`, because they are kept as files.
- A read with actions is always live. It is never answered from a stored copy.
- Waits count toward the call's `timeout`. See [Timeouts and errors](/scrape/timeouts-and-errors).

## Price

$1 per 1,000 pages. The actions add nothing, and neither do their screenshots, captures and PDFs.
