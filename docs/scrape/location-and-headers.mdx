Set `location` if the site shows different pages by country or language. Use `headers` when the site needs an extra header. These fields change what the site shows you, so a read that uses `headers`, `location.languages` or `skipTlsVerification` is always live.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request reads a page that echoes the headers it received, from Germany, with German as the first language choice and one custom header.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://httpbin.org/headers",
    "location": { "country": "DE", "languages": ["de-DE", "en"] },
    "headers": { "x-plan": "pro" }
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://httpbin.org/headers",
    location: { country: "DE", languages: ["de-DE", "en"] },
    headers: { "x-plan": "pro" },
  }),
});
const { data } = await response.json();
console.log(data.markdown);
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://httpbin.org/headers",
        "location": {"country": "DE", "languages": ["de-DE", "en"]},
        "headers": {"x-plan": "pro"},
    },
)
print(response.json()["data"]["markdown"])
```

## Read the response

Check the echoed headers in `data.markdown`. The language list went out as `Accept-Language`, with German first. `X-Plan` has the custom value you sent.

```json
{
  "success": true,
  "data": {
    "markdown": "{\n  \"headers\": {\n    \"Accept-Language\": \"de-DE,en;q=0.9\",\n    …\n    \"X-Plan\": \"pro\"\n  }\n}",
    "metadata": {
      "cacheState": "miss",
      "costUsd": 0.001
    }
  }
}
```

## Options

Change the country when you need a regional version. Set languages separately if you want the site to prefer a particular language.

| Field | Type | Default | Effect |
| - | - | - | - |
| `location.country` | `string` | `"US"` | A two-letter country code such as `DE` or `JP`, in any case. `UK` is read as `GB`. The read starts from that country. |
| `location.languages` | `array of string` | none | 1 to 5 languages to ask the site for, best first, such as `["de", "en"]` or `["pt-BR"]`. Sent as `Accept-Language`. |
| `headers` | `object` | none | Extra request headers to send to the site, such as `{ "x-plan": "pro" }`. |
| `skipTlsVerification` | `boolean` | `false` | Read a page whose certificate is expired, self-signed or for another name. The read is not private against someone between Stophy and the site. |
| `proxy` | `string` | `"auto"` | How hard a read tries. `basic` makes one plain attempt. `enhanced` starts with the stronger read, and `stealth` means the same. `auto` starts plain and tries the stronger read once if the site refuses. Same price for each. |

## Headers

Use `headers` for the destination site, not for authenticating your request to us.

- Send at most 30 headers.
- A name uses letters, digits and `-`, up to 64 characters. A value is up to 2,000 printable characters with no line breaks.
- `Host`, `Content-Length`, `Connection`, `Transfer-Encoding`, `Upgrade`, `TE` and `Proxy-Authorization` are refused, because Stophy sets them itself.
- Your Stophy API key belongs in the `Authorization` header of your request to Stophy, not in `headers`.
- Send `Cookie` or `Authorization` only for a site you are allowed to read as that user.

## Limits and errors

An invalid country code or a header we set ourselves fails the request. A valid location does not guarantee different content.

- A country that is not a two-letter code returns `400 invalidRequest` with the message `country: Expected a two-letter country code such as DE`.
- The country is a request. A site can still show the same page to everyone.
- A read with `headers`, `location.languages` or `skipTlsVerification` is never answered from a stored copy and never saved as one. See [Freshness and caching](/scrape/freshness-and-caching).
- A refused header returns `400 invalidRequest` with the message `Stophy sets this header itself.`

## Price

$1 per 1,000 pages. A country, languages, headers and `skipTlsVerification` add nothing.
