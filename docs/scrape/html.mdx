`html` returns the cleaned page and `rawHtml` returns the page as the site sent it. Use `html` to keep the structure of the content, and `rawHtml` when you need every tag, script and style.

## Make a request

This request asks for both formats so you can compare them.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "formats": ["html", "rawHtml"]
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.scrape({
  url: "https://example.com",
  formats: ["html", "rawHtml"],
});
console.log(data.html);
console.log(data.rawHtml);
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.scrape(
    url="https://example.com",
    formats=["html", "rawHtml"],
)["data"]
print(data["html"])
print(data["rawHtml"])
```
</CodeGroup>

## Read the response

Each format is a string in `data`. This real response is cut after the first paragraph of each format.

```json
{
  "success": true,
  "data": {
    "html": "<!DOCTYPE html><html lang=\"en\"><body><p lang=\"en\">This domain is for use in documentation examples without needing permission. This is not a service; avoid relying on it for testing and monitoring purposes.</p>…</body></html>",
    "rawHtml": "<!DOCTYPE html><html lang=\"en\"><head><meta charset=\"utf-8\"><link rel=\"icon\" href=\"data:,\"><meta name=\"viewport\" content=\"width=device-width,initial-scale=1\"><title>Example Domain</title>…",
    "metadata": {

      "sourceURL": "https://example.com/",
      "url": "https://example.com/",

      "costUsd": 0.001

```

`html` has no `head` or styles, and by default only the main content of the page. `rawHtml` is the whole document.

## Options

| Field | Type | Default | Effect |
| - | - | - | - |
| `formats` | `array` | `["markdown"]` | Add `"html"` for the cleaned page and `"rawHtml"` for the page as sent. |
| `removeBase64Images` | `boolean` | `true` | Drops images that carry their data in the URL (`data:image`). Send `false` to keep them in `html`. |

`onlyMainContent`, `includeTags` and `excludeTags` are described in [Content filtering](/scrape/content-filtering).

## Limits and errors

- A PDF comes back as Markdown only. Asking for `html` on a PDF returns `400 invalidRequest` with the message `formats: a PDF comes back as markdown only. Ask for markdown.`
- A page that answers with a 404 or 410 status, or cannot be read, costs nothing.

## Price

$1 per 1,000 pages, whether you ask for `html`, `rawHtml` or both.
