Use the extract ID to read the fields we found. Reading is free, and results are available for 24 hours unless you used zero data retention.

## Read a result

Get an API key in the [Quickstart](/quickstart), and install the SDK with `npm install stophy` or `pip install stophy`. Use the `id` that [Extract](/extract/overview) returned.

<CodeGroup>
```bash cURL
curl https://api.stophy.dev/v1/extract/8ae7db78-aab6-43c1-872f-bdedfea0afd9 \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.extract.result({ id: "8ae7db78-aab6-43c1-872f-bdedfea0afd9" });
console.log(result.status, result.data);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.extract.result(id="8ae7db78-aab6-43c1-872f-bdedfea0afd9")
print(result["status"], result["data"])
```
</CodeGroup>

## Read the response

Check `status` before reading the fields in `data`. This result comes from the request on [Extract](/extract/overview).

```json
{
  "success": true,
  "status": "completed",
  "data": {
    "module": "bun:sqlite",
    "queryMethods": ["all", "get", "run", "values", "iterate"],
    "transactionModes": ["deferred", "immediate", "exclusive"]
  },
  "urls": ["https://bun.com/docs/runtime/sqlite"],
  "costUsd": 0.005,
  "expiresAt": "2026-11-18T18:09:35.938Z"
}
```

| Field | What it holds |
| - | - |
| `success` | `true`, or `false` when `status` is `failed`. The HTTP status is still `200`. |
| `status` | `completed`, or `failed` when the run ended without an answer. A failed result has an `error` and no `data`. |
| `data` | The fields that the pages state. A field they do not state is left out. |
| `confidence` | For each field in `data`, a number from 0 to 1 for how sure Stophy is that the value is on the page. |
| `urls` | The pages that were read. |
| `warning` | The pages that could not be read, and why, or a note that a page was cut. The fields come from the rest. |
| `sources` | With `showSources`, the pages behind each field. |
| `costUsd` | What the extract cost. |
| `expiresAt` | When the result is deleted. |

## Show sources

If you need to link each value to a page, send `"showSources": true` when you start the extract. `sources` maps each field to the URLs that state its value.

A field that is not in `data` is not in `sources`. The full request is on [Schema](/extract/schema).

## Set a timeout

Raise `timeout` if the pages you need are slow. For example, `"timeout": 60000` gives them 60 seconds. `timeout` is how long to keep reading the pages, in milliseconds, from 1,000 to 300,000. The default is 30,000 ms. A page that is not read by then is skipped, named in `warning`, and costs nothing. The call fails only when no page can be read.

After the pages are read, the answer takes up to 45 more seconds. Set your client timeout above `timeout` plus 45 seconds. `warning` reads like `Read 1 of 2 pages. Skipped <url>: <reason>`, and like `1 of 1 pages were longer than 50000 characters and were cut there.` when a page is long. With several pages, each page gets a smaller share, and all together are read up to 150,000 characters.

## Get a webhook

Use a webhook if you want to be notified when the extract ends instead of polling. Send `webhook` as a public address, or as an object with `url`. For example, send `"events": ["failed"]` in the object if you only want failures.

Stophy sends one JSON `POST` when the extract ends. It has the `id`, the `event` (`completed` or `failed`), an `eventId`, `success` (`false` for `failed`), the `status`, the `data`, `confidence`, `urls`, `warning`, `sources`, `costUsd` and your `metadata`. Each call is signed: `Stophy-Signature` holds `t=<unix seconds>,v1=<hex>`, where `v1` is the HMAC-SHA256 of `<t>.<body>` with your webhook secret. A call that gets no `2xx` answer is sent again, up to 3 times. See [Webhooks](/webhooks).

## Options

Set these when you start the extract.

| Field | Type | Default | Effect |
| - | - | - | - |
| `showSources` | `boolean` | `false` | Add `sources` to the result. |
| `timeout` | `number` | 30,000 ms | Milliseconds to read the pages, from 1,000 to 300,000. |
| `webhook` | `string` or `object` | none | Where to be told when the extract ends. An object takes `url`, `headers`, `metadata` and `events`. `events` is `completed`, `failed` or both, which is the default. |

## Limits and errors

Save results before they expire. If no page could be read, check the returned error before retrying.

- A result is kept for 24 hours. With `zeroDataRetention` it is kept for 1 hour. After that, `GET` returns `404 notFound` with `No extract with that id. Results are kept for 24 hours.`
- A call that cannot read any page fails with the error of the page, such as `sourceTimeout` or `siteNotRead`. A failed call costs nothing, and a failed extract can be read back with `status` of `failed` and `success` of `false`.
- Without an API key, `GET /v1/extract/{id}` returns `401 apiKeyRequired`. You can read only your own results.
- More than 25 `urls` returns `400 invalidRequest`. `urls` with no public page in them returns `400 invalidRequest` with `None of these is a public website URL.`
