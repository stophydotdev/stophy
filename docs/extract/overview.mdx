---
title: "Extract"
description: "Pull the fields you name from up to 25 pages as JSON. Each value is checked against the page text and left out when the page does not state it."
---

Extract reads pages you name and fills the fields of a JSON Schema. It answers with an `id`, and you read the fields with `GET /v1/extract/{id}`. It needs an API key. See the [Quickstart](/quickstart).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/extract \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": ["https://bun.com/docs/runtime/sqlite"],
    "schema": {
      "type": "object",
      "properties": {
        "module": { "type": "string", "description": "The import path of the SQLite driver" },
        "transactionModes": {
          "type": "array",
          "items": { "type": "string", "enum": ["deferred", "immediate", "exclusive"] }
        },
        "pricePerMonth": { "type": ["number", "null"] }
      }
    }
  }'
# then: curl https://api.stophy.dev/v1/extract/$ID -H "Authorization: Bearer $STOPHY_API_KEY"
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { id } = await stophy.extract({
  urls: ["https://bun.com/docs/runtime/sqlite"],
  schema: {
    type: "object",
    properties: {
      module: { type: "string", description: "The import path of the SQLite driver" },
      transactionModes: {
        type: "array",
        items: { type: "string", enum: ["deferred", "immediate", "exclusive"] },
      },
      pricePerMonth: { type: ["number", "null"] },
    },
  },
});
const result = await stophy.extract.result({ id: id! });
console.log(result.status, result.data);
```
```python Python
from stophy import Stophy

stophy = Stophy()

started = stophy.extract(
    urls=["https://bun.com/docs/runtime/sqlite"],
    schema={
        "type": "object",
        "properties": {
            "module": {"type": "string", "description": "The import path of the SQLite driver"},
            "transactionModes": {
                "type": "array",
                "items": {"type": "string", "enum": ["deferred", "immediate", "exclusive"]},
            },
            "pricePerMonth": {"type": ["number", "null"]},
        },
    },
)
result = stophy.extract.result(id=started["id"])
print(result["status"], result["data"])
```
</CodeGroup>

The start call returns `id` and `invalidURLs`, the addresses it skipped because they are not public pages. The result is:

```json
{
  "success": true,
  "status": "completed",
  "data": {
    "module": "bun:sqlite",
    "transactionModes": ["deferred", "immediate", "exclusive"]
  },
  "urls": ["https://bun.com/docs/runtime/sqlite"],
  "expiresAt": "2026-11-18T18:09:35.938Z"
}
```

`pricePerMonth` is missing: the page does not state it, so the field is left out. Every returned value is checked against the page text.

## Result fields

| Field | Holds |
| --- | --- |
| `status` | `completed` or `failed`. The HTTP status is `200` for both. |
| `success` | `false` when `status` is `failed`. A failed result has `error` and no `data`. |
| `data` | The fields the pages state. |
| `confidence` | For each field in `data`, 0 to 1. |
| `sources` | With `showSources`, the URLs that state each field. |
| `urls` | The pages read. |
| `warning` | Pages that could not be read, or a note that a page was cut. The fields come from the rest. |
| `costUsd`, `expiresAt` | The cost, and when the result is deleted. |

Results are kept for 24 hours, or 1 hour with `zeroDataRetention`. After that `GET` returns `404 notFound`. You can read only your own results. Reading is free.

## Request fields

Send a `schema`, a `prompt`, or both. With a `prompt` and no `schema`, the model names up to 20 fields in camelCase.

| Field | Default | Effect |
| --- | --- | --- |
| `urls` | none | Up to 25 pages. An address ending in `/*` reads the pages under it, found through the sitemap. With several pages, one answer is filled from all of them. Leave it out and send a `prompt` to search the web. |
| `schema` | none | A JSON Schema with `properties`. See below. |
| `prompt` | none | What to pull, up to 10,000 characters. |
| `systemPrompt` | none | Standing instructions such as units or date format, up to 10,000 characters. |
| `showSources` | `false` | Add `sources` to the result. |
| `timeout` | `30000` | Milliseconds to read the pages, 1,000 to 300,000. A page not read in time is skipped, named in `warning`, and not charged. |
| `enableWebSearch` | `false` | Also search for your `prompt` and read up to 3 more pages. |
| `allowExternalLinks` | `false` | Also read up to 5 linked pages on other sites. |
| `ignoreSitemap`, `includeSubdomains`, `limit` | `false`, `true`, none | For a `/*` address: find pages by links, read subdomains, read at most `limit` pages. |
| `scrapeOptions` | none | How each page is read, with the options of [Scrape](/scrape/overview). |
| `ignoreInvalidURLs` | `true` | Send `false` to refuse the call when an address is not a public page. |
| `zeroDataRetention` | `false` | Keep nothing from the call. See [Zero data retention](/production/zero-data-retention). |
| `webhook` | none | A public address, or `{ "url": "...", "events": ["failed"] }` with `headers` and `metadata`. One call when the extract ends, with `completed` or `failed`. See [Webhooks](/webhooks). |

`agent` is accepted and ignored, so a client that always sends it works. To navigate a site, use [Agent](/agent/overview).

## Schema

Pydantic `model_json_schema()` and zod `toJSONSchema()` output work as they are. Draft-07 and 2020-12 both work.

| Keyword | Use |
| --- | --- |
| `properties` | The fields. Up to 100 top-level fields, 32 KB, 32 levels of nesting. |
| `type`, `items` | Strings, numbers, booleans, objects and lists. Nested values are checked one by one. |
| `enum`, `const` | A value outside the set is left out. |
| `anyOf`, `oneOf`, `["number", "null"]` | Several shapes, or a nullable value. |
| `$ref` with `$defs` | A shared shape. The schema itself can be a `$ref` to an object. |
| `description` | Tells the model what a field means. |
| `required` | Read, but a field the page does not state is still left out. Parse `data` as partial: `Sqlite.partial().parse(data)` in zod, defaults on every Pydantic field. |

## Limits and errors

Codes are on [Errors](/api-reference/errors). These are specific to Extract.

- A page is read up to 50,000 characters, and all pages together up to 150,000. A cut page is named in `warning`.
- The answer takes up to 45 seconds after the pages are read. Set your client timeout above `timeout` plus 45 seconds.
- The call fails only when no page can be read, with the page's error such as `sourceTimeout` or `siteNotRead`. A failed call is free.
- `400 invalidRequest`: more than 25 `urls`, no `schema` and no `prompt`, no public page in `urls`, no `properties` in the schema, or a schema over a limit above. The `error` text names the fix.
- A call that finds none of your fields is free. For price, see [Pricing](/account/pricing).
