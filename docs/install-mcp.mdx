The hosted MCP server gives an agent Stophy tools for search, scrape, map, parse, crawl, extract, agent, browsers and monitors. Enter the URL in your client's MCP settings. Do not open it as a web page.

To have your agent do this, paste: `Use curl to read https://docs.stophy.dev/agent-quickstart.md and connect the Stophy MCP server to this agent.`

## Choose how to connect

| Connect | URL | Tools |
| - | - | - |
| Browser sign-in | `https://mcp.stophy.dev/mcp` | Every tool. You approve the app in your browser and calls use your balance. |
| API key | `https://api.stophy.dev/mcp` with `Authorization: Bearer <key>` | Every tool |
| No key | `https://api.stophy.dev/mcp` | Search, scrape, map, parse and signup, within the [free limits](/production/rate-limits) |

Clients that support MCP OAuth start the sign-in on their own. Signing out of stophy.dev disconnects the app. Paging, crawl, batches, extract, agent, browsers and monitors need sign-in or a key.

## Connect your client

These commands use browser sign-in. For no key or a key, use the `api.stophy.dev` URL.

<CodeGroup>

```bash Claude Code
claude mcp add --transport http stophy https://mcp.stophy.dev/mcp
# then run /mcp, choose stophy and pick Authenticate
```

```bash Codex
codex mcp add stophy --url https://mcp.stophy.dev/mcp
codex mcp login stophy
```

```bash Gemini CLI
gemini extensions install https://github.com/stophydotdev/stophy
# then run /mcp auth stophy
```

```json Cursor (~/.cursor/mcp.json)
{ "mcpServers": { "stophy": { "url": "https://mcp.stophy.dev/mcp" } } }
```

```json Windsurf (mcp_config.json)
{ "mcpServers": { "stophy": { "serverUrl": "https://mcp.stophy.dev/mcp" } } }
```

```bash OpenCode
opencode mcp add stophy --url https://mcp.stophy.dev/mcp
# then run /mcps, choose stophy and sign in
```

```bash VS Code (no key)
code --add-mcp '{"name":"stophy","type":"http","url":"https://api.stophy.dev/mcp"}'
```

</CodeGroup>

Restart Cursor after you edit its file. In Windsurf, open the file with **Open MCP config file** in the Cascade MCP menu. If you see two `stophy` servers in Claude Code, run `claude mcp remove stophy` and add the one you want.

**Claude** on the web, desktop or mobile: open **Customize > Connectors**, click **+ Add**, then **Add custom connector**, name it `Stophy`, paste `https://mcp.stophy.dev/mcp` and continue. Claude opens stophy.dev to approve. Turn Stophy on per chat under **+ > Connectors**. The Free plan allows one custom connector. **Grok:** open [grok.com/connectors](https://grok.com/connectors), click **New Connector**, then **Custom**, paste the URL and sign in.

## Use an API key

Keep the key in `STOPHY_API_KEY`, never in a file you commit. [Get a key](https://stophy.dev/signup).

| Client | Add to the `https://api.stophy.dev/mcp` setup |
| - | - |
| Claude Code | `--header "Authorization: Bearer $STOPHY_API_KEY"`. Add `--scope user` for every project. |
| Codex | `--bearer-token-env-var STOPHY_API_KEY`. Codex reads it at start, so it is never saved to `~/.codex/config.toml`. |
| OpenCode | `--header 'Authorization=Bearer {env:STOPHY_API_KEY}'` |
| Cursor | `"headers": { "Authorization": "Bearer ${env:STOPHY_API_KEY}" }` under `stophy` |
| VS Code | In `.vscode/mcp.json`, add an input `{ "type": "promptString", "id": "stophy-key", "description": "Stophy API key", "password": true }`. Under `servers.stophy` set `"type": "http"`, the `url` and `"headers": { "Authorization": "Bearer ${input:stophy-key}" }`. |

The server refuses a wrong key. Remove the header to go back to the free tools. An agent with no key can call `stophy_signup`, which returns a link for you to approve and a code, then the key when called again with the code. See [Agent quickstart](/agent-quickstart).

## What your agent sees

Without a key the server lists `stophy_search`, `stophy_scrape`, `stophy_map`, `stophy_parse` and `stophy_signup`. With sign-in or a key it adds a tool for each product. A call costs what it does over HTTP, and `costUsd` in a result is what it cost. See [Pricing](/account/pricing).

| Tools | What they do |
| - | - |
| `stophy_crawl`, `stophy_crawl_status`, `stophy_crawl_cancel` | Start a background crawl, read its pages, stop it |
| `stophy_extract` | Pull fields you name from pages as JSON |
| `stophy_agent`, `stophy_agent_status`, `stophy_agent_cancel` | Start a task that searches and reads pages, read its answer, stop it |
| `stophy_developer_search` | Search code docs, issues, pull requests and releases |
| `stophy_paper_search`, `stophy_paper_read`, `stophy_paper_similar` | Search research papers, read one, find similar ones |
| `stophy_monitor_create`, `_list`, `_get`, `_update`, `_delete`, `_run`, `_checks`, `_check` | Watch pages on a schedule and read what changed |
| `browserOpen`, `browserRun`, `browserClose` and six more | Drive a cloud browser |

Ask *"What are people saying about Bun on Reddit?"* and the agent calls `stophy_scrape` with a Reddit search URL and `"formats": [{ "type": "json", "parser": "reddit-search" }]`. See [Pre-built parsers](/scrape/prebuilt-parsers).

## Drive a browser

Not listed without sign-in or a key.

| Tool | What it does |
| - | - |
| `browserOpen` | Opens a cloud browser. Returns its `id`, a live view link you can watch or take over, and the page's elements with refs such as `e12`. Takes `url` and the session options of [Browser sessions](/browser/overview), such as `profile`, `proxy`, `location`, `ttl`, `solveCaptchas` and `captureConsole`. |
| `browserRun` | Does one thing. Send the `id` and exactly one of `steps`, `code` or `prompt`. Returns the elements and open tabs. |
| `browserClose` | Closes the browser, saves its profile, and bills the session. Returns the time, traffic and cost. |

`browserUpload`, `browserDownloads`, `browserRecording`, `browserProxy`, `browserExtensions` and `browserNetworkPolicy` work on an open browser.

`steps` is up to 50 actions that run in order and stop at the first failure. The actions are `open`, `back`, `reload`, `click`, `dblclick`, `hover`, `check`, `uncheck`, `fill`, `type`, `press`, `select`, `scroll`, `drag`, `find`, `wait`, `get`, `is`, `read`, `screenshot`, `pdf`, `tab`, `dialog`, `upload`, `network` and `console`. A step names an element by its ref from the latest answer, and `find` picks one by role and name. `read` returns Markdown, `network` lists requests since the session opened, and `console` needs `captureConsole`. `code` is a script, and `prompt` is plain words. A call may take 30 seconds, and `timeout` raises that to 300.

A session is billed from `browserOpen` to `browserClose`, so tell your agent to close every browser it opens.

## More tools and a local server

`?toolsets=web` on `https://api.stophy.dev/mcp` adds batches and more crawl and agent tools, such as `batchScrape`, `crawlList` and `agentList`. `toolsets=browser` adds `browserProfiles`, `browserTask` and `browserTaskStatus`. `toolsets=webhook` adds the webhook delivery tools.

For an app that can only start a local server, `npx -y @stophy/mcp` (Node.js 18 or later) passes every request to the hosted server. Set `STOPHY_API_KEY` for every tool, and `STOPHY_MCP_URL` to change the server. Claude Desktop uses the connector above, not this package.

## Check it

Ask your agent to search YouTube for `rust tutorial` and summarize the top three videos. If `stophy` shows no tools, restart your client.
