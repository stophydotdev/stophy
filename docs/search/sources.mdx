`sources` picks the kinds of results a [search](/search/overview) returns, and `categories` adds PDFs, papers and videos. Each one comes back in its own list under `data`.

## Search several sources

Get an API key in the [Quickstart](/quickstart). This request asks for news, images, research papers and YouTube videos, two of each.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "sqlite",
    "sources": ["news", "images"],
    "categories": ["research", "videos"],
    "limit": 2
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/search", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    query: "sqlite",
    sources: ["news", "images"],
    categories: ["research", "videos"],
    limit: 2,
  }),
});
const { data } = await response.json();
console.log(Object.keys(data));
```
```python Python
import os

response = requests.post(
```

## Sources and categories

| Value | Goes in | What you get | Where in `data` | Price |
| - | - | - | - | - |
| `web` | `sources` | Web pages with `url`, `title`, `description`, and `date` and `category` when known. The default. | `web` | $0.001 per 10 results |
| `news` | `sources` | News articles with `title`, `url`, `snippet`, `date` and `imageUrl`. Up to 50 per search. | `news` | $0.001 per 10 results |
| `images` | `sources` | Images with `imageUrl`, `imageWidth`, `imageHeight` and the `url` of the page that holds them. | `images` | $0.001 per 10 results |
| `pdf` | `categories` | Web results that are PDF files. A result gets `category` set to `pdf` when its address ends in `.pdf` or the page that was read for it is a PDF. | `web` | $0.001 per 10 results |
| `research` | `categories` | Scholarly papers ranked by relevance, then by citations. Each has `doi`, `authors`, `year`, `venue`, `type`, `citedByCount` and `openAccessUrl` when known, and a `snippet` from the abstract that matches the query. | `research` | $0.001 per 10 results |
| `videos` | `categories` | YouTube videos in YouTube's order, with `channel`, `durationSeconds`, `views` and a watch `url`. A video whose captions Stophy holds also gets the `snippet` that matches the query and `startSeconds`, and its `url` carries `&t=`. | `videos` | $0.001 per 10 results |

Each entry is a string or an object with a `type`, such as `"web"` or `{ "type": "web" }`. Send up to 5 sources. The web source is the only one that takes its own `tbs`, `location`, `country` and `lang`: `{ "type": "web", "tbs": "qdr:w", "country": "de" }`. See [Filters](/search/filters).

With no `sources` you get web results. With only `research` or `videos` in `categories`, no web search runs. With `research` and `web`, the web results are limited to academic sites.

## Search PDFs

`categories: ["pdf"]` searches for PDF files. A web result gets `category: "pdf"` when its address ends in `.pdf`, or when you add [page content](/search/page-content) and the page that was read is a PDF. A result with neither has no `category`.

```bash
curl -X POST https://api.stophy.dev/v1/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "sqlite file format",
    "categories": ["pdf"],
    "limit": 2
  }'
```

This real response is cut to one of the two rows.

```json
{
  "success": true,
  "data": {
    "web": [
      {
        "url": "https://www.tutorialspoint.com/sqlite/sqlite_tutorial.pdf",

```

To read a PDF you found, add [page content](/search/page-content) or send its address to [Scrape](/scrape/pdfs-and-documents).

## Limits and errors

- A source that fails while others answer is left out, and `warning` names it, such as `news: …`. When every source fails, the call fails and costs nothing.
- An empty list costs nothing. `warning` says when a list came back empty, for example `research: no papers match these words. Try fewer or more general words.`
- With only `research` or `videos` and no `sources`, the fields that narrow web, news and image results return `400 invalidRequest`: `tbs`, `location`, `lang`, `includeDomains`, `excludeDomains`, `country` and `scrapeOptions`. The error names the field, such as `tbs narrows web, news and image results. Add them to sources or leave tbs out.` Add a source or leave the field out.
- An entry that is not `web`, `news` or `images` in `sources` returns `400 invalidRequest`. The error says `Send web, news or images, as a string or {"type":"web"}.`
- An entry that is not `pdf`, `research` or `videos` in `categories` returns `400 invalidRequest`. The error says `Send pdf, research or videos, as a string or {type}.`
- An `images` search needs words next to `imagesize:` or `larger:`, or it returns `400 invalidRequest`.
