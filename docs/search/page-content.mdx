Add `scrapeOptions` when a search snippet is not enough and you need the page behind a web or news result. If you only need matching passages from pages we already have, set `highlights` instead.

## Read each result

Get an API key in the [Quickstart](/quickstart). Reading result pages needs an API key. This request reads two results as `markdown`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "bun sqlite",
    "limit": 2,
    "scrapeOptions": {
      "formats": ["markdown"],
      "onlyMainContent": true
    }
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.search({
  query: "bun sqlite",
  limit: 2,
  scrapeOptions: {
    formats: ["markdown"],
    onlyMainContent: true,
  },
});
for (const result of data?.web ?? []) {
  console.log(result.url, result.markdown?.length ?? result.metadata?.error);
}
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.search(
    query="bun sqlite",
    limit=2,
    scrape_options={
        "formats": ["markdown"],
        "onlyMainContent": True,
    },
)["data"]
for result in data["web"]:
    print(result["url"], len(result.get("markdown", "")) or result["metadata"]["error"])
```
</CodeGroup>

## Read the response

Look for `markdown` on each web row we read. Its `metadata` is the same as in a [scrape](/scrape/page-metadata), and `metadata.costUsd` tells you what reading that page cost.

```json
{
  "success": true,
  "data": {
    "web": [
      {
        "url": "https://bun.com/docs/runtime/sqlite",
        "markdown": "# SQLite\n\n> Bun natively implements a high-performance SQLite3 driver.\n\n…",
        "metadata": {
          "costUsd": 0.001
        }
      }
    ]
  },
  "costUsd": 0.003
}
```

`costUsd` is $0.003 for two results: $0.001 for the search and $0.001 for each page. A format other than `markdown`, such as `summary`, `html` or `links`, appears as its own field on each row. See [Scrape](/scrape/overview) for every format. With `scrapeOptions.formats`, the `description` of a web row is filled from the page.

## Get highlights

Set `"highlights": true` when you only need passages that match `query`. For pages we already have, passages replace the web result's `description` in Markdown, up to about 2,000 characters. The `…` between passages marks skipped text. Other results keep their usual description, if they have one. This option adds nothing to the price.

To get passages in a separate list, put `{ "type": "highlights", "query": "refund policy" }` in `scrapeOptions.formats`. You can set a separate `count`. See [Highlights](/scrape/highlights).

## Read each outcome

Check `metadata.error` before using `markdown`. A failed page does not fail the search. The row keeps its URL, title and description, but it has no Markdown and we do not charge for reading it. If we do not read the site as a page, check the [parser list](https://api.stophy.dev/v1/parsers) for a parser that takes the URL. Otherwise, use search without page text.

| `metadata.error` | Meaning |
| - | - |
| `The page took too long to read. Read this address with scrape.` | The page did not answer inside its deadline. |
| `There was no time left to read this page. Read this address with scrape.` | The search `timeout` ran out before the page was reached. |
| `The page was not found or has no readable text.` | The page is gone or has no text to return. |
| `The page could not be read in this call. Read this address with scrape.` | Another failure. Read the address with [Scrape](/scrape/overview) to see why. |

## Options

Set `scrapeOptions.formats` to read pages. Set `scrapeLimit` at the top level if you want to read fewer pages than the number of results. `scrapeOptions` takes the options of [Scrape](/scrape/overview), so every Scrape page applies here.

| Field | Type | Default | Effect |
| - | - | - | - |
| `scrapeOptions.formats` | `array` | none | What to return for each result. With no `formats`, no page is read and nothing more is charged. Send up to 20, such as `markdown`, `summary`, `html`, `links` or `json`. |
| `scrapeOptions.onlyMainContent` | `boolean` | `true` | Keep only the main content of each page. See [Content filtering](/scrape/content-filtering). |
| `scrapeOptions.maxAge` | `number` | 2 days | Accept a stored copy of each page up to this many milliseconds old, at most 30 days. `0` reads live. See [Freshness and caching](/scrape/freshness-and-caching). |
| `scrapeOptions.timeout` | `number` | 30,000 ms | The most milliseconds one page may take, from 1,000 to 300,000. A page never gets more than what is left of the search `timeout`. Pages that run out of time get an error row. |
| `scrapeOptions.zeroDataRetention` | `boolean` | `false` | Keep nothing from the call. Adds $2 per 1,000 pages. See [Zero data retention](/production/zero-data-retention). |
| `highlights` | `boolean` | `false` | Fill each web `description` with the passages that best match `query`. |
| `limit` | `number` | 5 | With `scrapeOptions.formats`, how many results come back. Without `scrapeLimit`, every web and news result returned is read. |
| `scrapeLimit` | `number` | `limit` | With `scrapeOptions.formats`, how many web results and how many news results are read, from the top, 1 to 100. The other results come back without page text. It cannot be more than `limit`, and sending it without `scrapeOptions.formats` returns `400 invalidRequest`. |
| `maxTextLength` | `number` | none | A query parameter. Cuts every text value in the response to this many characters. A cut value ends with `…`. |

## Limits and errors

Use an API key and ask only for sources whose pages we can read.

- Only web and news results are read. `scrapeOptions.formats` with `images` in `sources` returns `400 invalidRequest`. The error says `Page text is only added to web and news results. Drop images.`
- Without an API key, `scrapeOptions` returns `401 apiKeyRequired` with `scrapeOptions: Reading result pages needs an API key. Get one at https://stophy.dev/signup, or leave scrapeOptions out.`
- Up to 10 pages are read at once. The search `timeout` is 60,000 ms by default when pages are read.

## Price

$1 per 1,000 results whose page is read, on top of the search price. `summary` and `json` with a schema or a prompt add $3 per 1,000 more each when they return something. A result with a `metadata.error` is not charged for its page. A result that is not read because of `scrapeLimit` is not charged for a page. A search with `limit: 20` and `scrapeLimit: 3` costs $0.002 for the 20 results plus $0.001 for each of the 3 pages that are read. See [Pricing](/account/pricing).
