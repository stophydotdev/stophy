Paper search finds research papers by their title and abstract. It has three operations: search papers, read one paper by its id, and find papers like it.

## Search papers

Get an API key in the [Quickstart](/quickstart). Paper search needs an API key. This request finds papers from 2024 on, newest first.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search/research/papers \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "retrieval augmented generation",
    "k": 3,
    "from": "2024-01-01",
    "sort": "date_desc"
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/search/research/papers", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    query: "retrieval augmented generation",
    k: 3,
    from: "2024-01-01",
    sort: "date_desc",
  }),
});
const { results } = await response.json();
console.log(results.map((paper) => `${paper.year} ${paper.title}`));
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/search/research/papers",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "query": "retrieval augmented generation",
        "k": 3,
        "from": "2024-01-01",
        "sort": "date_desc",
    },
)
for paper in response.json()["results"]:
    print(paper["year"], paper["title"])
```
</CodeGroup>

`GET /v1/search/research/papers` takes the same fields as query parameters.

`paperId` names the paper. `primaryId` is its best outside id: `arxiv:<id>`, else `doi:<DOI>`, else `openalex:<id>`. `ids` lists every id Stophy knows. `year`, `venue` and `openAccessUrl` appear when known, and `abstract` is an empty string when the index holds none.

### Search options

| Field | Type | Default | Effect |
| - | - | - | - |
| `query` | `string` | none | What to search for. Required. |
| `k` | `number` | 40 | How many papers, 1 to 500. |
| `authors` | `string` | none | Keep papers with an author whose name contains this text. |
| `from` | `string` | none | Keep papers published in this year or later. A date such as `2024-01-01`; only its year counts. |
| `to` | `string` | none | Keep papers published in this year or earlier. A date such as `2025-12-31`; only its year counts. |
| `sort` | `string` | `relevance` | `relevance`, or `date_desc` for the newest year first. |

## Read one paper

`GET /v1/search/research/papers/{id}` takes a `paperId`, a DOI as `doi:10.18653/v1/2024.eacl-demo.16`, an arXiv id as `arxiv:<id>`, or an OpenAlex id as `openalex:W4411630045`. Add `query` to get the passage that matches it.

<CodeGroup>
```bash cURL
curl "https://api.stophy.dev/v1/search/research/papers/W4411630045?query=how+is+retrieval+evaluated&k=1" \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```
```typescript TypeScript
const params = new URLSearchParams({ query: "how is retrieval evaluated", k: "1" });
const response = await fetch(
  `https://api.stophy.dev/v1/search/research/papers/W4411630045?${params}`,
  { headers: { Authorization: `Bearer ${process.env.STOPHY_API_KEY}` } },
);
const { paper, passages } = await response.json();
console.log(paper.title, passages);
```
```python Python
import os

import requests

response = requests.get(
    "https://api.stophy.dev/v1/search/research/papers/W4411630045",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    params={"query": "how is retrieval evaluated", "k": 1},
)
body = response.json()
print(body["paper"]["title"], body["passages"])
```
</CodeGroup>

The paper index holds titles and abstracts, not full text, so the passage is the abstract, and `note` says so. Here `authors` is one string. `k`, from 1 to 50, is only valid with `query`. Without `query`, the answer holds only `paper`.

## Find similar papers

`GET /v1/search/research/papers/{id}/similar` ranks papers by the words of your `intent` and the title of the paper. Add more papers to find ones like all of them: repeat `anchor` once for each.

<CodeGroup>
```bash cURL
curl "https://api.stophy.dev/v1/search/research/papers/W4411630045/similar?intent=evaluating+retrieval+augmented+generation&k=5" \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```
```typescript TypeScript
const params = new URLSearchParams({
  intent: "evaluating retrieval augmented generation",
  k: "5",
});
const response = await fetch(
  `https://api.stophy.dev/v1/search/research/papers/W4411630045/similar?${params}`,
  { headers: { Authorization: `Bearer ${process.env.STOPHY_API_KEY}` } },
);
const { results } = await response.json();
console.log(results.map((paper) => paper.title));
```
```python Python
import os

import requests

response = requests.get(
    "https://api.stophy.dev/v1/search/research/papers/W4411630045/similar",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    params={"intent": "evaluating retrieval augmented generation", "k": 5},
)
print([paper["title"] for paper in response.json()["results"]])
```

The papers you start from are left out of `results`. `poolSize` is how many papers came back.

| Field | Type | Default | Effect |
| - | - | - | - |
| `intent` | `string` | none | What you want the papers to be about. Required. |
| `k` | `number` | 40 | How many papers, 1 to 500. |
| `anchor` | `string` | none | Another paper id to find papers like. Repeat it for each. |
| `mode` | `string` | `similar` | Only `similar` works. |

## Limits and errors

- All three operations need an API key. Without one they return `401 apiKeyRequired`.
- A paper that is not in the index returns `404 notFound` with `No paper matches <id>.`
- `from` later than `to` returns `400 invalidRequest` with `from: must not be later than to.` `from` and `to` must be dates as `YYYY-MM-DD`.
- `categories` on a search returns `400 invalidRequest`, because the paper index holds no categories. `mode` set to `citers` or `references` returns `400 invalidRequest`, because the index holds no citations.
- A field the search does not take returns `400 invalidRequest` and names every such field, as in `Unrecognized key: "limit". Use k for the number of results.` Send `k` for the number of papers.
- A search that returns no papers costs nothing.

## Price

Searching papers and finding similar papers cost $1 per 1,000 searches of up to 10 papers: $0.001 for each 10. Reading one paper counts as one page: $1 per 1,000 pages. A failed call costs nothing. See [Pricing](/account/pricing).
