Use filters when the query alone brings back results from the wrong site, time or place. Send them next to `query` in [Search](/search/overview).

## Search selected sites

Get an API key in the [Quickstart](/quickstart). This request searches two sites and keeps results from the past year.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "sqlite driver",
    "includeDomains": ["bun.com", "nodejs.org"],
    "tbs": "qdr:y",
    "limit": 3
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.search({
  query: "sqlite driver",
  includeDomains: ["bun.com", "nodejs.org"],
  tbs: "qdr:y",
  limit: 3,
});
console.log(data?.web?.map((result) => result.url));
```
```python Python
from stophy import Stophy

stophy = Stophy()

data = stophy.search(
    query="sqlite driver",
    include_domains=["bun.com", "nodejs.org"],
    tbs="qdr:y",
    limit=3,
)["data"]
print([result["url"] for result in data["web"]])
```
</CodeGroup>

## Read the response

Check `data.web` for results from the domains you named. The service returns `date` where it is known.

```json
{
  "success": true,
  "data": {
    "web": [
      {
        "url": "https://bun.com/",
        "position": 1
      },
      {
        "url": "https://bun.com/blog/bun-v1.3.3",
        "position": 2,
        "date": "2025-11-21T00:00:00.000Z"
      }
    ]
  },
  "costUsd": 0.001
}
```

A filter can leave fewer results than `limit`. A call that returns nothing costs nothing and carries a `warning`.

## Search from a place

Set `location` when a city or country matters to the query. For a bakery search from Berlin, add `"location": "Berlin,Germany"`. Add `"lang": "de"` to prefer German results. Some results can still be in other languages.

## Options

Choose the filters each source can use. Web results accept the most filters.

| Field | Type | Default | Effect |
| - | - | - | - |
| `includeDomains` | `array of string` | none | Keep only results on these sites. Up to 10 domains. A domain also matches its subdomains. Not with `excludeDomains`. |
| `excludeDomains` | `array of string` | none | Drop results on these sites. Up to 10 domains. Not with `includeDomains`. |
| `tbs` | `string` | any time | The time window, see the table below. Web takes every value, news takes `qdr` and `sbd`, images take none. |
| `location` | `string` | none | Where to search from, such as `Germany` or `San Francisco,California,United States`. The last part is the country and replaces `country`. A city before it narrows web results to that place. |
| `country` | `string` | `us` | Two-letter country to search from, such as `de`. `uk` is read as `gb`. Image results are always from the US. |
| `lang` | `string` | none | Two-letter language for web results, such as `de`. |
| `safe` | `boolean` | `false` | Hide explicit web, news and image results. |

A filter sent at the top level applies to every source it fits. To give web results their own `tbs`, `location`, `country` or `lang`, send the web source as an object: `"sources": [{ "type": "web", "tbs": "qdr:w", "country": "de" }]`. See [Sources](/search/sources).

### Time window

Use `tbs` to restrict dates or show the newest results first.

| `tbs` | Effect |
| - | - |
| `qdr:d`, `qdr:w`, `qdr:m`, `qdr:y` | The past day, week, month or year. |
| `cdr:1,cd_min:MM/DD/YYYY,cd_max:MM/DD/YYYY` | A date range. Send `cd_min`, `cd_max` or both. Web only. |
| `sbd:1` | Newest first. Results without a date come last, and a `warning` says how many. Every result found is sorted before `limit` applies, so `limit: 1` returns the newest one. |

Join values with a comma, such as `sbd:1,qdr:w` for the past week, newest first.

## Limits and errors

Check the error before retrying. Some filters cannot be combined or used with a particular source.

- `includeDomains` together with `excludeDomains` returns `400 invalidRequest`. The error says `Send includeDomains or excludeDomains, not both.`
- A `tbs` that is not in the table returns `400 invalidRequest`, and the error names the part it did not understand. `qdr` takes `d`, `w`, `m` or `y`, and `cd_min` must be on or before `cd_max`.
- A date range (`cdr`) with `news` in `sources` returns `400 invalidRequest`. The error says `News takes qdr and sbd only.`
- `tbs` with only `images` in `sources` returns `400 invalidRequest`. The error says `Image results cannot be filtered by time. Leave tbs out or drop images.` With other sources, images are left unfiltered and `warning` says so.
- A `location` that does not end in a country returns `400 invalidRequest`. The error says `Send a place that ends with a country, like Berlin,Germany or Germany, or use country.`
- A `country` other than `us` with `images` in `sources` returns `400 invalidRequest`, because image results are always from the US.
- With `categories` of `research` and `web` in `sources`, `includeDomains` and `excludeDomains` return `400 invalidRequest`, because research already limits the search to academic sites.
