Check your balance, spending and limits without opening the dashboard. They are free and need an API key. Every amount is in dollars. Each response also has older fields that count the same amounts in steps of $0.002. This page leaves them out. Use the dollar fields.

| Call | What it shows |
| - | - |
| `GET /v1/limits` | Your tier, balance, per-minute limits, calls and jobs at once, and key expiry |
| `GET /v1/usage` | Your balance, and what all your calls have cost |
| `GET /v1/usage/history` | What you spent and how many paid calls you made, per hour, day or month |
| `GET /v1/team/credit-usage` | Your balance |
| `GET /v1/team/credit-usage/historical` | What you spent each month |

## Check your limits and balance

Call `GET /v1/limits` to see what you can spend and how many calls you can make with this key.

<CodeGroup>
```bash cURL
curl https://api.stophy.dev/v1/limits \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/limits", {
  headers: { Authorization: `Bearer ${process.env.STOPHY_API_KEY}` },
});
const { data } = await response.json();
console.log(data.balanceUsd, data.perMinute);
```
```python Python
import os

import requests

response = requests.get(
    "https://api.stophy.dev/v1/limits",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
)
data = response.json()["data"]
print(data["balanceUsd"], data["perMinute"])
```
</CodeGroup>

Start with `data.balanceUsd` and `data.perMinute`. This response uses an example balance.

```json
{
  "success": true,
  "data": {
    "tier": "paid",
    "balanceUsd": 25,
    "rateLimit": {
      "limitPerMinute": 600,
      "remaining": 597,
      "resetsAt": "2026-11-17T17:44:00.000Z"
    },
    "perMinute": { "calls": 600, "jobs": 100, "interact": 100, "reads": 1500 },
    "billingUrl": "https://stophy.dev/billing"
  },
  "costUsd": 0,
  "requestId": "5f9f38f3-3b4b-4cf0-87c5-d88404d9ad2f"
}
```

| Field | What it is |
| - | - |
| `tier` | `free` until your first top-up, then `paid` |
| `balanceUsd` | What is left on the account, in dollars |
| `rateLimit` | Calls a minute this key may make, how many are left counting this request, and when the minute resets. `null` when the counter is unavailable. |
| `perMinute` | The limit a minute for each kind of call: `calls`, `jobs`, `interact` and `reads` |
| `concurrency` | How many calls may run at once and how many run now |
| `jobsAtOnce`, `queuedJobs` | Crawls, batches, extracts and agent runs that may run at once, and that may wait |
| `sessionsAtOnce` | Browser sessions that may be open at once |
| `paidLimits` | On the `free` tier, the limits a `paid` account has. `null` on `paid`. |
| `keyExpiresAt` | When this key stops working, or `null` when it does not expire |
| `billingUrl` | Where to add money |

`GET /v1/limits` counts as one call toward the per-minute limit. See [Rate limits](/production/rate-limits) for what each limit means.

## Check what you have used

Call `GET /v1/usage` for your total spend and paid call count. `balanceMicros` is the balance in millionths of a dollar. `costUsd` is what all your calls have cost, and `requestCount` is how many paid calls you made. This response has no `success` or `data` wrapper.

## Read your spending over time

Use `GET /v1/usage/history` to compare spend over time or narrow it to one endpoint or key. For example, set `interval=day`, `endpoint=scrape` and `from=2026-11-15` for daily scrape spend from November 15 onward. Read the window in `data.from` and `data.to`, the total in `data.totals`, and its breakdown in `data.buckets`. Each bucket gives you `start`, `costUsd` and `requests`.

| Parameter | Default | What it does |
| - | - | - |
| `interval` | `day` | The bucket size: `hour`, `day` or `month` |
| `from` | 2 days, 30 days or 366 days before `to`, for `hour`, `day` and `month` | The start of the window. An ISO time such as `2026-11-01` or `2026-11-01T08:00:00Z`. |
| `to` | Now | The end of the window, not included |
| `endpoint` | All | Only calls to this endpoint, such as `scrape` |
| `apiKeyId` | All | Only calls made with this key |

The window can span at most 31 days for `hour` and 366 days for `day` and `month`, and `from` must be before `to`, or the call answers `invalidRequest`. `start` is the UTC start of the bucket. Buckets with no paid calls are left out, and calls that cost nothing are not counted. `totals` adds the buckets.

## Read your monthly spend

`GET /v1/team/credit-usage` returns your balance. `GET /v1/team/credit-usage/historical` returns one row for each month of the last year, with what you spent. The first call returns `balanceUsd`. There are no plans, so its plan and period fields are `null`.

Read `periods` for the monthly rows. Each has `startDate`, `endDate`, `totalCostUsd` and `costUsd`. Send `byApiKey=true` to split each month by the key that made the calls. Each row then has the key's name in `apiKey`.

For the model use of extract and agent, see [Usage and logs](/production/usage-and-logs).
