title: "Install skills"
description: "Install the Stophy agent skills so your coding agent picks the right command for a task. One command for any agent, plus Claude Code, Cursor and Gemini."
---

Each skill is a `SKILL.md` in the `skills` folder of [stophydotdev/stophy](https://github.com/stophydotdev/stophy). It teaches an agent which Stophy command fits a task and how to read the result. A skill is instructions only: it lets the agent run `stophy` and `npx @stophy/cli` shell commands. If `stophy` is missing or old, skills fall back to `npx @stophy/cli@latest`.

## Install

```bash
npx skills add stophydotdev/stophy
```

To install some skills, add `--skill <name>` for each, such as `--skill stophy-web --skill stophy-video`. `stophy init` runs this for you. See [Install the CLI](/install-cli).

The repository is also a plugin. Each manifest names the hosted [MCP server](/install-mcp).

| Agent | Install |
| - | - |
| Claude Code | `/plugin marketplace add stophydotdev/stophy`, then `/plugin install stophy@stophy` |
| Cursor | Add the server to `~/.cursor/mcp.json`. See [MCP server](/install-mcp) |
| Gemini CLI | `gemini extensions install https://github.com/stophydotdev/stophy` |

The Claude Code plugin brings the skills and the MCP server, and asks you to sign in with your browser the first time.

## Sign in

Skills call the CLI. Search, scrape, map, parse and the parsers marked `keyless` work with no login, within the [free limits](/production/rate-limits). For the rest, run `stophy login --browser` or set `STOPHY_API_KEY`.

## The skills

Start with `stophy`. It names the skill and command for your task, and covers setup, login and errors.

| Group | Skills |
| - | - |
| Tasks | `stophy-scrape` (one page, or a site's data through a parser), `stophy-search`, `stophy-crawl` (list, crawl or batch), `stophy-extract`, `stophy-parse`, `stophy-monitor`, `stophy-download` (a site as Markdown files), `stophy-docs` (a library's current docs), `stophy-browser` |
| Build | `stophy-build` (an app with the SDK or REST API), `stophy-build-scrape`, `stophy-build-search` |
| Workflows | `stophy-lead-gen`, `stophy-job-postings`, `stophy-shop`, `stophy-competitive-intel`, `stophy-deep-research` |
| Site data | `stophy-video` (YouTube, TikTok, Instagram), `stophy-social`, `stophy-places`, `stophy-jobs`, `stophy-shopping`, `stophy-apps`, `stophy-real-estate`, `stophy-ads`, `stophy-web` (Google Patents and Trends) |

## Check it

In a new session, ask which Stophy command reads `https://bun.com/docs` and tell the agent not to run it. A loaded skill answers `stophy scrape "https://bun.com/docs"`. If it answers with a plain HTTP fetch, check each skill sits in a folder your agent reads as `<name>/SKILL.md`, and restart the session.
