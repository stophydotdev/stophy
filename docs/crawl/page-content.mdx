`scrapeOptions` sets how every page of a crawl is read. It takes the same fields as [Scrape](/scrape/overview), so a crawl can return Markdown, links, HTML, a screenshot, JSON and the rest. Without it, each page comes back as `markdown`.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request crawls a site for 3 pages and returns each as Markdown plus its links, keeping only the main content and dropping the footer.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/crawl \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://quotes.toscrape.com",
    "limit": 3,
    "scrapeOptions": {
      "formats": ["markdown", "links"],
      "onlyMainContent": true,
      "excludeTags": ["footer"],
      "waitFor": 500
    }
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { id } = await stophy.crawl({
  url: "https://quotes.toscrape.com",
  limit: 3,
  scrapeOptions: {
    formats: ["markdown", "links"],
    onlyMainContent: true,
    excludeTags: ["footer"],
    waitFor: 500,
  },
});
console.log(id);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.crawl(
    url="https://quotes.toscrape.com",
    limit=3,
    scrape_options={
        "formats": ["markdown", "links"],
        "onlyMainContent": True,
        "excludeTags": ["footer"],
        "waitFor": 500,
    },
)
print(result["id"])
```
</CodeGroup>

## Options

`scrapeOptions` is an object. Every field below is a field of Scrape, and means the same here.

| Field | Type | Default | Effect |
| - | - | - | - |
| `formats` | `array` | `["markdown"]` | What each page returns. See the formats in the [Scrape overview](/scrape/overview#formats). |
| `onlyMainContent` | `boolean` | `true` | Keep the main content, without menus, headers and footers. |
| `onlyCleanContent` | `boolean` | `false` | A model removes banners and prompts that are left. See [Content filtering](/scrape/content-filtering). |
| `includeTags`, `excludeTags` | `array of string` | none | Keep or remove parts of each page by CSS selector. |
| `removeBase64Images` | `boolean` | `true` | Drop images that carry their data in the URL. |
| `waitFor`, `mobile`, `fastMode`, `blockAds` | varies | varies | Waiting and rendering. See [Waiting and rendering](/scrape/waiting-and-rendering). |
| `actions` | `array of object` | none | Steps to run on each page before it is read. See [Browser actions](/scrape/browser-actions). |
| `location`, `headers`, `skipTlsVerification`, `proxy` | varies | varies | Where to read from and what to send. See [Location and headers](/scrape/location-and-headers). |
| `maxAge`, `minAge`, `storeInCache`, `lockdown` | varies | varies | How old a stored copy may be. See [Freshness and caching](/scrape/freshness-and-caching). |
| `checkPromptInjection`, `redactPII` | varies | `false` | Scan for prompt injection, or hide personal data. See [Safety](/scrape/safety). |
| `parsers` | `array` | none | PDF options for document pages. See [PDFs and documents](/scrape/pdfs-and-documents). |
| `profile` | `object` | none | Read with the cookies a browser profile saved. |

These Scrape fields are not allowed in `scrapeOptions`: `url`, `linkStyle`, `maxChars`, `offset` and `query`. A crawl takes its URLs from `url` and the links it follows, and it returns whole pages.

## Limits and errors

- Each page gets about 20 seconds plus your `waitFor`. A `timeout` inside `scrapeOptions` is replaced by that value.
- With a profile that saves changes, a crawl reads one page at a time, so it is slower. Send `"saveChanges": false` in `profile` to read at full speed.
- A page that fails does not stop the crawl, and it is listed in the crawl's errors. See [Read a crawl](/crawl/async).
- Options that need an API key in Scrape, such as `actions` and `waitFor`, work here, because Crawl always needs an API key.

## Price

$1 per 1,000 pages, plus what the formats and options you choose add in Scrape: for example `summary`, `json` with a schema and `question` add $3 per 1,000 pages each, and `checkPromptInjection` adds $2.50. See the [Scrape price](/scrape/overview#price). A page that comes back with a 404 or 410 status, or cannot be read, costs nothing.
