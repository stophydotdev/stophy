Use Crawl to find and read pages across a site from one starting URL. We follow links in the background and return pages as they finish. If you already have the list of URLs, use [Batches](/batches/overview).

## Make a request

To start with a small crawl, give us the URL of a docs section and set `limit` to `3`. Crawl needs an [API key](/quickstart). For the SDK tabs, run `npm install stophy` or `pip install stophy`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/crawl \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com/docs/runtime",
    "limit": 3
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { id } = await stophy.crawl({
  url: "https://bun.com/docs/runtime",
  limit: 3,
});
console.log(id);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.crawl(
    url="https://bun.com/docs/runtime",
    limit=3,
)
print(result["id"])
```
</CodeGroup>

## Read the response

Save the `id` or `url` from the start response. You use it to read the pages as they finish.

```json
{
  "success": true,
  "id": "job_9FAn-0pRXhHk7olrXk0sVg",
  "url": "https://api.stophy.dev/v1/crawl/job_9FAn-0pRXhHk7olrXk0sVg"
}
```

Poll `GET /v1/crawl/{id}` while `status` is `scraping`. `total` is how many pages we have found so far, and `data` holds the finished pages. Once `status` is `completed`, read each page's `markdown` and `metadata`. Follow `next` if the response includes it.

See [Read a crawl](/crawl/async) for polling, paging, cancelling and webhooks.

## Options

Set the scope before you start a crawl. Use `scrapeOptions` to choose what you get back for each page.

| Field | What it does | Guide |
| - | - | - |
| `url` | The page to start from. Required. | [Scope](/crawl/scope) |
| `limit` | Stop after reading this many pages. 1 to 10,000, default 10,000. | [Scope](/crawl/scope) |
| `includePaths`, `excludePaths`, `regexOnFullURL` | Read only the paths you match, or skip them. | [Scope](/crawl/scope) |
| `maxDiscoveryDepth`, `crawlEntireDomain` | How far from the start page to go, and whether to leave its path. | [Scope](/crawl/scope) |
| `allowSubdomains`, `allowExternalLinks` | Follow links to subdomains, or to other sites. | [Scope](/crawl/scope) |
| `sitemap`, `ignoreQueryParameters`, `deduplicateSimilarURLs` | How pages are found and counted as one. | [Scope](/crawl/scope) |
| `prompt` | Read pages about a topic first, and stop when new pages stop mentioning it. | [Scope](/crawl/scope) |
| `scrapeOptions` | How to read each page: formats, filters, actions and more. | [Page content](/crawl/page-content) |
| `webhook`, `delay`, `maxConcurrency`, `zeroDataRetention` | Be told as pages finish, pace the crawl, or keep nothing. | [Read a crawl](/crawl/async) |

To turn a plain-language request into these fields, see [Describe a crawl](/crawl/describe).

## Limits and errors

Check the job status to tell a queued crawl from a failed start.

- A crawl reads at most 10,000 pages. A crawl and its pages are kept for 24 hours.
- A start page that cannot be read, or that the site's robots rules do not allow, ends the crawl with `status` `failed` and the reason in `error`. Later pages that those rules disallow are skipped.
- Crawl needs an API key. Without one, the call returns `401 apiKeyRequired`.
- A crawl can wait before it starts. While it waits, the answer has a `queuePosition`.

## Price

$1 per 1,000 pages. Starting a crawl is free, and each page is charged when it finishes. A page that answers 404 or 410, or cannot be read, costs nothing. The formats and options you send in `scrapeOptions` add what they add in [Scrape](/scrape/overview#price). This crawl read 3 pages and cost $0.003. See [Pricing](/account/pricing).

## Choose another API

Use a different call if you do not need us to follow links and read their content.

- [Map](/map/overview) lists the pages of a site without reading them.
- [Scrape](/scrape/overview) reads one page.
- [Batches](/batches/overview) read a list of URLs in the background.
- [Search](/search/overview) finds pages from a query and can read each result.
- [Extract](/extract/overview) pulls the fields you name from one or more pages.
