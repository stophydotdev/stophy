Crawl starts at one page, follows its links, and reads every page it finds. It runs in the background. The call answers at once with an `id`, and you read the pages as they finish.

## Make a request

Get an API key in the [Quickstart](/quickstart). Crawl needs one. This request crawls a docs section and stops after 3 pages.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/crawl \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com/docs/runtime",
    "limit": 3
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/crawl", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://bun.com/docs/runtime",
    limit: 3,
  }),
});
const { id } = await response.json();
console.log(id);
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/crawl",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://bun.com/docs/runtime",
        "limit": 3,
    },
)
print(response.json()["id"])
```
</CodeGroup>

While the crawl runs, `status` is `scraping`, `total` is the number of pages found so far, and `data` holds the pages that are done. See [Read a crawl](/crawl/async) for polling, paging, cancelling and webhooks.

## Options

| Field | What it does | Guide |
| - | - | - |
| `url` | The page to start from. Required. | [Scope](/crawl/scope) |
| `limit` | Stop after reading this many pages. 1 to 10,000, default 10,000. | [Scope](/crawl/scope) |
| `includePaths`, `excludePaths`, `regexOnFullURL` | Read only the paths you match, or skip them. | [Scope](/crawl/scope) |
| `maxDiscoveryDepth`, `crawlEntireDomain` | How far from the start page to go, and whether to leave its path. | [Scope](/crawl/scope) |
| `allowSubdomains`, `allowExternalLinks` | Follow links to subdomains, or to other sites. | [Scope](/crawl/scope) |
| `sitemap`, `ignoreQueryParameters`, `deduplicateSimilarURLs` | How pages are found and counted as one. | [Scope](/crawl/scope) |
| `prompt` | Read pages about a topic first, and stop when new pages stop mentioning it. | [Scope](/crawl/scope) |
| `scrapeOptions` | How to read each page: formats, filters, actions and more. | [Page content](/crawl/page-content) |
| `webhook`, `delay`, `maxConcurrency`, `zeroDataRetention` | Be told as pages finish, pace the crawl, or keep nothing. | [Read a crawl](/crawl/async) |

To turn a plain-language request into these fields, see [Describe a crawl](/crawl/describe).

## Limits and errors

- A crawl reads at most 10,000 pages. A crawl and its pages are kept for 24 hours.
- A start page that cannot be read, or that the site's robots rules do not allow, ends the crawl with `status` `failed` and the reason in `error`. Later pages that those rules disallow are skipped.
- Crawl needs an API key. Without one, the call returns `401 apiKeyRequired`.
- A crawl can wait before it starts. While it waits, the answer has a `queuePosition`.

## Price

$1 per 1,000 pages. Starting a crawl is free, and each page is charged when it finishes. A page that answers 404 or 410, or cannot be read, costs nothing. The formats and options you send in `scrapeOptions` add what they add in [Scrape](/scrape/overview#price). This crawl read 3 pages and cost $0.003. See [Pricing](/account/pricing).
