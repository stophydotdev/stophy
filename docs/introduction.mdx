Search, read, and act on the web. Send a URL or a query to one API and get Markdown, JSON or a finished task back. A failed call costs nothing.

## Make your first request

[Get an API key](/get-credentials) and set it as `STOPHY_API_KEY`. This call reads `example.com` as Markdown. The TypeScript and Python tabs use the [SDKs](/sdks).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "url": "https://example.com", "formats": ["markdown"] }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();
const { data } = await stophy.scrape({ url: "https://example.com", formats: ["markdown"] });
console.log(data.markdown);
```
```python Python
from stophy import Stophy

stophy = Stophy()
result = stophy.scrape(url="https://example.com", formats=["markdown"])
print(result["data"]["markdown"])
```
</CodeGroup>

The page text is in `data.markdown`. `data.metadata` has the title, the site's status code and `costUsd`, what the call cost.

```json
{
  "success": true,
  "data": {
    "markdown": "This domain is for use in documentation examples without needing permission. …",
    "metadata": { "title": "Example Domain", "statusCode": 200, "costUsd": 0.001 }
  }
}
```

## Choose an API

Crawl follows links from one URL to find pages. A batch reads a list of URLs you already have. Extract reads the pages you name. Agent finds the pages itself.

| You have | You want | Use |
| - | - | - |
| A URL | The page as Markdown, links, a screenshot or JSON | [Scrape](/scrape/overview) |
| A URL on a site with its own data | A video, listing or profile as JSON | [Scrape with a parser](/scrape/prebuilt-parsers) |
| A site | Every URL on it | [Map](/map/overview) |
| A site | The content of its pages | [Crawl](/crawl/overview) |
| A list of URLs | Their content, as a background job | [Batches](/batches/overview) |
| A query | Ranked web, news, image, video or research results | [Search](/search/overview) |
| Pages and the fields you want | The values, each checked against the page | [Extract](/extract/overview) |
| A task in plain words | An answer with a quote for each field | [Agent](/agent/overview) |
| A PDF, Word, Excel or PowerPoint file | Its text as Markdown | [Parse](/parse/overview) |
| A site that needs clicks or a login | A browser you control | [Browser sessions](/browser/overview) |
| A site with a search box or a form | What the form returns | [Browser tasks](/browser/tasks) |
| A page that changes | A record of each change | [Monitors](/monitors/overview) |
