Search, read, and act on the web. Send a URL or a question and get Markdown, JSON or a finished task back. A failed call is free.

## Make a request

This call reads `example.com` as Markdown. It needs no API key. The TypeScript and Python tabs use the [SDK](/sdks).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Content-Type: application/json" \
  -d '{ "url": "https://example.com", "formats": ["markdown"], "onlyMainContent": true }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();
const { data } = await stophy.scrape({ url: "https://example.com", formats: ["markdown"], onlyMainContent: true });
console.log(data.markdown);
```
```python Python
from stophy import Stophy

stophy = Stophy()
result = stophy.scrape(url="https://example.com", formats=["markdown"], only_main_content=True)
print(result["data"]["markdown"])
```
</CodeGroup>

The page text is in `data.markdown`. `data.metadata` has the title, the site's status code and `costUsd`.

```json
{
  "success": true,
  "data": {
    "markdown": "This domain is for use in documentation examples without needing permission. …",
    "metadata": { "title": "Example Domain", "statusCode": 200, "costUsd": 0 }
  }
}
```

Other endpoints and more calls a minute need an API key. See the [Quickstart](/quickstart), or let your coding agent do the setup with the [Agent quickstart](/agent-quickstart).

## Choose an API

Crawl follows links from one URL to find pages. A batch reads a list of URLs you already have. Extract reads the pages you name. Agent searches for the pages itself.

| You have | You want | Use |
| - | - | - |
| A URL | The page as Markdown, links, a screenshot or JSON | [Scrape](/scrape/overview) |
| A URL on a site with its own data | A video, listing or profile as JSON | [Scrape with a parser](/scrape/prebuilt-parsers) |
| A site | Every URL on it | [Map](/map/overview) |
| A site | The content of many of its pages | [Crawl](/crawl/overview) |
| A list of URLs | Their content, as a background job | [Batches](/batches/overview) |
| A question | Ranked web, news, image, video or research results | [Search](/search/overview) |
| Pages and the fields you want | The values, each checked against the page | [Extract](/extract/overview) |
| A task in plain words | An answer with a quote for each field | [Agent](/agent/overview) |
| A PDF, Word, Excel or PowerPoint file | Its text as Markdown | [Parse](/parse/overview) |
| A site that needs clicks or a login | A browser you control | [Browser sessions](/browser/overview) |
| A site with a search box or a form | What the form returns | [Browser tasks](/browser/tasks) |
| A page that changes | A record of each change | [Monitors](/monitors/overview) |
