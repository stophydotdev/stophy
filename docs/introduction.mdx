Give your agents the live web. One API to search the web, read what people say, and look up products, places, jobs and homes.

You send a JSON request and get JSON back. Most calls cost $1.50 per 1,000. The call below needs no key.

```bash
curl -X POST https://api.stophy.dev/v1/google/search \
  -H "content-type: application/json" \
  -d '{"query":"postgres jsonb index"}'
```

<Accordion title="Response">
```json
{
  "success": true,
  "data": {
    "results": [
      {
        "type": "web",
        "url": "https://www.postgresql.org/docs/9.6/functions-json.html",
        "title": "PostgreSQL: Documentation: 9.6: JSON Functions and Operators",
        "description": "August 12, 2021 - Some further operators also exist only for jsonb, as shown in Table 9-43. Many of these operators can be indexed by jsonb operator classes.",
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 0,
  "requestId": "e4395adf-cdd4-4bd3-97cb-329e60df032c"
}
```
</Accordion>

That is page 1 of Google results, and `creditsUsed: 0` means it cost nothing. Without a key you get the first page only, up to 10 calls a minute and 50 a day. A key opens every endpoint and every page.

## Connect your agent

<CodeGroup>
```bash Claude Code
claude mcp add --transport http stophy https://api.stophy.dev/mcp
```

```bash Codex
codex mcp add stophy --url https://api.stophy.dev/mcp
```
</CodeGroup>

Your agent can call the free endpoints right away. To use every endpoint, sign in with your browser at `https://mcp.stophy.dev/mcp`. Every other client has its own page under [MCP server](/mcp-server).

## Search, then read

Most sites take two calls. Find posts with `reddit.search`, then open one with `reddit.post` to read its comments. Each call returns one page, and the response tells you how to get the next. `reddit.search` works without a key and `reddit.post` needs one. See [Page through results](/guides/paging).

## What it costs

- Most calls cost $0.0015, which is $1.50 per 1,000. Top up $100 or more and they cost $1.20 per 1,000, or $0.80 from $500.
- New accounts start with $1.50 free, enough for 1,000 calls.
- A call that fails or finds nothing costs nothing.

A few endpoints cost more. [Pricing](/billing) lists them.
