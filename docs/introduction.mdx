Stophy is one API for the live web. Your agent can:

- [Search](/api-reference/endpoint/search) the web, news and images.
- [Scrape](/api-reference/endpoint/scrape) any public page as markdown, HTML, links, a screenshot or JSON.
- [Map](/api-reference/endpoint/map) a site's pages, [crawl](/api-reference/endpoint/crawl) a site, or [batch scrape](/api-reference/endpoint/batch-scrape) many pages.
- [Extract](/api-reference/endpoint/extract) the fields you name from a page.
- Read a site's own data, like a Reddit search, a YouTube transcript or Google Maps places, through one of 103 [parsers](/guides/parsers).

Search, scrape, map and parse work without a key, within [free limits](/rate-limits).

## Connect your agent

<CodeGroup>
```bash Claude Code
claude mcp add --transport http stophy https://api.stophy.dev/mcp
```

```bash Codex
codex mcp add stophy --url https://api.stophy.dev/mcp
```
</CodeGroup>

Your agent can call the free endpoints right away. For every endpoint, add `https://mcp.stophy.dev/mcp` instead and sign in with your browser. [MCP server](/mcp-server) covers Cursor, Claude Desktop and other clients.
