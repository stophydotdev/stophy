## Connect your agent

<CodeGroup>
```bash Claude Code
claude mcp add --transport http stophy https://api.stophy.dev/mcp
```

```bash Codex
codex mcp add stophy --url https://api.stophy.dev/mcp
```
</CodeGroup>

Your agent can call the free endpoints right away. For all 137, add `https://mcp.stophy.dev/mcp` instead and sign in with your browser. [MCP server](/mcp-server) covers Cursor, Claude Desktop and other clients.
