Search, read, and act on the web. Stophy is one API that lets your agent search the web, read any page as Markdown or JSON, crawl a whole site, fill fields from pages, and drive a cloud browser when a page needs clicks. You pay in dollars for what you use, and a failed call is free.

## Make a request

Scrape is where most agents start. You send a URL and get the page back in the formats you list. This request returns the main content of `example.com` as Markdown. To try it without an API key, leave out the `Authorization` line of the cURL request, as the [Quickstart](/quickstart) does. That works up to 10 calls a minute and 50 a day, and the Quickstart gets you a key for more. The TypeScript and Python tabs use the [SDK](/sdks), from `npm install stophy` or `pip install stophy`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "formats": ["markdown"],
    "onlyMainContent": true
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { data } = await stophy.scrape({
  url: "https://example.com",
  formats: ["markdown"],
  onlyMainContent: true,
});
console.log(data.markdown);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.scrape(
    url="https://example.com",
    formats=["markdown"],
    only_main_content=True,
)
print(result["data"]["markdown"])
```
</CodeGroup>

The page text is in `data.markdown`. `data.metadata` holds the page title, the status code the site answered with, and `costUsd`, what the call cost in dollars. With a key, this one costs $0.001.

```json
{
  "success": true,
  "data": {
    "markdown": "This domain is for use in documentation examples without needing permission. …",
    "metadata": {
      "title": "Example Domain",
      "statusCode": 200,
      "costUsd": 0.001
    }
  }
}
```

## What you can do

* **Read a page.** [Scrape](/scrape/overview) returns Markdown, HTML, links, images, a screenshot, a summary or JSON in a shape you describe. Add [browser actions](/scrape/browser-actions) to click and type before the page is read.
* **Read a site's own data.** A [pre-built parser](/scrape/prebuilt-parsers) returns a video, a listing or a profile as JSON instead of page text.
* **Work on many pages.** [Map](/map/overview) lists a site's pages, [crawl](/crawl/overview) reads them in the background, and [batches](/batches/overview) read a list of URLs.
* **Find pages.** [Search](/search/overview) returns web, news, image, research and video results, and can read each result.
* **Pull fields.** [Extract](/extract/overview) fills the fields you name from pages, each checked against the page. [Agent](/agent/overview) searches and reads on its own to fill them.
* **Read files.** [Parse](/parse/overview) turns a PDF, Word, Excel, PowerPoint or HTML file, or a picture of text, into Markdown.
* **Use a browser.** [Browser sessions](/browser/overview) give you a cloud browser to drive with code or a prompt. [Browser tasks](/browser/tasks) click through a public site and return what they find.
* **Watch for changes.** [Monitors](/monitors/overview) check pages on a schedule and tell you what changed. They can send each change to a [webhook](/webhooks).

## Choose an API

Start from what you have. Two pairs get mixed up most. Crawl finds pages for you by following links from one URL, while a batch reads a list of URLs you already have. Extract reads the pages you name, while Agent searches for the pages on its own.

| You have | You want | Use |
| - | - | - |
| A URL | The page as Markdown, links, a screenshot or JSON | [Scrape](/scrape/overview) |
| A site | Every URL on it | [Map](/map/overview) |
| A site | The content of many of its pages | [Crawl](/crawl/overview) |
| A list of URLs | Their content, as a background job | [Batches](/batches/overview) |
| A question | Ranked web, news, image or research results | [Search](/search/overview) |
| Pages and the fields you want | The values, each checked against the page | [Extract](/extract/overview) |
| A task in plain words | An answer with a quote for each field | [Agent](/agent/overview) |
| A PDF, Word, Excel or PowerPoint file | Its text as Markdown | [Parse](/parse/overview) |
| A site that needs clicks or a login | A browser you control | [Browser sessions](/browser/overview) |
| A site with a search box or a form | What the form returns | [Browser tasks](/browser/tasks) |
| A page that changes | A record of each change | [Monitors](/monitors/overview) |
