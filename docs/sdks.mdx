Use an SDK to call Stophy from your app. Pick TypeScript or Python for installation and a first request. For terminal commands, use the [CLI](/install-cli).

| Language | Package | Install | Runs on |
| - | - | - | - |
| [TypeScript](/sdks/typescript) | [`stophy`](https://www.npmjs.com/package/stophy) | `npm install stophy` | Node.js, Bun, Deno and the browser |
| [Python](/sdks/python) | [`stophy`](https://pypi.org/project/stophy/) | `pip install stophy` | Python 3.9 or later |

## Set your API key

Set `STOPHY_API_KEY` to use endpoints that need a key or to go beyond the free limits. Both SDKs read it from the environment when you do not pass a key to the client. Keep it in your secret store or your project's `.env` file.

Keep the key in server-side code. Never commit it or ship it to a browser. The [Quickstart](/quickstart) shows where to get one. Without an API key, `scrape`, `search`, `map` and `parse` work within the [free limits](/production/rate-limits). `parsers`, `endpoints`, `signup` and `signup.poll` need no API key. Every other method fails with the code `apiKeyRequired`.

## Methods

Use this table to find the SDK method for an [API endpoint](/api-reference/introduction). The method returns the API response as JSON.

| Method | Endpoint |
| - | - |
| `scrape`, `search`, `map`, `parse` | `POST /v1/scrape`, `/v1/search`, `/v1/map`, `/v1/parse` |
| `parsed` | Scrape with a [parser](/scrape/prebuilt-parsers) |
| `parsers`, `endpoints` | `GET /v1/parsers`, `GET /v1/endpoints` |
| `crawl`, `crawl.status`, `crawl.cancel` | `/v1/crawl` and `/v1/crawl/{id}` |
| `batch.scrape`, `batch.scrape.status`, `batch.scrape.cancel` | `/v1/batch/scrape` and `/v1/batch/scrape/{id}` |
| `extract`, `extract.result` | `POST /v1/extract`, `GET /v1/extract/{id}` |
| `browser.task`, `browser.task.status` | `/v1/browser/task` and `/v1/browser/task/status` |
| `signup`, `signup.poll`, `key.revoke` | `/v1/signup`, `/v1/signup/poll`, `DELETE /v1/key` |
| `limits`, `usage`, `logs` | `GET /v1/limits`, `/v1/usage`, `/v1/logs` |

The SDKs have no methods for [agent](/agent/overview), [browser sessions](/browser/overview), [monitors](/monitors/overview), [webhooks](/webhooks), [feedback](/production/agent-feedback), usage history or the team calls. Call those over HTTP with the same API key.

## Timeouts and retries

Check these defaults before you add your own retries. Each attempt waits up to 70 seconds. Both SDKs retry eligible calls twice by default, using a backoff or the delay returned by the API. They stop if the requested delay exceeds 60 seconds. A `DELETE` is not retried.

Some writes cannot be safely replayed after a lost response. If a write may have run, the error can carry `outcomeUnknown` in TypeScript or `outcome_unknown` in Python. Check whether the work finished before making a new request. When a replayable write has an unresolved outcome, the error can carry its original idempotency key. Reuse that key and the same request body to recover the result; a new key can start new work.

For calls that accept a key, pass `idempotencyKey` in the TypeScript call options or `idempotency_key` in Python. For a `StophyError`, read the recovery key from `error.details.idempotencyKey` in TypeScript or `error.details["idempotencyKey"]` in Python. Network errors carry it as `idempotencyKey` in TypeScript or `idempotency_key` in Python. See [Timeouts](/production/timeouts).

## Handle errors

Catch `StophyError` to decide whether to retry or ask for a new key. Both SDKs include `code`, `retryable`, `retryAfterSeconds`, `status` and the `requestId`. The message says what went wrong and what to do next. The codes are the API's own. See [Troubleshooting](/production/troubleshooting).

A call your balance cannot cover fails with `insufficientCredits` and status `402`, and charges nothing. The message names your balance and the most the call can cost. Add money at [stophy.dev/billing](https://stophy.dev/billing) and send the call again. See [Pricing](/account/pricing).

`401` with `apiKeyRequired` means the call needs an API key. `401` with `unauthorized` means the key is wrong or has been revoked.
