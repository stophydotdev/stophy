Each parser reads one kind of page and returns the site's own data. Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. The data comes back in `data.json`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.linkedin.com/jobs/search?keywords=software%20engineer&location=United%20States&f_TPR=r604800","formats":[{"type":"json","parser":"linkedin-jobs"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.linkedin.com/jobs/search?keywords=software%20engineer&location=United%20States&f_TPR=r604800",
    formats: [{ type: "json", parser: "linkedin-jobs" }],
  }),
});
console.log(await response.json());
```

import os

import requests

response = requests.post(

## upwork-search

An Upwork job search page, like upwork.com/nx/search/jobs/?q=react.

- **Example page:** https://www.upwork.com/nx/search/jobs/?q=react&sort=recency
- **Returns:** A list of jobs: `results`, `cursor`, `page`, `total`.
- **Options:** `jobType`, `experienceLevel`, `workload` (Upwork's hours needed: full time, part time, or as needed. Only hourly jobs say this, so the search stays hourly), `duration` (Upwork's project length: under one month, one to three months, three to six months, or more than six months. Only hourly jobs say this, so the search stays hourly), `minHourlyRate` (Lowest hourly rate in USD. A job matches when its posted range overlaps this minimum, so 25 to 50 matches a minimum of 50. The search stays hourly), `maxHourlyRate` (Highest hourly rate in USD. Send it with minHourlyRate. The job's posted range overlaps both, and the search stays hourly), `page` (Page number, starting at 1).
- **Price:** 1 credit per call.
