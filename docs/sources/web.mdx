Each parser reads one kind of page and returns the site's own data. Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. The data comes back in `data.json`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://scholar.google.com/scholar?q=attention+is+all+you+need","formats":[{"type":"json","parser":"google-scholar"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://scholar.google.com/scholar?q=attention+is+all+you+need",
    formats: [{ type: "json", parser: "google-scholar" }],
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(

```

## google-scholar

A Google Scholar results page with a search in q or a cites id.

- **Example page:** https://scholar.google.com/scholar?q=attention+is+all+you+need
- **Returns:** `title`, `url`, `format`, `authors`, `publication`, `year`.
- **Options:** `citesId` (A result's citesId: lists the works that cite it, like Scholar's Cited by), `yearFrom` (Scholar's own Custom range: from this year), `yearTo` (Scholar's own Custom range: up to this year), `sort` (Scholar's own sort. Newest lists recent additions first), `type` (Scholar's own Any type, Review articles, or Case law), `includePatents`, `includeCitations` (Scholar's own include citations: works known only from citations), `page` (Page number, starting at 1).
- **Price:** 1 credit per call.

## google-patents

A Google Patents search page with q, inventor or assignee.

- **Example page:** https://patents.google.com/?q=solid+state+battery&assignee=Toyota
- **Returns:** `patentId`, `title`, `snippet`, `assignee`, `inventor`, `priorityDate`.
- **Options:** `inventor`, `office` (Google Patents' own Patent office, like US, EP, WO, CN or JP), `language`, `dateType` (Which date before and after compare: Google Patents' own date choice), `after`, `before`, `status`, `type`, `litigation` (Google Patents' own Litigation: has related litigation, or no known), `sort`, `page` (Page number, starting at 1).
- **Price:** 1 credit per call. Works without an API key.

## google-trends

A Google Trends explore page with search terms in q, or the trending now page. One term gives its related searches and several terms give their interest over time. Set options.view to related, interest or regions to pick that answer for the terms.

- **Example page:** https://trends.google.com/trends/explore?q=bitcoin&geo=US&date=today%2012-m
- **Returns:** `query`, `value`.
- **Options:** `searchType` (Google Trends' own search type: web, images, news, shopping or youtube), `category` (Google Trends' own top-level category), `resolution`, `country` (ISO 3166-1 alpha-2 country code, e.g. us. Any case is accepted), `time` (Google Trends' own Trending now time range), `status` (Google Trends' own Trend status: all, or only trends still rising), `sort` (Google Trends' own sort).
- **Price:** 1 credit per call.

<Accordion title="Example response">

```json
{
  "results": [
    {
      "query": "bitcoin price",
      "value": 100
    }
  ],
  "rising": [
    {
      "query": "spcx",
      "increasePercent": null,
      "isBreakout": true
    }
  ]
}
```

</Accordion>

## phone-numbers

Any public web page.

- **Example page:** https://www.hetzner.com/legal/legal-notice/
- **Returns:** `phone`, `pages`.
- **Options:** `country` (Two-letter country code for numbers written without a country prefix, such as DE. Without it the country comes from the page: its numbers with a prefix, its address and its domain ending).
- **Price:** 1 credit per call.

<Accordion title="Example response">

```json
{
  "url": "https://www.hetzner.com/legal/legal-notice/",
  "phones": [
    {
      "phone": "+1 555 0100",

        "https://www.hetzner.com/legal/legal-notice/",
        "https://www.hetzner.com/support/",
        "https://www.hetzner.com/unternehmen/ueber-uns/"
      ]
    }
  ]
}
```
