Each parser reads one kind of page and returns the site's own data. Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. The data comes back in `data.json`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.amazon.com/s?k=laptop&low-price=300&high-price=900&s=review-rank","formats":[{"type":"json","parser":"amazon-search"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.amazon.com/s?k=laptop&low-price=300&high-price=900&s=review-rank",
    formats: [{ type: "json", parser: "amazon-search" }],
  }),
});
console.log(await response.json());
```

import os

import requests

response = requests.post(
