Each parser reads one kind of page and returns the site's own data. Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. The data comes back in `data.json`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.zillow.com/homes/San-Francisco,-CA_rb/","formats":[{"type":"json","parser":"zillow-search"}]}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://www.zillow.com/homes/San-Francisco,-CA_rb/",
    formats: [{ type: "json", parser: "zillow-search" }],
  }),
});
console.log(await response.json());
```

## zillow-search

A Zillow search page for a place, like zillow.com/homes/San-Francisco,-CA_rb/.

- **Example page:** https://www.zillow.com/homes/San-Francisco,-CA_rb/
- **Returns:** A list of listings: `results`, `cursor`, `page`, `total`.
- **Options:** `status`, `minPrice`, `maxPrice`, `minBedrooms`, `maxBedrooms`, `minBathrooms`, `minSqft`, `maxSqft`, `minLotSize` (Zillow's own Lot size minimum, in square feet), `maxLotSize` (Zillow's own Lot size maximum, in square feet), `minYearBuilt` (Zillow's own Year built minimum), `maxYearBuilt` (Zillow's own Year built maximum), `maxHoa` (Zillow's own Max HOA: the highest monthly HOA fee in USD. 0 means no HOA fee), `minParkingSpots` (Zillow's own Parking spots filter: at least this many (1 to 4)), `daysOnZillow` (Zillow's own Days on Zillow filter: listed in the last 1, 7, 14, 30 or 90 days, or 6, 12, 24 or 36 months. For sold homes it means sold in the last N), `hasPool` (Zillow's own "Must have pool" filter. Only matching homes when true), `hasGarage` (Zillow's own "Must have garage" filter. Only matching homes when true), `hasAirConditioning` (Zillow's own "Must have A/C" filter. Only matching homes when true), `isWaterfront` (Zillow's own "Waterfront" filter. Only matching homes when true), `singleStory` (Zillow's own "Single-story only" filter. Only matching homes when true), `openHouse` (Zillow's own "Must have open house" filter. Only matching homes when true), `priceReduced` (Zillow's own "Must have price reduction" filter. Only matching homes when true), `has3dTour` (Zillow's own "Must have 3D Tour" filter. Only matching homes when true), `petsAllowed` (Zillow's own "Pets Allowed" filter. Only matching homes when true. Rentals only: needs status forRent), `homeTypes` (Zillow's own Home type filter. On rentals, apartment and condo are one Zillow category (apartments, condos and co-ops), so either one returns both), `sort` (Zillow's own sort. priceHigh, bedrooms, bathrooms, squareFeet and lotSize put the largest first, and priceLow the smallest. A rental building sits where its highest unit rent falls), `keywords` (Words the listing must mention, like "pool" or "fixer upper"), `page` (Page number, starting at 1).
- **Price:** 2 credits per call.
