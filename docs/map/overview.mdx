Map lists a site's URLs without reading the pages, so you can choose which to read.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/map \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com",
    "search": "sqlite",
    "limit": 5
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { links } = await stophy.map({
  url: "https://bun.com",
  search: "sqlite",
  limit: 5,
});
console.log(links.map((link) => link.url));
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.map(url="https://bun.com", search="sqlite", limit=5)
print([link["url"] for link in result["links"]])
```
</CodeGroup>

You get at most 5,000 URLs, subdomains included. Set `limit` from 1 to 100,000. Calls without a key list one host and have lower limits, see [Without a key](/production/rate-limits#without-a-key).

```json
{
  "success": true,
  "links": [
    { "url": "https://bun.com/reference/node/sqlite/constants/SQLITE_ANALYZE" },
    { "url": "https://bun.com/reference/node/sqlite/constants/SQLITE_ATTACH" }
  ]
}
```

The URLs are in `links`, best `search` match first. A row can also have `title` and `description`. A map lists what it finds in the time allowed, so it can miss pages.

## Fields

| Field | Default | What it does |
| - | - | - |
| `search` | none | Keep only URLs whose address, title or description has these words. |
| `sitemap` | `include` | `include` uses sitemaps and links, `only` lists what the sitemaps name, `skip` ignores them. |
| `includeSubdomains` | `true` | `false` lists only the host you sent. |
| `ignoreQueryParameters` | `true` | `false` keeps the `?query` part of each URL. |
| `timeout` | none | Stop after this many milliseconds, at least 1,000, and return what was found. |
| `location` | United States | `country` and `languages` to read the site from. |
| `ignoreCache` | `false` | `true` builds the list again instead of reusing one from the last 6 hours. |

## Errors

| Code | Cause | Fix |
| - | - | - |
| `503 sourceUnavailable` | The site, or its sitemap with `sitemap: "only"`, cannot be reached | Wait `retryAfterSeconds`, then retry |
| `404 notFound` | `sitemap: "only"` on a site with no sitemap | Send `sitemap: "include"` |
| `403 siteNotRead` | Stophy does not read this site | Use a [parser](/scrape/prebuilt-parsers) |
| `400 invalidRequest` | A private network URL | Send a public URL |

Every other code is in [Errors](/api-reference/errors).
