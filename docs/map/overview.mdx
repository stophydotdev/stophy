---
title: "Map"
description: "List the URLs of a website without reading the pages, optionally filtered by topic, in one request. Works without an API key."
---

Use Map to list a site's URLs before you choose which to read with [Scrape](/scrape/overview) or a [batch](/batches/overview). To read pages without choosing, use [Crawl](/crawl/overview).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/map \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com",
    "search": "sqlite",
    "includeSubdomains": false,
    "limit": 5
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { links } = await stophy.map({
  url: "https://bun.com",
  search: "sqlite",
  includeSubdomains: false,
  limit: 5,
});
console.log(links.map((link) => link.url));
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.map(
    url="https://bun.com",
    search="sqlite",
    include_subdomains=False,
    limit=5,
)
print([link["url"] for link in result["links"]])
```
</CodeGroup>

Map works without a key within the keyless limits in [Rate limits](/production/rate-limits). Get a key in the [Quickstart](/quickstart).

```json
{
  "success": true,
  "links": [
    { "url": "https://bun.com/reference/node/sqlite/constants/SQLITE_ANALYZE" },
    { "url": "https://bun.com/reference/node/sqlite/constants/SQLITE_ATTACH" }
  ]
}
```

`links` holds the URLs, best `search` matches first. An entry may also have `title` and `description`. The call is priced per call, not per URL. See [Pricing](/account/pricing).

| Field | Default | Effect |
| - | - | - |
| `url` | required | Any page of the site. |
| `search` | none | Keep URLs that match these words in the address, not the page text. Partial matches rank lower. |
| `limit` | 5000 | Most URLs, 1 to 100,000. |
| `sitemap` | `include` | `include` uses sitemaps and links, `only` lists what the sitemaps name, `skip` ignores them. |
| `includeSubdomains` | `true` | Also list subdomains such as `docs.bun.com`. `true` needs an API key, so keyless calls list one host. |
| `ignoreQueryParameters` | `true` | List each page once, without its `?query`. `false` keeps it. |
| `timeout` | none | Stop after this many milliseconds, at least 1,000, and return what was found. |
| `location` | United States | `country` and `languages` to read the site from. See [Location and headers](/scrape/location-and-headers). |
| `ignoreCache` | `false` | Build the list again instead of reusing one made in the last 6 hours. |

A map lists what it found in the time allowed, so it can miss pages, and a site that exposes few pages returns a short list. Fixes for these errors are in [Errors](/api-reference/errors):

- `503 sourceUnavailable`: the site cannot be reached.
- `403 siteNotRead`: the site is not read.
- `404 notFound`: `sitemap: "only"` on a site with no sitemap. Use `include`.
- `400 invalidRequest`: a private network URL, or `limit` above 100,000.
