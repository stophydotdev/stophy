Use Map to list the URLs on a site before you choose which pages to read. If you need their content and do not want to choose URLs yourself, use [Crawl](/crawl/overview).

## Make a request

Send a site URL and a small `limit` to try Map. The example asks for up to five URLs. For the SDK tabs, run `npm install stophy` or `pip install stophy`. You can use an [API key](/quickstart) or omit the bearer header to try Map free, up to 10 calls a minute and 50 a day per IP address. See [Rate limits](/production/rate-limits).

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/map \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com",
    "limit": 5
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { links } = await stophy.map({
  url: "https://bun.com",
  limit: 5,
});
for (const link of links) console.log(link.url, link.title);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.map(url="https://bun.com", limit=5)
for link in result["links"]:
    print(link["url"], link.get("title"))
```
</CodeGroup>

## Read the response

Read `links` for the URLs we found. Each entry has a `url`, with `title` and `description` when we know them. Read the `x-cost-usd` header to check the price of the call.

```json
{
  "success": true,
  "links": [
    {
      "url": "https://bun.com/"
    },
    { "url": "https://bun.com/404" },
    { "url": "https://bun.com/blog" }
  ]
}
```

## Options

Set a limit when you only need a sample. Set `ignoreCache` if you need a new list instead of one we made in the last six hours.

| Field | Type | Default | Effect |
| - | - | - | - |
| `url` | `string` | none | Any page of the site to map, such as `https://bun.com`. Required. |
| `limit` | `number` | `5000` | The most URLs to return, 1 to 100,000. |
| `timeout` | `number` | none | Stop looking after this many milliseconds, at least 1,000, and return what was found. |
| `location` | `object` | United States | `country` and `languages` to read the site from. See [Location and headers](/scrape/location-and-headers). |
| `ignoreCache` | `boolean` | `false` | Send `true` to build the list again instead of reusing one made in the last 6 hours. |

To narrow the list by topic, sitemap, subdomain or query string, see [Filter and search](/map/filter-and-search).

## Use the results

Pick the URLs you need and read them:

- [Scrape](/scrape/overview) reads one URL.
- [Batches](/batches/overview) read a list of URLs in the background.
- [Crawl](/crawl/overview) follows links from one URL on its own, without a list.

## Limits and errors

Check the error code before you try the same URL again. A short list can still be a successful result.

- A site that cannot be reached returns `503 sourceUnavailable`.
- `sitemap: "only"` on a site with no sitemap returns `404 notFound`. Send `sitemap: "include"` to list its pages instead.
- A site Stophy does not read returns `403 siteNotRead`.
- A URL on a private network returns `400 invalidRequest`.
- `includeSubdomains: true` without an API key returns `401 apiKeyRequired`. Without an API key, the list covers one host.
- A map lists what was found in the time allowed. It may not find every page of the site. A site that exposes few pages returns a short list.

## Price

$0.50 per 1,000 calls, whatever the length of the list. A call that fails costs nothing. See [Pricing](/account/pricing).

Choose another call if you need page content or have a query instead of a site URL.
