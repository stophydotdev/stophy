Use Map filters to get a short list of URLs before you scrape or batch them. `search` matches the address, not the text of the page.

## Make a request

Get an API key in the [Quickstart](/quickstart). This request keeps up to five URLs that match `sqlite`. It stays on the starting host and uses the sitemap as well as links on the site.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/map \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://bun.com",
    "search": "sqlite",
    "includeSubdomains": false,
    "sitemap": "include",
    "limit": 5
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const { links } = await stophy.map({
  url: "https://bun.com",
  search: "sqlite",
  includeSubdomains: false,
  sitemap: "include",
  limit: 5,
});
console.log(links.map((link) => link.url));
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.map(
    url="https://bun.com",
    search="sqlite",
    include_subdomains=False,
    sitemap="include",
    limit=5,
)
print([link["url"] for link in result["links"]])
```
</CodeGroup>

## Read the response

Read `links` for the matching URLs, best matches first. `costUsd` is the price of the Map call, not the price to read those pages.


## Options

Set these fields alongside `url` to decide where we look and how many URLs we return.

| Field | Type | Default | Effect |
| - | - | - | - |
| `search` | `string` | none | Keep only URLs that mention these words, best matches first, such as `pricing`. |
| `sitemap` | `string` | `"include"` | `include` uses the site's sitemaps and its pages. `only` lists what the sitemaps name. `skip` ignores the sitemaps. |
| `includeSubdomains` | `boolean` | `true` | Also list pages on subdomains, such as `docs.bun.com` for `bun.com`. Sending `true` needs an API key. |
| `ignoreQueryParameters` | `boolean` | `true` | List each page once, without its `?query` part. Send `false` to keep the `?query` part. |
| `limit` | `number` | `5000` | The most URLs to return, 1 to 100,000. Combine it with `search` to keep a short list. |

## Choose pages by topic

`search` ranks the list, so `limit: 20` returns the 20 URLs that match best. For a repeatable dataset, save the list before you send it to a [batch](/batches/overview). Use [Scrape](/scrape/overview) for the pages themselves.

## Limits and errors

Check whether your filters need a key or a sitemap before you send the request.

- `search` can be a word or several words. Matches that include only some of them rank lower.
- `sitemap: "only"` on a site with no sitemap returns `404 notFound`.
- `includeSubdomains: true` without an API key returns `401 apiKeyRequired`.
- `limit` above 100,000 returns `400 invalidRequest`.
