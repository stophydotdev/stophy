Call Stophy from Node.js, Bun, Deno or the browser and get typed results back.

```bash
npm install stophy
```

## Make a call

No account, no key.

```ts
import { Stophy } from "stophy";

const result = await new Stophy().google.search({ query: "postgres jsonb index" });
console.log(result.data.results);
```

Methods follow the endpoint id. `google.search` is `stophy.google.search(...)`, and `reddit.search` is `stophy.reddit.search(...)`. The inputs and results are typed, so a missing required field is a compile error.

## Use a key

A call that needs a key throws a `StophyError` with code `apiKeyRequired`.

Set `STOPHY_API_KEY` and `new Stophy()` picks it up. Or pass it in:

```ts
import { Stophy } from "stophy";

const stophy = new Stophy({ apiKey: process.env.STOPHY_API_KEY });
const posts = await stophy.reddit.search({ query: "bun runtime" });
console.log(posts.data.results.length, posts.creditsUsed);
```

`new Stophy("your key")` works too.

## Find endpoints

```ts
import { Stophy } from "stophy";

const catalog = await new Stophy().endpoints();
const free = catalog.endpoints.filter((endpoint) => endpoint.keyless);
console.log(catalog.endpoints.length, free.length);
```

## Page through results

When there is more, `data.cursor` is set. Pass it back for the next page. Paging needs a key.

```ts
import { Stophy } from "stophy";

const stophy = new Stophy();
let cursor: string | undefined;
for (let page = 1; page <= 2; page++) {
  const result = await stophy.reddit.search({ query: "bun runtime", cursor });
  console.log(result.data.results.length);
  cursor = result.data.cursor;
  if (!cursor) break;
}
```

Some endpoints take a `page` number instead, like `google.search`. See [Page through results](/guides/paging).

## Handle errors

```ts
import { Stophy, StophyError } from "stophy";

try {
  await new Stophy().reddit.search({ query: "bun runtime", cursor: "next" });
} catch (error) {
  if (error instanceof StophyError) {
    console.log(error.status, error.code, error.message);
    console.log(error.retryable, error.retryAfterSeconds, error.requestId);
  }
}
```

The SDK retries network errors and the statuses 429, 500, 502, 503 and 504 for you, and waits as long as the API asks. If the API asks for more than 60 seconds, it throws at once with `retryAfterSeconds` set. [Errors](/api-reference/errors) lists every code.

## Options

```ts
import { Stophy } from "stophy";

const stophy = new Stophy({
  apiKey: process.env.STOPHY_API_KEY,
  timeoutMs: 20_000,
  maxRetries: 3,
  retryInitialDelayMs: 500,
  headers: { "x-app": "my-app" },
});

const controller = new AbortController();
setTimeout(() => controller.abort(), 5_000);
await stophy.google.search({ query: "bun runtime" }, { signal: controller.signal });
```

| Option | Default | What it does |
| --- | --- | --- |
| `apiKey` | `STOPHY_API_KEY` | Your API key |
| `baseUrl` | `STOPHY_BASE_URL` or `https://api.stophy.dev` | Where requests go |
| `timeoutMs` | `70000` | Time limit for each attempt. A timed-out attempt is not retried. |
| `maxRetries` | `2` | Retries per request. `0` turns them off. |
| `retryInitialDelayMs` | `500` | Base delay before a retry. Each retry waits longer. |
| `headers` | none | Extra headers on every request |
| `fetch` | global `fetch` | Your own `fetch` |

## Check your usage

These need a key.

```ts
import { Stophy } from "stophy";

const stophy = new Stophy();

const usage = await stophy.usage();
console.log(usage.balanceMicros / 1_000_000, usage.creditsUsed, usage.requestCount);

const logs = await stophy.logs({ days: 7, endpoint: "reddit.search" });
for (const entry of logs.logs) {
  console.log(entry.createdAt, entry.endpoint, entry.credits);
}
```
