Call Stophy from TypeScript, Python or your terminal. All three call the same [API](/api-reference/introduction) and read `STOPHY_API_KEY` from your environment.

## Install

<CodeGroup>

```bash TypeScript icon="/images/icons/typescript.svg"
npm install stophy
```

```bash Python icon="python"
pip install stophy
```

```bash CLI icon="square-terminal"
curl -fsSL https://stophy.dev/install | bash
```

</CodeGroup>
