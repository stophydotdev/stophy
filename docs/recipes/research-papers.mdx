Find papers by title and abstract, then read open PDFs for the notes you want to cite. The index can return a paper without an abstract, so do not rely on it for the paper's claims.

You need an API key in `STOPHY_API_KEY`. See the [Quickstart](/quickstart). Paper search needs an API key.

## 1. Search for papers

Search before you open any PDFs. This request asks for up to 3 papers from 2024 onward, newest first.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search/research/papers \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "retrieval augmented generation",
    "k": 3,
    "from": "2024-01-01",
    "sort": "date_desc"
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/search/research/papers", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    query: "retrieval augmented generation",
    k: 3,
    from: "2024-01-01",
    sort: "date_desc",
  }),
});
const { results } = await response.json();
console.log(results.map((paper) => `${paper.year} ${paper.title}`));
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/search/research/papers",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "query": "retrieval augmented generation",
        "k": 3,
        "from": "2024-01-01",
        "sort": "date_desc",
    },
)
for paper in response.json()["results"]:
    print(paper["year"], paper["title"])
```
</CodeGroup>

Read the papers in `results`. Each can include `paperId`, `primaryId`, `title`, `abstract`, `authors`, `year`, `venue`, `citedByCount` and `openAccessUrl`. `primaryId` is the best outside ID. Look in `openAccessUrl` for a free copy, but check whether it is a PDF or a landing page. In this search, two of the three results had no abstract. Two links went straight to PDFs. The other went to a landing page. See [Papers](/search/papers) for search options.

## 2. Read a paper

Use Scrape to read a direct PDF link as Markdown. This request reads the first 2 pages of the third paper and cuts the text at 2,000 characters.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://aclanthology.org/2024.eacl-demo.16.pdf",
    "parsers": [{ "type": "pdf", "maxPages": 2 }],
    "maxChars": 2000
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://aclanthology.org/2024.eacl-demo.16.pdf",
    parsers: [{ type: "pdf", maxPages: 2 }],
    maxChars: 2000,
  }),
});
const { data } = await response.json();
console.log(data.metadata.totalPages, data.markdown);
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/scrape",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://aclanthology.org/2024.eacl-demo.16.pdf",
        "parsers": [{"type": "pdf", "maxPages": 2}],
        "maxChars": 2000,
    },
)
data = response.json()["data"]
print(data["metadata"]["totalPages"], data["markdown"])
```
</CodeGroup>

Read `data.markdown` for the text, and check `nextOffset` before you quote from it. The example cuts the returned text.

```json
{
  "success": true,
  "data": {
    "markdown": "Proceedings of the 18th Conference of the European Chapter of the Association for Computational Linguistics\nSystem Demonstrations, pages 150–158\n\n## RAGAS: Automated Evaluation of Retrieval Augmented Generation\n\nShahul Es†, Jithin James†, Luis Espinosa-Anke∗♢, Steven Schockaert∗\n…\n\nAbstract\nWe introduce RAGAS1 (Retrieval Augmented\nGeneration Assessment), a framework for\nreference-free evaluation of Retrieval Augmented Generation (RAG) pipelines. …",
    "nextOffset": 1969,
    "warning": "The page text was cut short. Send offset 1969 to read on.",
    "metadata": {
      "sourceURL": "https://aclanthology.org/2024.eacl-demo.16.pdf",
      "statusCode": 200,
      "contentType": "application/pdf",
      "numPages": 9,
      "totalPages": 9,
      "costUsd": 0.0015
    }
  }
}
```

`totalPages` is the pages in the file, 9 here. `nextOffset` says where to read on. Send the same request with `"offset": 1969`. Send a larger `maxPages` for more pages, and `pageMarkers: true` to see where each page starts. See [PDFs and documents](/scrape/pdfs-and-documents). The read cost $0.0015.

A landing page such as the DOI link in the second result is not a PDF. Scrape reads it as a page, and it may not hold the paper. Keep the papers whose link ends in `.pdf` or points at `arxiv.org/pdf`.

## 3. Read every paper

Repeat the PDF read for each result whose `openAccessUrl` points straight to a PDF. Skip landing pages. Keep the paper's `primaryId` as `id`, with its title, year and returned Markdown as `text`. Use the same ID when you see that paper again.

Each note is ready to hand to a model with the instruction to quote only from `text` and cite `id`. For a paper you hold as a file, [Parse documents](/parse/overview) gives the same Markdown from an upload.

## What to check

Check the paper and its text before asking a model to quote from it.

- `results` is not empty, and the papers match your topic. If not, change the query, or add `authors`, `from` and `to`.
- Check that each note contains the paper's title. A PDF can start with publication details before the title. If a PDF comes back empty, try `"mode": "ocr"` in the PDF options.
- The text you hand a model is cut at `maxChars`. Read on with `nextOffset` when the answer needs the methods or the results.
- A claim in your summary is a quote you can find in `text`. Check three.
