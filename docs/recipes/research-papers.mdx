Paper search finds papers by title and abstract. Many papers have no abstract in the index, so you read the paper itself. You search, keep the papers with an open PDF, and read the first pages of each with Scrape.

You need an API key in `STOPHY_API_KEY`. See the [Quickstart](/quickstart). Paper search needs an API key.

## 1. Search for papers

This request finds papers from 2024 on, newest first, and asks for 3.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search/research/papers \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "retrieval augmented generation",
    "k": 3,
    "from": "2024-01-01",
    "sort": "date_desc"
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/search/research/papers", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,

  },
  body: JSON.stringify({
    query: "retrieval augmented generation",
    k: 3,
    from: "2024-01-01",
    sort: "date_desc",
  }),
});
const { results } = await response.json();
console.log(results.map((paper) => `${paper.year} ${paper.title}`));
```

## 2. Read a paper

Scrape reads a PDF the way it reads a page and returns Markdown. This request reads the first 2 pages of the third paper and cuts the text at 2,000 characters.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://aclanthology.org/2024.eacl-demo.16.pdf",
    "parsers": [{ "type": "pdf", "maxPages": 2 }],
    "maxChars": 2000
  }'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/scrape", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://aclanthology.org/2024.eacl-demo.16.pdf",
    parsers: [{ type: "pdf", maxPages: 2 }],
    maxChars: 2000,
  }),
});
const { data } = await response.json();
console.log(data.metadata.totalPages, data.markdown);
```

`totalPages` is the pages in the file, 9 here. `nextOffset` says where to read on. Send the same request with `"offset": 1969`. Send a larger `maxPages` for more pages, and `pageMarkers: true` to see where each page starts. See [PDFs and documents](/scrape/pdfs-and-documents). The read cost $0.0015.

A landing page such as the second paper's is not a PDF. Scrape reads it as a page, and it may not hold the paper. Keep the papers whose link ends in `.pdf` or points at `arxiv.org/pdf`.

## 3. Read every paper

This function searches, keeps the papers with a direct PDF link, reads the first 2 pages of each, and returns notes with the id, title, year and text. The `id` is the paper's `primaryId`, so a citation points at the same paper wherever you saw it.

```typescript
interface Paper {
  primaryId: string;
  title: string;
  year?: number;
  openAccessUrl?: string;
}

async function post<Answer>(path: string, body: object): Promise<Answer> {
  const response = await fetch(`https://api.stophy.dev${path}`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(body),
  });
  return response.json();
}

export async function readPapers(query: string) {
  const { results } = await post<{ results: Paper[] }>("/v1/search/research/papers", {
    query,
    k: 3,
    from: "2024-01-01",
    sort: "date_desc",
  });
  const notes = [];
  for (const paper of results) {
    const link = paper.openAccessUrl;
    if (link === undefined || !/\.pdf$|arxiv\.org\/pdf\//.test(link)) continue;
    const { data } = await post<{ data: { markdown: string } }>("/v1/scrape", {
      url: link,
      parsers: [{ type: "pdf", maxPages: 2 }],
      maxChars: 2000,
    });
    notes.push({ id: paper.primaryId, title: paper.title, year: paper.year, text: data.markdown });
  }
  return notes;
}
```

Each note is ready to hand to a model with the instruction to quote only from `text` and cite `id`. For a paper you hold as a file, [Parse documents](/parse/overview) gives the same Markdown from an upload.

## What to check

- `results` is not empty, and the papers match your topic. If not, change the query, or add `authors`, `from` and `to`.
- Every note has a `text` that starts with the paper's title. If a PDF comes back empty, try `"mode": "ocr"` in the PDF options.
- The text you hand a model is cut at `maxChars`. Read on with `nextOffset` when the answer needs the methods or the results.
- A claim in your summary is a quote you can find in `text`. Check three.
