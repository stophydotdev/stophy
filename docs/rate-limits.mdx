## Limits

| | Limit |
| --- | --- |
| With a key | 600 requests a minute per account |
| Without a key | 10 requests a minute and 50 a day per IP address |

Without a key you can call the endpoints marked `keyless: true` in the [catalog](https://api.stophy.dev/v1/endpoints), over HTTP and [MCP](/mcp-server/keyless), for the first page only. [Sign up](https://stophy.dev/signup) to lift that.

Responses include the `X-RateLimit-Limit` and `X-RateLimit-Remaining` headers.

## When you go over

| Code | Status | What to do |
| --- | --- | --- |
| `rateLimited` | `429` | Wait for the `Retry-After` header, which is also `retryAfterSeconds` in the body, then retry. |
| `freeLimit` | `429` | Get a key at `signupUrl`, or wait for `retryAfterSeconds`. |

Both are marked `retryable: true`. [Errors and retries](/guides/errors-and-retries) has a retry loop.
