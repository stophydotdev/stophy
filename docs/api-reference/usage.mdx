Send your key and get back your balance and lifetime totals. The call is free.

```bash
curl https://api.stophy.dev/v1/usage \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```

<ResponseField name="balanceMicros" type="integer" required>
  Your balance in millionths of a dollar. Divide by 1,000,000 for dollars, so `1200000` is $1.20.
</ResponseField>

<ResponseField name="creditsUsed" type="integer" required>
  What all your calls have cost so far, in [cost units](/billing#cost-units).
</ResponseField>

<ResponseField name="requestCount" type="integer" required>
  How many paid calls you have made.
</ResponseField>

<RequestExample>
```bash cURL icon="terminal"
curl https://api.stophy.dev/v1/usage \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "balanceMicros": 1200000,
  "creditsUsed": 300,
  "requestCount": 120
}
```
</ResponseExample>

This response is not wrapped in `success` and `data`. Without a valid key it returns `401` with code `apiKeyRequired`.
