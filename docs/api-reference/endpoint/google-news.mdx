## Response

`data.results` lists the articles, each with its publisher and time.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "url": "https://www.reuters.com/business/nvidia-broadcom-shielded-ai-power-crunch-hits-chip-supply-chain-says-morgan-2026-10-05/",
        "title": "Nvidia, Broadcom shielded as AI power crunch hits chip supply chain, says Morgan Stanley",
        "source": "Reuters",
        "description": "Nvidia and Broadcom are relatively insulated from a worsening US data-center power crunch, but any ​resultant delay in…",
        "publishedAt": "2026-10-05T14:15:59.000Z",
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `source` | string | Publication that ran the article. |
| `page` | integer | The page number of this response. |
| `position` | integer | The 1-based position of the result in the list. |
| `publishedAt` | string (ISO 8601) | When the article was published. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. Send `query` or `topic`, not both. |
| `topic` | string | The top 10 headlines in one section, instead of a search. Send `query` or `topic`, not both. One of `world`, `nation`, `business`, `technology`, `entertainment`, `sports`, `science` or `health`. |
| `country` | string | Two-letter country code, like `us`. |
| `language` | string | Two-letter language code, like `en` or `pt`. |
| `includeDomains` | string[] | Only results from these domains. Up to 10 values. |
| `excludeDomains` | string[] | Leave out results from these domains. Up to 10 values. |
| `time` | string | Only results from this period. Leave it out for any time. One of `pastHour`, `past24Hours`, `pastWeek`, `pastMonth` or `pastYear`. |
| `sort` | string | By relevance, or newest first. One of `relevance` or `newest`. Defaults to `relevance`. |
| `page` | integer | Page number, starting at 1. From 1 to 10. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 10.
