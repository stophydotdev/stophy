## Response

`data.results` lists the comments, or the replies when you send `comment`.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "commentId": "7652752342874718983",
        "text": "the cameraman",
        "authorId": "7642245892504519701",
        "authorUsername": "fatimaart65",
        "authorName": "FatimaArtist 🎨",
        "authorUrl": "https://www.tiktok.com/@fatimaart65",
        "authorAvatarUrl": "https://p16-common-sign.tiktokcdn-us.com/tos-alisg-avt-0068/b3dcfceeddca1dc92f9dfc8ed794539c~tplv-tiktokx-cropcenter:10…",
        "likes": 4560,
        "replies": 19,
        "publishedAt": "2026-06-18T15:07:46.000Z"
      }
    ],
    "cursor": "20"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |
| `likes` | integer | The number of likes. |

<Note>Replies are best effort: TikTok sometimes shows only some of a comment's replies, so a list can come back shorter than the comment's replies count.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `comment` | string | A comment id from an earlier response. Returns that comment's replies. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
