## Response

`data` has the batch's progress when it stopped, and its cost in `creditsUsed`.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "id": "job_BC0vf8IzmDUA4VeGy9M7tA",
    "status": "completed",
    "total": 2,
    "completed": 2,
    "failed": 0,
    "creditsUsed": 2
  },
  "creditsUsed": 0,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `total` | integer | The total number of matching results, across all pages. |

## Price

This call is free. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
