## Response

`data` has the crawl's id and status, to follow with `web.crawl.status`.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "id": "job_Qg9km6Ss5DAJktZgPYOUkA",
    "status": "queued",
    "total": 1
  },
  "creditsUsed": 0,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `total` | integer | The total number of matching results, across all pages. |

<Note>It answers at once with an id; ask [Web Crawl Status](/api-reference/endpoint/web-crawl-status) for the pages, or send webhook to be told as each one finishes.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `goal` | string | What you are looking for, such as sqlite performance. Pages about it are read first, and the crawl stops once new pages stop mentioning it. |
| `includePaths` | string[] | Read only pages whose path matches one of these, such as /blog/*. Up to 20 values. |
| `excludePaths` | string[] | Skip pages whose path matches one of these, such as /tag/*. Up to 20 values. |
| `maxDepth` | integer | How many links away from the start page to go. From 1 to 10. Defaults to `3`. |
| `maxPages` | integer | Stop after reading this many pages in total, across every call. From 1 to 1000. Defaults to `100`. |
| `entireSite` | boolean | Read the whole site, not only pages under the start page's path. Defaults to `false`. |
| `includeSubdomains` | boolean | Also read pages on subdomains, such as docs.bun.com for bun.com. Defaults to `false`. |
| `onlyMainContent` | boolean | Keep only each page's main content, without menus, headers and footers. Defaults to `true`. |
| `webhook` | string | A public address that gets a JSON POST when the job starts, for each finished page, and when the job ends. If your address answers slowly, a page event can carry only the page url. Read that page with the status call. |

## Price

$0.0015 a page for most pages, $0.003 when a page takes more work to load, and $0.0075 for the hardest pages to reach. A page that cannot be read costs nothing. Each page is charged when it finishes. Starting the job is free. A call costs at most $7.50. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
