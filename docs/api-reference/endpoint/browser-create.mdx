## Price

$0.06 per hour open, $0.84 per hour once a prompt has run, billed when it closes, one minute at least. Traffic adds $5 per GB through the managed network location, the default, and $0.20 per GB direct or through your own proxy.

See [Pricing](/account/pricing).

```bash cURL
curl -X POST https://api.stophy.dev/v1/browser \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl":300,"activityTtl":60,"recording":true,"metadata":{"purpose":"docs-example"}}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/browser", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    ttl: 300,
    activityTtl: 60,
    recording: true,
    metadata: { purpose: "docs-example" },
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/browser",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "ttl": 300,
        "activityTtl": 60,
        "recording": True,
        "metadata": {"purpose": "docs-example"},
    },
)
print(response.json())
```
