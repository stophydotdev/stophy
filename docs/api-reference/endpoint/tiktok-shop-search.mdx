## Response

`data.results` lists the products, each with its price, units sold and shop.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "productId": "1732195217319498354",
        "title": "GummyGlow Brand New Upgrade Fruity Wax Gummies, 12oz Party-Ready Pack - 5 Sour Flavors, Crunchy ASMR Sweet Snacks,…",
        "productUrl": "https://shop.tiktok.com/us/pdp/fruitywax-bear-candy-12oz-pack-5-flavors-retro-party-treats/1732195217319498354",
        "price": 19.47,
        "currency": "USD",
        "sold": 28642,
        "rating": 4,

        "shopId": "7496048947258165874",
        "shopName": "Gummy Glow"
      }
    ],
    "cursor": "30::1732195217319498354,1729698659696480903,1729659431304270343,1732017016925885182,1732184216657432914,173206684122117…"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"

```

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | The number of reviews the rating is based on. |
| `sold` | integer | The number of units sold. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
