Scrape a Glassdoor company's ratings and details. Pick the company or companyName by its URL, ID or companyName.

## Request

Send exactly one of `companyUrl`, `companyId` or `companyName`. More than one, or none, fails with `invalidRequest`.

## Response

`data` has the company's ratings, size, industry and headquarters.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "companyId": "9079",
    "companyUrl": "https://www.glassdoor.com/Overview/Working-at-Google-EI_IE9079.11,17.htm",
    "name": "Google",
    "rating": 4.4,
    "reviews": 71507,
    "cultureRating": 4.2,
    "workLifeBalanceRating": 4.2,
    "payRating": 4.5,
    "managementRating": 3.9,
    "careerOpportunitiesRating": 4.2,
    "recommendPercent": 88,
    "ceoApprovalPercent": 84,
    "size": "10000+ Employees",
    "industry": "Internet & Web Services",
    "headquarters": "Mountain View, CA",
    "website": "https://goo.gle/4ehVuXi"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | Reviews in every language. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
