## Response

If successful, the response body contains the standard envelope. `data` contains the answer, the pages it cites in `sources` and the searches it ran in `searchQueries`.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "query": "What is the best CRM for a small business?",
    "answer": "## Best CRM for a Small Business in 2026\n\n**My top recommendation is HubSpot CRM for most small businesses.** It…",
    "sources": [
      {
        "url": "https://technologyadvice.com/small-business-crm/",
        "title": "Best CRM for Small Business in 2026",
        "domain": "technologyadvice.com"
      }
    ],
    "searchQueries": ["best CRM for small business 2026 pricing features HubSpot Zoho Pipedrive Freshsales"]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `answer` | string | The answer text returned by Google. |

For every field, see the response schema on this page.

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
