## Response

`data` has the answer, the pages it cites in `sources` and the searches it ran in `searchQueries`.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "query": "What is the best CRM for a small business?",
    "answer": "## Best CRM for a Small Business in 2026\n\n**My top recommendation is HubSpot CRM for most small businesses.** It…",
    "sources": [
      {
        "url": "https://technologyadvice.com/small-business-crm/",
        "title": "Best CRM for Small Business in 2026",
        "domain": "technologyadvice.com"
      }
    ],
    "searchQueries": ["best CRM for small business 2026 pricing features HubSpot Zoho Pipedrive Freshsales"]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `answer` | string | The answer text returned by Google. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
