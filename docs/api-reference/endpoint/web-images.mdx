## Response

`data.results` lists the images, each with its size, thumbnail and the page it is on.

This real response is cut to one item per list.

  "success": true,
  "data": {

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `safeSearch` | boolean | Hide explicit images. Defaults to `false`. |
| `limit` | integer | Return at most this many images. You pay $0.0015 per 10 returned. From 1 to 100. Defaults to `10`. |

## Price

$0.0015 per 10 images. A call costs at most $0.015. A call that fails or finds nothing is free. Send a smaller `limit` to get fewer items and pay less. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
