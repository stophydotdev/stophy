Use the secret to check Stophy-Signature on a webhook call: compute the HMAC-SHA256 of "`<t>`.`<body>`" and compare it with v1, then reject a call whose t is more than a few minutes old. Send rotate: true to get a new secret; the old one stops signing at once, so deploy the new one first or accept both for a while.
