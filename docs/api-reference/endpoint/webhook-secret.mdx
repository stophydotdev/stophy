Use the secret to check Stophy-Signature on a webhook call: compute the HMAC-SHA256 of "`<t>`.`<body>`" and compare it with v1, then reject a call whose t is more than a few minutes old.

<RequestExample>
```bash cURL
curl -X POST https://api.stophy.dev/v1/webhook/secret \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```
</RequestExample>
