## Response

`data` has the web results in `results`, Google's AI Overview when it shows one, related questions and related searches.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "aiOverview": {
      "text": "The best project management software depends on your team's specific workflow, size, and goals, with top platforms…"
    },
    "results": [
      {
        "type": "web",
        "url": "https://www.reddit.com/r/projectmanagement/comments/1dogwhv/looking_for_a_project_management_software_with/",
        "title": "Looking for a project management software with specific ...",
        "description": "Microsoft Access, Smartsuite, NocoDB, Fibery, Zoho Creator, Baserow), Asana is capable of this. Use Monday.com. Look…",
        "position": 1
      },
      {
        "type": "post",

      }
    ],
    "peopleAlsoAsk": [
      {
        "question": "Which is the most popular project management software?"
      }
    ],
    "relatedSearches": ["Best project management software reddit"],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"

```

| Field | Type | Description |
| --- | --- | --- |
| `type` | string | The kind of item: `web`, `news`, `video`, `post` or `place`. |
| `site` | string | Where the result was found, like YouTube or Reddit. |
| `publishedAt` | string (ISO 8601) | When it was published. For videos it is approximate, because Google shows only how long ago. |
| `page` | integer | The page number of this response. |
| `position` | integer | The 1-based position of the result in the list. |
| `aiOverview` | object | The Google AI Overview. Left out when Google shows none. |

<Note>Turn on scrapeResults to get the text of the top pages in the same call.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. |
| `language` | string | Two-letter language code, like `en` or `pt`. |
| `includeDomains` | string[] | Only results from these domains. Up to 10 values. |
| `excludeDomains` | string[] | Leave out results from these domains. Up to 10 values. |
| `time` | string | Only results from this period. Leave it out for any time. One of `pastHour`, `past24Hours`, `pastWeek`, `pastMonth` or `pastYear`. |
| `safeSearch` | boolean | Hide explicit results. Defaults to `false`. |
| `scrapeResults` | boolean | Also read the top results and add each page's text as markdown. Costs $0.0015 more for each result that comes back with its text. Defaults to `false`. |
| `scrapeLimit` | integer | How many of the top results to read when `scrapeResults` is on. From 1 to 5. Defaults to `3`. |
| `page` | integer | Page number, starting at 1. From 1 to 100. Defaults to `1`. |

## Price

$0.0015 per call, plus $0.0015 for each result that comes back with its page text when scrapeResults is on. A call costs at most $0.009. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 100. Requests without an API key return the first page only.
