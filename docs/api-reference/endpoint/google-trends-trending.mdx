## Response

`data.results` lists what is trending, each with its search volume and start time.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "query": "france vs belgium",
        "volume": 100000,
        "increasePercent": 1000,
        "startedAt": "2026-10-05T17:50:00.000Z",
        "isActive": true,
        "related": ["france vs belgium", "france national football team"],
        "categories": ["sports"],
        "trendUrl": "https://trends.google.com/trends/explore?q=france+vs+belgium&geo=US&date=now+1-d"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `volume` | number | The search volume of the trend. |
| `increasePercent` | number | The growth in search volume, as a percentage. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. Defaults to `us`. |
| `time` | string | How far back to look. One of `past4Hours`, `past24Hours`, `past48Hours` or `past7Days`. Defaults to `past24Hours`. |
| `category` | string | Only trends in this category. One of 19 values, like `autos`, `beautyFashion` and `business`. |
| `status` | string | All trends, or only the ones still rising. One of `all` or `active`. Defaults to `all`. |
| `sort` | string | How to order the trends. One of `relevance`, `searchVolume`, `recency` or `title`. Defaults to `relevance`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
