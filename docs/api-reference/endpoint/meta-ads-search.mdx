| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `firstShownAt` | string (ISO 8601) | The first day the ad was shown. |
| `countries` | string[] | Countries the Ad Library says the ad ran in. Meta sends none for most ads, so an empty list means unknown, not worldwide. It is not the country you searched. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, or `all`. Defaults to `us`. |
| `status` | string | Active ads, inactive ads or both. One of `active`, `inactive` or `all`. Defaults to `active`. |
| `mediaType` | string | Only ads of this type. `text` means no image or video. One of `image`, `video` or `text`. |
| `platforms` | string[] | Only ads shown on at least one of these platforms. One of `facebook`, `instagram`, `audienceNetwork`, `messenger`, `whatsapp` or `threads`. |
| `language` | string | Only ads written in this language. Two-letter code, like `en`. |
| `shownFrom` | string (date) | Only ads shown on or after this day. Format: `YYYY-MM-DD`. |
| `shownTo` | string (date) | Only ads shown on or before this day. Format: `YYYY-MM-DD`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
