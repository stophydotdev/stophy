## Response

`data.results` lists the jobs, each with its company, location and posting date.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "jobId": "4471906326",
        "jobUrl": "https://www.linkedin.com/jobs/view/4471906326",
        "title": "Software Engineer III, Foundation Services, Google Cloud",
        "companyName": "Google",
        "companyUrl": "https://www.linkedin.com/company/google",
        "companyAvatarUrl": "https://media.licdn.com/dms/image/v2/D4E0BAQGv3cqOuUMY7g/company-logo_100_100/B4EZmhegXHGcAU-/0/1759350753990/google_lo…",
        "location": "Kirkland, WA",
        "publishedAt": "2026-09-29T00:00:00.000Z",
        "insight": "Actively Hiring"
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |

<Note>When nothing matches your words, LinkedIn shows other jobs.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `location` | string | The city or area to search in. |
| `datePosted` | string | Only jobs posted in this period. One of `anyTime`, `pastMonth`, `pastWeek` or `past24Hours`. Defaults to `anyTime`. |
| `company` | object | One company, or up to five. Use LinkedIn links, slugs like `google`, or company ids. Accepts a string or an array of 1 to 5 strings. |
| `easyApply` | boolean | Only Easy Apply jobs. Defaults to `false`. |
| `fewApplicants` | boolean | Only jobs with fewer than 10 applicants. Defaults to `false`. |
| `page` | integer | Page number, starting at 1. From 1 to 100. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 100.
