## Response

`data.results` lists a page of the company's reviews, each with its rating, title, text and date.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "companyDomain": "stripe.com",
    "companyName": "Stripe",
    "total": 7019,
    "results": [
      {
        "reviewId": "6ac9d8b3d55b885799b7fd12",
        "reviewUrl": "https://www.trustpilot.com/reviews/6ac9d8b3d55b885799b7fd12",
        "rating": 1,
        "title": "Worst service ever",
        "text": "Worst service ever! There automated system just suspended my account in two days of creation. No support nothing. I…",
        "language": "en",
        "publishedAt": "2026-10-10T08:18:30.000Z",
        "experiencedDate": "2026-10-10",
        "isVerified": false,
        "authorName": "Sarmad Bashir",
        "authorCountry": "PK"
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `total` | integer | The total number of matching results, across all pages. |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |
| `rating` | integer | The average star rating, on a scale of 1 to 5. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `ratings` | integer[] | Only reviews with these star ratings, 1 to 5. Empty means every rating. Up to 5 values. |
| `language` | string | Only reviews in this language, as a two-letter code like `en`. Defaults to `all`. Defaults to `all`. |
| `datePublished` | string | Only reviews published in the last 30 days, 3, 6 or 12 months. One of `last30Days`, `last3Months`, `last6Months` or `last12Months`. |
| `verifiedOnly` | boolean | Only reviews Trustpilot marks as verified. Defaults to `false`. |
| `search` | string | Only reviews that mention this word or phrase. |
| `page` | integer | Page number, starting at 1. Trustpilot shows 10 pages of 20 reviews without an account; narrow with ratings, language, `datePublished` or search to reach older reviews. From 1 to 10. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 10.
