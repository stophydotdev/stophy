## Response

`data` has what the video says as one block of `text`.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "videoId": "7137423965982592302",
    "videoUrl": "https://www.tiktok.com/@charlidamelio/video/7137423965982592302",
    "language": "en",
    "isAutoGenerated": true,
    "durationSeconds": 11.12093696,
    "transcribedSeconds": 12,
    "text": "First time, first time, first time, look, you'll hear your eyes. What are you willing to do? All I tell you what…"
  },
  "creditsUsed": 4,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `text` | string | The whole transcript as one block. |
| `transcribedSeconds` | number | Seconds of audio that were transcribed when the video had no captions. The price depends on it. |
| `isAutoGenerated` | boolean | True when the captions were generated, not written by a person. |
| `durationSeconds` | number | The duration, in seconds. |

<Note>Without an API key it reads captions only.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `language` | string | Language code, like `en` or `pt-BR`. |
| `includeTimestamps` | boolean | Return each line with its start and end time, in `segments`. Defaults to `false`. |

<Note>Videos longer than 3 minutes are rejected with `invalidRequest`. Rejected requests are not billed.</Note>

## Price

$0.0015 when the video has captions; otherwise $0.003 plus $0.0015 for every 10 seconds of audio, up to 3 minutes. A call costs at most $0.03. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
