## Response

`data` has the business's rating, price level, categories, address, phone, website and hours.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "businessId": "MGzro82Fi4LYvc86acoONQ",
    "businessAlias": "franklin-barbecue-austin",
    "businessUrl": "https://www.yelp.com/biz/franklin-barbecue-austin",
    "name": "Franklin Barbecue",
    "rating": 4.5,
    "reviews": 6492,
```

| Field | Type | Description |
| --- | --- | --- |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | The number of reviews the rating is based on. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
