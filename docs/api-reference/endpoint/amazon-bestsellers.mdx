## Response

`data.results` lists the best sellers in the category, in rank order.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "category": "Electronics",
    "results": [
      {
        "rank": 1,
        "productId": "B08JHCVHTY",
        "productUrl": "https://www.amazon.com/dp/B08JHCVHTY",
        "title": "blink plus plan with monthly auto-renewal",
        "imageUrl": "https://images-na.ssl-images-amazon.com/images/I/31YHGbJsldL._AC_UL300_SR300,200_.png",
        "price": 11.99,
        "priceCurrency": "USD",
        "rating": 4.4,
        "reviews": 280840
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | The number of reviews the rating is based on. |
| `rank` | integer | The 1-based position of the entry in the list. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. One of 21 values, like `us`, `gb` and `de`. Defaults to `us`. |
| `page` | integer | Page number, starting at 1. From 1 to 2. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 2.
