<Note>Needs no API key.</Note>

Free, and needs no key. Answers 202 with status waiting until your person approves, so poll every few seconds. After approval it answers 200 with the key exactly once. A code that is unknown, expired or already collected is notFound: sign up again.

<RequestExample>
```bash cURL
curl -X POST https://api.stophy.dev/v1/signup/poll \
  -H "Content-Type: application/json" \
  -d '{"code":"<code>"}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/signup/poll", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ code: "<code>" }),
});
console.log(await response.json());
```
```python Python
import requests

response = requests.post(
    "https://api.stophy.dev/v1/signup/poll",
    json={"code": "<code>"},
)
print(response.json())
```
