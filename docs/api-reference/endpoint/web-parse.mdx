## Response

`data` has the file's text as markdown, with its metadata.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "markdown": "# How tides work\n\nThe Moon pulls on the oceans and makes two bulges of water that move around the Earth as it turns,…",
    "isTruncated": false,
    "metadata": {
      "title": "How tides work",
      "contentType": "text/html"
    }
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

<Note>To read a page or a PDF by its address, use [Web Scrape](/api-reference/endpoint/web-scrape).</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `filename` | string | The file's name, such as report.docx. The type is read from the file itself. |
| `maxPages` | integer | Read at most this many PDF pages, sheets or slides; `isTruncated` says when the file had more. From 1 to 100. Defaults to `100`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
