Scrape a Google Maps place's reviews. Pick the place by its URL or ID.

## Request

Send exactly one of `placeUrl` or `placeId`. Both, or none, fails with `invalidRequest`.

<Note>Works without an API key, for the first page only, up to 10 calls a minute and 50 a day.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `sort` | string | Which reviews come first. One of `relevance`, `newest`, `highest` or `lowest`. Defaults to `newest`. |
| `language` | string | Language code, like `en` or `pt-BR`. Defaults to `en`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
