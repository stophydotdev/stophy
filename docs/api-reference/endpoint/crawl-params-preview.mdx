Best to see what a crawl would do before starting it. Send the site's address and what you want, such as only the blog posts from this year. The answer holds the options to pass to crawl. A call that finds nothing to set is free.

<RequestExample>
```bash cURL
curl -X POST https://api.stophy.dev/v1/crawl/params-preview \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://bun.com/docs","prompt":"Only the runtime pages, at most 10"}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/crawl/params-preview", {
  method: "POST",

```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/crawl/params-preview",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://bun.com/docs",
        "prompt": "Only the runtime pages, at most 10",
    },
)
print(response.json())
```
