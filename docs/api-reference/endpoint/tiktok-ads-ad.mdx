| Field | Type | Description |
| --- | --- | --- |
| `firstShownAt` | string (ISO 8601) | The first day the ad was shown. |
| `lastShownAt` | string (ISO 8601) | The last day the ad was shown. |
| `reachMin` | integer | With `reachMax`, the range for the number of people the ad reached. |
| `impressionsMin` | integer | With `impressionsMax`, the range for the number of times the ad was shown. |
| `paidBy` | string | The entity that paid for the ad. |
| `countries` | string[] | The countries in which the ad was shown. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
