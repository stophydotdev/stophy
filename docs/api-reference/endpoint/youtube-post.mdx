| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `repliesCursor` | string | Send this as cursor to [YouTube Post](/api-reference/endpoint/youtube-post), with the same `postId`, to read this comment's replies. It does not work with [YouTube Comments](/api-reference/endpoint/youtube-comments). |
| `publishedAt` | string (ISO 8601) | Approximate: YouTube shows only how long ago a post was published, so this is rounded to that unit, such as a day or a year. |
| `likes` | integer | The number of likes. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `sort` | string | Which comments come first. One of `top` or `newest`. Defaults to `top`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
