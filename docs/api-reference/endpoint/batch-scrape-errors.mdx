## Failed pages

Lists up to 1,000 failed pages with `url`, `code`, `message`, `retryable` and `at`. `isTruncated` is `true` when there are more. Retry a page when `retryable` is `true`. A batch does not apply robots.txt, so `robotsBlocked` is always empty.

```bash cURL
  -H "Authorization: Bearer $STOPHY_API_KEY"
```
