Scrape a YouTube channel and its videos. Pick the channel by its URL or ID.

## Request

Send exactly one of `channelUrl` or `channelId`. Both, or none, fails with `invalidRequest`.

<Note>Works without an API key, for the first page only, up to 10 calls a minute and 50 a day.</Note>

| Field | Type | Description |

| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `type` | string | The kind of item: `video`, `playlist` or `post`. |

| `publishedAt` | string (ISO 8601) | Approximate: YouTube lists show only how long ago a video was published, so this is rounded to that unit, such as a day or a year. [YouTube Video](/api-reference/endpoint/youtube-video) has the exact time. |
| `durationSeconds` | integer | The duration, in seconds. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `tab` | string | Which tab of the channel to read. `releases` are a music channel's albums. One of `videos`, `shorts`, `live`, `playlists`, `podcasts`, `releases` or `posts`. Defaults to `videos`. |
| `sort` | string | How to order the items on the videos, shorts and live tabs. One of `latest`, `popular` or `oldest`. Defaults to `latest`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`. A cursor expires after 6 hours.
