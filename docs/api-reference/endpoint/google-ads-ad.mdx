## Response

`data` has the ad's advertiser, format and creative, and the countries it ran in.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "adId": "CR00462730911658541057",
    "adUrl": "https://adstransparency.google.com/advertiser/AR16735076323512287233/creative/CR00462730911658541057",
    "advertiserId": "AR16735076323512287233",
    "advertiserName": "Nike, Inc.",
    "advertiserUrl": "https://adstransparency.google.com/advertiser/AR16735076323512287233",
    "format": "text",
    "lastShownAt": "2026-10-05T20:27:35.000Z",
    "imageUrl": "https://tpc.googlesyndication.com/archive/simgad/5743239130676952852",
    "advertiserCountry": "US",
    "advertiserIsVerified": true,
    "paidBy": "Nike, Inc.",
    "variations": [
      {
        "imageUrl": "https://tpc.googlesyndication.com/archive/simgad/5743239130676952852"
      }
    ],
    "regions": [
      {
        "country": "US",
        "lastShownAt": "2026-09-01T00:00:00.000Z"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `lastShownAt` | string (ISO 8601) | The last day Google shows the ad in this country, as the start of that day in UTC. |
| `paidBy` | string | The entity that paid for the ad. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `advertiserId` | string | Advertiser id, like `AR18378488041124659201`. Send it with `adId`. A link already has it. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
