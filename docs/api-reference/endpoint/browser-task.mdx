Best for a few steps a person would click through on a public site, like a search with filters or a form to fill without sending it. It answers at once with an id; ask browser.task.status for the result. A task takes up to 20 steps and 3 minutes, and stops before anything that pays, books, sends, submits or deletes. Stophy never logs in to a site.

## Price

$0.006 for each step the task takes, up to maxSteps and maxCost. A task that ends before its first step costs nothing. Starting a task sets aside the most it can cost, and what it does not use comes back when it ends.

A credit costs $0.002, and less after larger top-ups. See [Pricing](/billing).

```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/browser/task", {
```

```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/browser/task",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "url": "https://news.ycombinator.com",
        "goal": "Open the newest stories and read the title of the first one",
        "schema": {
            "type": "object",
            "properties": {"title": {"type": "string"}},
        },
        "maxSteps": 4,
    },
)
print(response.json())
```
