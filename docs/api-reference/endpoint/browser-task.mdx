Best for a few steps a person would click through on a public site, like a search with filters or a form to fill without sending it. It answers at once with an id; ask browser.task.status for the result. A task takes up to 50 steps and 10 minutes, and stops before anything that pays, books, sends, submits or deletes. Stophy never logs in to a site.

## Price

$0.84 per hour of browser time the task runs, billed by the minute, one minute at least, up to maxCost. A task that ends before its first step costs nothing. Starting a task sets aside the most it can cost, and what it does not use comes back when it ends.

See [Pricing](/account/pricing).

<RequestExample>
```bash cURL
curl -X POST https://api.stophy.dev/v1/browser/task \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://news.ycombinator.com","goal":"Open the newest stories and read the title of the first one","schema":{"type":"object","properties":{"title":{"type":"string"}}},"maxSteps":4}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.browser.task({
  url: "https://news.ycombinator.com",
  goal: "Open the newest stories and read the title of the first one",
  schema: { type: "object", properties: { title: { type: "string" } } },
  maxSteps: 4,
});
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.browser.task(
    url="https://news.ycombinator.com",
    goal="Open the newest stories and read the title of the first one",
    schema={
        "type": "object",
        "properties": {"title": {"type": "string"}},
    },
    max_steps=4,
)
print(result)
```
