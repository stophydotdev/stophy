## Response

`data.results` lists the places, each with its type, address and link.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "placeId": "187591",
        "placeUrl": "https://www.tripadvisor.com/Hotel_Review-g186338-d187591-Reviews-The_Ritz_London_Hotel-London_England.html",
        "name": "The Ritz London Hotel",
        "type": "accommodation",
        "address": "150 Piccadilly",
        "parent": "London, England",
        "latitude": 51.507088,
        "longitude": -0.141628,
        "imageUrl": "https://dynamic-media-cdn.tripadvisor.com/media/photo-o/33/be/ef/d4/the-ritz-london-entrance.jpg?w=1200&h=900&s=1"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `type` | string | The kind of place. |
| `placeUrl` | string (URL) | Send it as `placeUrl` to get the place's details or reviews. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `type` | string | The kind of place. One of `all`, `hotels`, `restaurants`, `attractions` or `geos`. Defaults to `all`. |
| `location` | string | Narrow the search to this place. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
