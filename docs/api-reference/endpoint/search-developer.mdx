## Price

$0.001 for each 10 results; no results cost nothing.

See [Pricing](/account/pricing).

<RequestExample>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search/developer \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"bun sqlite","k":5}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/search/developer", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ query: "bun sqlite", k: 5 }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/search/developer",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={"query": "bun sqlite", "k": 5},
)
print(response.json())
```
