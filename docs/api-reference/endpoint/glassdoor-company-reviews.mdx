## Response

`data.results` lists the reviews, each with its rating, pros, cons and the reviewer's job title.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "companyId": "9079",
    "total": 66022,
    "totalAllLanguages": 71507,
    "results": [
      {
        "reviewId": "106005473",
        "rating": 5,
        "title": "Good place to work at",
        "pros": "Pay and benefits are good, WLB is good.",
        "cons": "Some bureaucracy, report chain is long.",
        "jobTitle": "Software Engineer",
        "location": "Waterloo, ON",
        "employmentStatus": "regular",
        "createdDate": "2026-10-17"
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `total` | integer | Reviews written in English. These are the ones this endpoint lists. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `page` | integer | Page number, starting at 1. From 1 to 500. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 500.
