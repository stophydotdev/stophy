## Response

`data` has the product's rating, and `results` lists the first page of its reviews.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "rating": 4,
    "reviews": 2956,
    "results": [
      {
        "reviewId": "7689658813176153870",
        "rating": 1,
        "text": "It said it was supposed to be crunchy it was not crunchy and didn’t taste good",
        "authorName": "f**s",
        "isVerified": true,
        "publishedAt": "2026-09-26T02:04:41.569Z",
        "country": "US",
        "imageUrls": ["https://p16-oec-general-useast5.ttcdn-us.com/tos-useast5-i-omjb5zjo8w-tx/ca205418263841dba0067240a5eea513~tplv-fhlh96ny…", "https://p16-oec-general-useast5.ttcdn-us.com/tos-useast5-i-omjb5zjo8w-tx/12ce5ce9ab5142a78b0a816658f3705c~tplv-fhlh96ny…"]
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | The number of reviews the rating is based on. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
