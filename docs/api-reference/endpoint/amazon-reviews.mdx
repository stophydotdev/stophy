## Response

`data.results` lists the reviews, each with its rating, text and whether the purchase is verified.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "productId": "B0CX23V2ZK",
    "results": [
      {
        "authorName": "MWW",
        "rating": 1,
        "title": "Trash",
        "text": "Apple has really gone down hill. They will eventually intentionally stop supporting the latest operating system, which…",
        "publishedAt": "2026-07-23T00:00:00.000Z",
        "country": "United States",
        "isVerified": true,
        "isVine": false,
        "helpfulVotes": 0
      }
    ],
    "cursor": "9XB9OW7DMjAyNi0xMC0xOFQyMDowMDo1MC43NDc5NjM0MTRaADEw"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `publishedAt` | string (ISO 8601) | The day the review was written, at midnight UTC. Amazon gives no time of day. |
| `rating` | integer | The average star rating, on a scale of 1 to 5. |

<Note>Returns reviews for few US products, since Amazon US shows reviews only after sign-in. For India, [Amazon Product](/api-reference/endpoint/amazon-product) with country in returns up to 13 reviews.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `rating` | integer | Only reviews with this star rating. From 1 to 5. |
| `verifiedOnly` | boolean | Only reviews from verified purchases. Defaults to `false`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
