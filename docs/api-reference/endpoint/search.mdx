Best when you want web results, news, images or all three at once, grouped by type, with the page text of the top web results if you ask for it.

<Note>Works without an API key, up to 10 calls a minute and 50 a day per IP. See [Rate limits](/rate-limits).</Note>

## Price

2 credits per 10 results from each source, plus 1 credit for each web result that comes back with its page text when scrapeOptions is on.

A credit costs $0.002, and less after larger top-ups. See [Pricing](/billing).

<RequestExample>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"nvidia earnings","sources":["web","news"],"limit":5}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/search", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    query: "nvidia earnings",
    sources: ["web", "news"],
    limit: 5,
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/search",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "query": "nvidia earnings",
        "sources": ["web", "news"],
        "limit": 5,
    },
)
print(response.json())
```
