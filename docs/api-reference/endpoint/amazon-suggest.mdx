## Response

`data.results` lists the suggestions, best first.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "keyword": "best running shoes for women",
        "rank": 1
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `rank` | integer | The 1-based position of the entry in the list. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. One of 21 values, like `us`, `ca` and `mx`. Defaults to `us`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
