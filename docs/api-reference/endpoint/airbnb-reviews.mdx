## Response

`data.results` lists a page of the listing's reviews, each with its rating, text and date.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "listingId": "53888412",
    "total": 337,
    "results": [
      {
        "reviewId": "1785576510399038758",
        "rating": 5,
        "text": "Très bel appartement. Très bien localisé au cœur du quartier Alfama. Endroit parfait, près des transports et lieux à…",
        "language": "fr",
        "translatedText": "Very nice apartment. Very well located in the heart of the Alfama district. Perfect location, close to public…",
        "createdAt": "2026-09-29T15:01:47.000Z",
        "authorName": "Isabelle",
        "stayNote": "Stayed a few nights"
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `total` | integer | The total number of matching results, across all pages. |
| `createdAt` | string (ISO 8601) | The creation time, in UTC. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `page` | integer | Page number, starting at 1. From 1 to 200. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 200.
