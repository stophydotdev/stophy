## Response

`data.results` lists the hotels, each with its price per night, total price, rating and amenities.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "checkIn": "2026-11-19",
    "checkOut": "2026-11-20",
    "results": [
      {
        "name": "Santa Luzia BB - HOrigem - Double Room, River View",
        "hotelId": "ChkQicjQ0reM7_U9Gg0vZy8xMXo0Y25fNDlzEAI",
        "hotelUrl": "https://www.google.com/travel/hotels/entity/ChkQicjQ0reM7_U9Gg0vZy8xMXo0Y25fNDlzEAI?hl=en&gl=us&curr=USD&ts=CAESCgoCCAM…",
        "price": 76,
        "totalPrice": 80,
        "priceCurrency": "USD",
        "rating": 5,
        "reviews": 8,
        "amenities": ["Sleeps 2", "7 bedrooms"],
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `price` | number | Lowest price per night. |
| `totalPrice` | number | For the whole stay, with taxes and fees. |
| `page` | string | The page number of this response. |
| `position` | integer | The 1-based position of the result in the list. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | The number of reviews the rating is based on. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `checkIn` | string (date) | The check-in date. Defaults to tomorrow. Format: `YYYY-MM-DD`. |
| `checkOut` | string (date) | The check-out date. Defaults to one night after `checkIn`. Format: `YYYY-MM-DD`. |
| `adults` | integer | How many adults. From 1 to 12. Defaults to `2`. |
| `childrenAges` | integer[] | One age for each child, like `[7, 12]`. Up to 8 values. |
| `currency` | string | Three-letter currency code, like `USD`. Defaults to `USD`. |
| `minPrice` | integer | Lowest price per night. |
| `maxPrice` | integer | Highest price per night. |
| `minRating` | string | Only hotels with at least this guest rating. One of `3.5+`, `4+` or `4.5+`. |
| `hotelClass` | integer[] | Only hotels with these star ratings, like `[4, 5]`. Up to 4 values. |
| `amenities` | string[] | Only hotels that offer every one of these. One of 19 values, like `freeWifi`, `freeBreakfast` and `restaurant`. |
| `propertyTypes` | string[] | Only these kinds of property. One of `beachHotels`, `boutiqueHotels`, `hostels`, `inns`, `motels`, `resorts`, `spaHotels`, `bedAndBreakfasts`, `other` or `apartmentHotels`. |
| `freeCancellation` | boolean | Only hotels you can cancel for free. Defaults to `false`. |
| `specialOffers` | boolean | Only hotels with special offers. Defaults to `false`. |
| `sort` | string | How to order the hotels. One of `relevance`, `lowestPrice`, `highestRating` or `mostReviewed`. Defaults to `relevance`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
