## Response

`data.results` lists the ads, each with its advertiser, text and images.

This real response is cut to one item per list.

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `total` | integer | The total number of matching results, across all pages. |

<Note>Only [LinkedIn ad details](/api-reference/endpoint/linkedin-ads-ad) returns run dates, impressions and who paid, and only for ads shown in the EU. To get them, set an EU country.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `advertiser` | string | Only ads from this advertiser. |
| `country` | string | Two-letter country code, like `us`. |
| `within` | string | Only ads shown in the last 30 days or the last year. One of `month`, `year` or `all`. Defaults to `all`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
