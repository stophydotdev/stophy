## Response

`data` has the post's text and author, and its exact likes, replies, reposts, quotes, bookmarks and views.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "postId": "2107773105779167621",
    "postUrl": "https://x.com/NASA/status/2107773105779167621",
    "text": "LIVE: After nearly eight months aboard the @Space_Station, it’s time for Crew-12 to come home. Tune in as the…",
    "publishedAt": "2026-10-07T10:00:43.000Z",
    "language": "en",
    "likes": 2021,
    "replies": 106,
    "reposts": 331,
    "quotes": 29,
    "bookmarks": 102,
    "views": 2868815,
    "authorId": "11348282",
    "authorUsername": "NASA",
    "authorName": "NASA",
    "authorUrl": "https://x.com/NASA",
    "authorAvatarUrl": "https://pbs.twimg.com/profile_images/1321163587679784960/0ZxKlEKB_400x400.jpg",
    "authorIsVerified": true,
    "links": ["https://x.com/i/broadcasts/1aKbdEQgXAdJX"],
    "mentions": ["Space_Station"],
    "isEdited": false,
    "isSensitive": false
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"

```

| Field | Type | Description |
| --- | --- | --- |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |
| `likes` | integer | The number of likes. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
