## Response

`data` has the batch's progress and its cost so far in `creditsUsed`, and `results` lists the pages read so far.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "id": "job_BC0vf8IzmDUA4VeGy9M7tA",
    "status": "completed",
    "total": 2,
    "completed": 2,
    "failed": 0,
    "creditsUsed": 2,
    "results": [
      {
        "markdown": "[Bun RuntimeA fast JavaScript runtime designed as a drop-in replacement for Node.jsGet started with `bun…",
```

| Field | Type | Description |
| --- | --- | --- |
| `total` | integer | The total number of matching results, across all pages. |

<Note>Send the cursor from the last answer to get only the pages finished since. A batch and its pages are kept for 24 hours.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

This call is free. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
