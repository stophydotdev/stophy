## Response

`data` has the profile's bio, followers and post count.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "userId": "28829152388",
    "username": "nasa",
    "userUrl": "https://www.threads.com/@nasa",
    "name": "NASA",
    "bio": "Making the seemingly impossible, possible. ✨",
    "isVerified": true,
    "isPrivate": false,
    "followers": 12764861,
    "threads": 144,
    "avatarUrl": "https://scontent-lax3-1.cdninstagram.com/v/t51.82787-19/669747085_18089786557960389_922072622069351626_n.jpg?stp=dst-jp…"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

<Note>followers is exact. threads is the count Threads shows, which it rounds above 1,000 (1.6K comes back as 1600).</Note>

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
