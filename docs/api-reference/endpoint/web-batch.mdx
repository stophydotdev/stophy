## Response

`data` has the batch's id and status, to follow with `web.batch.status`.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "id": "job_BC0vf8IzmDUA4VeGy9M7tA",
    "status": "queued",
    "total": 2
  },
  "creditsUsed": 0,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `total` | integer | The total number of matching results, across all pages. |

<Note>It answers at once with an id; ask [Web Batch Status](/api-reference/endpoint/web-batch-status) for the pages, or send webhook to be told as each one finishes.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `webhook` | string | A public address that gets a JSON POST when the job starts, for each finished page, and when the job ends. If your address answers slowly, a page event can carry only the page url. Read that page with the status call. |
| `formats` | object[] | What to return: markdown (clean page text), html (the cleaned page), `rawHtml` (the page as sent), links (every link on the page), screenshot (a link to a JPEG of the visible page, kept for 7 days), changes (what changed in the markdown since your key last read this page with the same options, kept 30 days) and network (the JSON the page loaded while it rendered, up to 30 responses). Send `{ "type": "screenshot", "fullPage": true }` for the whole page. Send `{ "type": "highlights", "query": "refund policy" }` for the passages that best match a query. A screenshot or network costs $0.003, or $0.0075 on the hardest pages to reach. A PDF comes back as markdown only. Up to 8 values. |
| `onlyMainContent` | boolean | Keep only the page's main content, without menus, headers, footers and ads. Defaults to `true`. |
| `includeTags` | string[] | Keep only the parts of the page that match these CSS selectors, such as article or .price. When set, `onlyMainContent` is not applied. Up to 20 values. |
| `excludeTags` | string[] | Remove the parts of the page that match these CSS selectors, such as .comments. Up to 20 values. |
| `waitFor` | integer | Extra milliseconds to wait before reading, for pages that load their content late. To wait for an element, add a wait action with a selector. A read that waits costs $0.003, or $0.0075 on the hardest pages to reach. From 0 to 10000. |
| `timeout` | integer | How long to keep trying, in milliseconds. Pages behind a bot check can need 10 to 30 seconds the first time. From 10000 to 60000. Defaults to `30000`. |
| `maxAge` | integer | Accept a stored answer up to this many milliseconds old. 0 always reads the page live. metadata.`cacheState` says which one you got. From 0 to 172800000. Defaults to `3600000`. |
| `location` | object | Where to read the page from. The default is the United States. |
| `actions` | object[] | Steps to run on the page, in order, before reading it: `{ "type": "wait", "milliseconds": 500 }`, `{ "type": "wait", "selector": ".results" }`, `{ "type": "click", "selector": "button.more" }`, `{ "type": "write", "text": "tides" }`, `{ "type": "press", "key": "Enter" }` or `{ "type": "scroll", "direction": "down" }`. A read with actions costs $0.003, or $0.0075 on the hardest pages to reach. Up to 20 values. |
| `linkStyle` | string | How links appear in the markdown. inline keeps `[text](address)`. numbered writes Pricing⟨3⟩ and lists each address once at the end. none keeps only the link text, which makes link-heavy pages 10 to 70% shorter; ask for the links format to get the addresses. One of `inline`, `numbered` or `none`. Defaults to `inline`. |
| `maxChars` | integer | Cut the markdown at this many characters; `isTruncated` says when that happened. From 500 to 1000000. |

## Price

$0.0015 a page for most pages, $0.003 when a page takes more work to load, and $0.0075 for the hardest pages to reach. A read with a screenshot, actions or waitFor costs $0.003, or $0.0075 on the hardest pages to reach. An answer from a stored copy costs $0.0015. A page that cannot be read costs nothing. Each page is charged when it finishes. Starting the job is free. A call costs at most $0.75. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
