## Pages

Poll until `status` is `completed`, `failed` or `cancelled`, then call `next` until it is gone. Each answer holds up to 100 finished pages or 2 MB. A page's URL is in `metadata.url`. See [Read the results](/batches/results).

`failed` counts the pages that could not be read. `errors` lists the failed pages in this answer with `url`, `code`, `message`, `retryable` and `at`, and `error` is set only when the whole job failed. For every failed page, call [Batch scrape errors](/api-reference/endpoint/batch-scrape-errors).
