## Response

`data.results` lists the pages read, each with its depth and its text as markdown.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "pagesRead": 4,
    "results": [
      {
        "url": "https://bun.com/docs",
        "title": "Welcome to Bun | Bun Docs",
        "depth": 0,
        "markdown": "[Bun RuntimeA fast JavaScript runtime designed as a drop-in replacement for Node.jsGet started with `bun…"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `depth` | integer | The nesting level of the comment in the thread. Top-level comments are 0. |

<Note>Set goal to read the pages about one topic first and stop when the site has no more about it. Use [Web Map](/api-reference/endpoint/web-map) to only list pages.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `goal` | string | What you are looking for, such as sqlite performance. Pages about it are read first, and the crawl stops once new pages stop mentioning it. |
| `includePaths` | string[] | Read only pages whose path matches one of these, such as /blog/*. Up to 20 values. |
| `excludePaths` | string[] | Skip pages whose path matches one of these, such as /tag/*. Up to 20 values. |
| `maxDepth` | integer | How many links away from the start page to go. From 1 to 10. Defaults to `3`. |
| `maxPages` | integer | Stop after reading this many pages in total, across every call. From 1 to 1000. Defaults to `100`. |
| `entireSite` | boolean | Read the whole site, not only pages under the start page's path. Defaults to `false`. |
| `includeSubdomains` | boolean | Also read pages on subdomains, such as docs.bun.com for bun.com. Defaults to `false`. |
| `onlyMainContent` | boolean | Keep only each page's main content, without menus, headers and footers. Defaults to `true`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

$0.0015 a page for most pages, $0.003 when a page takes more work to load, and $0.0075 for the hardest pages to reach. A page that cannot be read costs nothing. Each call reads up to 4 pages. A call costs at most $0.03. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
