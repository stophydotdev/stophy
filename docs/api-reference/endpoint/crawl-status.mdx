## Pages

Poll until `status` is `completed`, `failed` or `cancelled`, then call `next` until it is gone. An answer holds up to 100 finished pages or 2 MB, and a page's URL is in `metadata.url`. See [Read the results](/crawl/async).

`failed` counts the pages that could not be read. `errors` lists the failed pages in this answer, and `error` is set only when the whole job failed. [Crawl errors](/api-reference/endpoint/crawl-errors) lists every failed page.

curl https://api.stophy.dev/v1/crawl/job_qqmWroHTkWk61kDjA32Q3g \
  -H "Authorization: Bearer $STOPHY_API_KEY"
