## Response

`data.results` lists the listings, each with its title, price, city and photo.

This real response is cut to one item per list.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `minPrice` | integer | Lowest price in local currency (e.g., 50). From 0 to 1000000000. |
| `maxPrice` | integer | Highest price in local currency (e.g., 500). From 0 to 1000000000. |
| `sort` | string | Sort order (newest, `priceLow` or `priceHigh`), relevance by default. One of `newest`, `priceLow` or `priceHigh`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
