Scrape a Google Play app's reviews. Pick the app by its URL or ID.

## Request

Send exactly one of `appUrl` or `appId`. Both, or none, fails with `invalidRequest`.

<Note>Works without an API key, for the first page only, up to 10 calls a minute and 50 a day.</Note>

## Response

`data.results` lists the app's reviews, each with its rating, text and app version.

This real response is cut to one item per list.

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |
| `rating` | integer | The average star rating, on a scale of 1 to 5. |
| `likes` | integer | The number of likes. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `language` | string | Language code, like `en` or `pt-BR`. Defaults to `en`. |
| `sort` | string | Which reviews come first. One of `newest`, `relevance` or `highest`. Defaults to `newest`. |
| `rating` | integer | Only reviews with this many stars. From 1 to 5. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
