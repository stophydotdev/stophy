## Response

If successful, the response body contains the standard envelope. `data.results[]` contains the listings, newest first, each with its title, price, location and link.

The following example is a real response, truncated: each list shows one item and long strings are cut.

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Search words (e.g., "road bike"). Leave out to list the newest in the category. |
| `radius` | integer | Miles around the ZIP code, 25 by default. Must be between 1 and 250. If unset, defaults to `25`. |
| `category` | string | Specifies which listings to search, `forSale` by default. Acceptable values are `forSale`, `carsAndTrucks`, `apartments`, `housing`, `jobs`, `gigs`, `services` and `free`. If unset, defaults to `forSale`. |
| `minPrice` | integer | The minimum price in US dollars (e.g., 50). Must be between 0 and 100000000. |
| `maxPrice` | integer | The maximum price in US dollars (e.g., 500). Must be between 0 and 100000000. |
| `limit` | integer | The maximum number of listings to return. Billed at 1 credit per 10 returned. Must be between 1 and 360. If unset, defaults to `20`. |

## Billing

A successful request consumes 1 credit per 10 listings, up to 36 credits. Requests that fail, or that return no items, are not billed. Set `limit` to cap the number of items returned and billed.

## Pagination

This method is not paginated. A single request returns the complete result.
