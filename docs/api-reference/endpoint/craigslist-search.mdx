## Response

`data.results` lists the listings, newest first, each with its title, price, location and link.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "totalResults": 719,
    "results": [
      {
        "listingId": "7951123997",
        "listingUrl": "https://www.craigslist.org/view/d/san-mateo-got-gary-fisher-klunker/2qNKE1a54sBSCGGXEBiaaj",
        "title": "Got A Gary Fisher Klunker Panther Diamondback LAWWILL Pro Cruiser !?🤔",
        "price": 123,
```

| Field | Type | Description |
| --- | --- | --- |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |

<Note>Listings come newest first, at most 360 per search, so narrow with filters when totalResults is higher.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Search words (e.g., "road bike"). Leave out to list the newest in the category. |
| `radius` | integer | Miles around the ZIP code, 25 by default. From 1 to 250. Defaults to `25`. |
| `category` | string | Which listings to search, `forSale` by default. One of `forSale`, `carsAndTrucks`, `apartments`, `housing`, `jobs`, `gigs`, `services` or `free`. Defaults to `forSale`. |
| `minPrice` | integer | Lowest price in US dollars (e.g., 50). From 0 to 100000000. |
| `maxPrice` | integer | Highest price in US dollars (e.g., 500). From 0 to 100000000. |
| `limit` | integer | Return at most this many listings. You pay $0.0015 per 10 returned. From 1 to 360. Defaults to `20`. |

## Price

$0.0015 per 10 listings. A call costs at most $0.054. A call that fails or finds nothing is free. Send a smaller `limit` to get fewer items and pay less. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
