Best for a few facts from one page, like a price, a date or a list of names. Every field is checked against the page text and comes back null when the page does not state it. Use scrape for the whole page.

## Price

5 credits for most pages: the page's own price plus 4 credits. A call that finds none of the fields is free.

See [Pricing](/billing) for what credits cost.

<RequestExample>
```bash cURL
curl -X POST https://api.stophy.dev/v1/extract \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"urls":["https://bun.com/docs/runtime/bunfig"],"schema":{"type":"object","properties":{"file":{"type":"string"}}},"prompt":"What is the name of the configuration file this page describes?"}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/extract", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    urls: ["https://bun.com/docs/runtime/bunfig"],
    schema: { type: "object", properties: { file: { type: "string" } } },
    prompt: "What is the name of the configuration file this page describes?",
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/extract",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "urls": ["https://bun.com/docs/runtime/bunfig"],
        "schema": {
            "type": "object",
            "properties": {"file": {"type": "string"}},
        },
        "prompt": "What is the name of the configuration file this page describes?",
    },
)
print(response.json())
```
