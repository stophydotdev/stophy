## Response

`data.results` lists the regions, each with one value for each query.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "code": "CH",
        "name": "Switzerland",
        "values": {
          "bitcoin": 100
        }
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `values` | object | Search interest for each query, relative to the peak value of 100. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. |
| `time` | string | How far back to look. One of `pastHour`, `past4Hours`, `pastDay`, `past7Days`, `past30Days`, `past90Days`, `past12Months`, `past5Years` or `since2004`. Defaults to `past12Months`. |
| `searchType` | string | Where the searches were made. One of `web`, `images`, `news`, `shopping` or `youtube`. Defaults to `web`. |
| `category` | string | Only searches in this category. One of 25 values, like `artsEntertainment`, `autosVehicles` and `beautyFitness`. |
| `resolution` | string | How finely to split the results by place. One of `country`, `region` or `metro`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
