Scrape a Pinterest pin. Pick the pin by its URL or ID.

## Request

Send exactly one of `pinUrl` or `pinId`. Both, or none, fails with `invalidRequest`.

<Note>Works without an API key, for the first page only, up to 10 calls a minute and 50 a day.</Note>

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
