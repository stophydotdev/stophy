## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `chart` | string | Which chart to read. One of `free`, `paid` or `grossing`. Defaults to `free`. |
| `device` | string | The device the apps must run on, iphone, ipad or mac. An `iPhone` app can also run on an `iPad` or a Mac, so it can show under more than one. One of `iphone`, `ipad` or `mac`. Defaults to `iphone`. |
| `genre` | string | Only apps in this genre. One of 24 values, like `business`, `weather` and `utilities`. |
| `country` | string | Two-letter country code, like `us`. Defaults to `us`. |
| `limit` | integer | Return at most this many apps. You pay $0.0015 per 10 returned. From 1 to 100. |

## Price

$0.0015 per 10 apps. A call costs at most $0.015. A call that fails or finds nothing is free. Send a smaller `limit` to get fewer items and pay less. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
