Best for finding the right page on a site before reading it with scrape. Add search to rank pages about one topic first.

<Note>Works without an API key, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits).</Note>

## Price

$0.50 per 1,000 calls.

See [Pricing](/account/pricing).

<RequestExample>
```bash cURL
curl -X POST https://api.stophy.dev/v1/map \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://bun.com","search":"sqlite"}'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const result = await stophy.map({ url: "https://bun.com", search: "sqlite" });
console.log(result);
```
```python Python
from stophy import Stophy

stophy = Stophy()

result = stophy.map(url="https://bun.com", search="sqlite")
print(result)
```
