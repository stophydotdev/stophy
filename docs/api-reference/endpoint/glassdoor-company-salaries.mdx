## Response

`data.results` lists pay by job title, with the low, median and high total and base pay.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "companyId": "9079",
    "country": "United States",
    "total": 9187,
    "results": [
      {
        "jobTitle": "Software Engineer",
        "reports": 51206,
        "totalPayMin": 251389,
        "totalPayMedian": 311696,
        "totalPayMax": 396274,
        "basePayMin": 156159,
        "basePayMedian": 184723,
        "basePayMax": 218512,
        "payCurrency": "USD",
        "payPeriod": "year"
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `total` | integer | Job titles with pay reports in this country. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Country the pay is reported for, as its English name like India or Germany. Defaults to the United States. |
| `page` | integer | Page number, starting at 1. From 1 to 100. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 100.
