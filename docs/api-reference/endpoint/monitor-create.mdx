## Price

$1 per 1,000 pages read, for every check. A json mode adds $3 per 1,000 pages when it returns something, and a judged change adds $1 per 1,000 pages.

See [Pricing](/account/pricing).

```python Python
import os

import requests

    "https://api.stophy.dev/v1/monitor",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "name": "Docs example",
        "targets": [
            {
                "type": "scrape",
                "urls": ["https://bun.com/docs/runtime/bunfig"],
            },
        ],
        "schedule": {"text": "daily"},
    },
)
```
