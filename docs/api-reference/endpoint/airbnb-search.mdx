## Response

`data.results` lists the stays, each with its total price, price per night, rating and photos.

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | Number of reviews Airbnb shows for the stay, the same as total in [Airbnb Reviews](/api-reference/endpoint/airbnb-reviews). A room in a larger property shares the property's reviews. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `guests` | integer | Number of guests. Only stays that fit this many. From 1 to 16. Defaults to `1`. |
| `minPrice` | integer | Airbnb's own price range minimum: the nightly price after discounts and before taxes, in currency. |
| `maxPrice` | integer | Airbnb's own price range maximum: the nightly price after discounts and before taxes, in currency. |
| `roomType` | string | Airbnb's own Type of place filter: `entireHome` (Entire home) or `privateRoom` (Room). One of `entireHome` or `privateRoom`. |
| `currency` | string | Currency of every price in the answer and of `minPrice` and `maxPrice`. One of `USD`, `EUR`, `GBP`, `JPY`, `CAD`, `AUD`, `CHF`, `MXN` or `BRL`. Defaults to `USD`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
