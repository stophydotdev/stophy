## Response

If successful, the response body contains the standard envelope. `data` contains the answer and the pages it cites in `sources`.

The following example is a real response, truncated: each list shows one item and long strings are cut.

```json
{
  "success": true,
  "data": {
    "query": "What is the best CRM for a small business?",
    "answer": "The \"best\" CRM for a small business depends heavily on your budget, your technical setup, and whether your primary…",
    "sources": [
      {
        "url": "https://helpmonks.com/blog/best-crm-tools-small-businesses-2026/",
        "title": "10 Best CRM Tools for Small Businesses in 2026 - Helpmonks",
        "domain": "helpmonks.com"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| `answer` | string | The answer text returned by Google. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

This method is not paginated. A single request returns the complete result.
