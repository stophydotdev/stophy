## Response

`data` has the answer and the pages it cites in `sources`.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "query": "What is the best CRM for a small business?",
    "answer": "The \"best\" CRM for a small business depends heavily on your budget, your technical setup, and whether your primary…",
    "sources": [
      {
        "url": "https://helpmonks.com/blog/best-crm-tools-small-businesses-2026/",
        "title": "10 Best CRM Tools for Small Businesses in 2026 - Helpmonks",
        "domain": "helpmonks.com"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `answer` | string | The answer text returned by Google. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
