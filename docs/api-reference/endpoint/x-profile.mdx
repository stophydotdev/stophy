Scrape an X profile. Pick the profile or user by its URL or username.

## Request

Send exactly one of `profileUrl` or `username`. Both, or none, fails with `invalidRequest`.

<Note>Works without an API key, for the first page only, up to 10 calls a minute and 50 a day.</Note>

## Response

`data` has the profile's bio, followers, following, post count and join date.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "userId": "11348282",
    "username": "NASA",
    "profileUrl": "https://x.com/NASA",
    "name": "NASA",
    "bio": "Making the seemingly impossible, possible. ✨",
    "location": "Pale Blue Dot",
    "website": "http://www.nasa.gov/",
    "joinedAt": "2007-12-19T20:20:32.000Z",
    "followers": 92329477,
    "following": 115,
    "posts": 74412,
    "isVerified": true,
    "verifiedType": "Government",
    "isProtected": false,
    "avatarUrl": "https://pbs.twimg.com/profile_images/1321163587679784960/0ZxKlEKB_400x400.jpg",
    "bannerUrl": "https://pbs.twimg.com/profile_banners/11348282/1788992290"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `posts` | integer | The number of posts. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
