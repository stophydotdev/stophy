## Response

`data` has the emails, phone numbers and social profiles the site publishes.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "url": "https://plausible.io/",
    "emails": [
      {
        "email": "name@example.com",
        "pages": ["https://plausible.io/contact"]
      }
    ],
    "socials": [
      {
        "network": "x",
        "username": "PlausibleHQ",
        "url": "https://x.com/PlausibleHQ",
        "pages": ["https://plausible.io/", "https://plausible.io/contact"]
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

<Note>Reads the page you send and the contact, imprint and about pages it links to. Use [Web Scrape](/api-reference/endpoint/web-scrape) to read a page in full.</Note>

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
