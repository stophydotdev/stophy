Scrape a YouTube video's transcript. Pick the video by its URL or ID.

## Request

Send exactly one of `videoUrl` or `videoId`. Both, or none, fails with `invalidRequest`.

<Note>Works without an API key, for the first page only, up to 10 calls a minute and 50 a day.</Note>

## Response

`data` has what the video says as one block of `text`.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "videoId": "p0fybvFyOlM",
    "videoUrl": "https://www.youtube.com/watch?v=p0fybvFyOlM",
    "language": "ar",
    "isAutoGenerated": true,
    "durationSeconds": 799,
    "text": "يا للهول. شيء جديد على وشك الحدوث. حسناً، سنرى شيئاً جديداً قادماً من OpenAI. هذا صحيح. سنحصل على شيء مذهل. وهل تعرف…"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `text` | string | The whole transcript as one block. |
| `isAutoGenerated` | boolean | True when YouTube wrote the captions, not a person. |
| `language` | string | The language of the transcript. |
| `durationSeconds` | number | The duration, in seconds. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `language` | string | Language code, like `en` or `pt-BR`. |
| `includeTimestamps` | boolean | Return each line with its start and end time, in `segments`. Defaults to `false`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
