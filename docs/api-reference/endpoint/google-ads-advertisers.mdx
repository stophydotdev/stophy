## Response

`data.results` lists the advertisers that match, each with a range for how many ads it runs.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "advertiserId": "AR06641858037806006273",
        "advertiserName": "Nike",
        "advertiserCountry": "KE",
        "advertiserUrl": "https://adstransparency.google.com/advertiser/AR06641858037806006273",
        "isVerified": false,
        "adsMin": 1,
        "adsMax": 1
      }
    ],
    "domains": ["nike.sk"]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `adsMin` | integer | With `adsMax`, the range for how many ads the advertiser runs. |
| `domains` | string[] | Domains that match your query. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Country code like de. Advertisers are matched on ads shown in this country, wherever the advertiser is based, and `adsMin` and `adsMax` count only the ads shown there. |
| `limit` | integer | How many advertisers to ask Google for, 1 to 100. Google ranks the list for the count you ask, so a larger limit is not the same list with more rows added, and there are no further pages. Fewer come back when Google has fewer matches. From 1 to 100. Defaults to `10`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Send a smaller `limit` to get fewer items. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
