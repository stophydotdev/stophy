## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. Defaults to `us`. |
| `language` | string | Language code, like `en` or `pt-BR`. Defaults to `en`. |
| `limit` | integer | Return at most this many apps. You pay $0.0015 per 10 returned. From 1 to 50. |

## Price

$0.0015 per 10 apps. A call costs at most $0.0075. A call that fails or finds nothing is free. Send a smaller `limit` to get fewer items and pay less. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
