## Response

`data.results` lists the articles, each with its source, description and time.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "url": "https://finance.yahoo.com/markets/stocks/article/nvidia-stock-trims-losses-as-chip-sell-off-eases-amid-ai-financing-con…",
        "title": "Nvidia stock trims losses as chip sell-off eases amid AI financing concerns",
        "source": "Yahoo! Finance",
        "description": "Nvidia and other big chip stocks pared losses as AI jitters eased on Thursday.",
        "publishedAt": "2026-10-15T20:00:34.000Z",
        "position": 1
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `position` | integer | The 1-based position of the result in the list. |
| `publishedAt` | string (ISO 8601) | When the article was published. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. |
| `time` | string | Only articles from the past week, month or year. Leave out for any time. One of `pastWeek`, `pastMonth` or `pastYear`. |
| `limit` | integer | Return at most this many articles. You pay $0.0015 per 10 returned. From 1 to 50. Defaults to `10`. |

## Price

$0.0015 per 10 articles. A call costs at most $0.0075. A call that fails or finds nothing is free. Send a smaller `limit` to get fewer items and pay less. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
