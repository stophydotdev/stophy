## Response

`data.results` lists the flight options, each with its price, airlines, stops, times and legs.

| Field | Type | Description |
| --- | --- | --- |
| `price` | number | Total fare in `priceCurrency` for all adults together. For a round trip it covers both directions. |
| `legs` | object[] | The outbound journey only, including a return search. |
| `departureLocalTime` | string | Local time at the airport, YYYY-MM-DDTHH:mm, no time zone. |
| `isBest` | boolean | True for the options Google marks as best. |
| `durationSeconds` | integer | The duration, in seconds. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `returnDate` | string | The return date. Leave it out for a one-way trip. Format: `YYYY-MM-DD`. |
| `adults` | integer | How many adults. From 1 to 9. Defaults to `1`. |
| `cabin` | string | The cabin class. One of `economy`, `premiumEconomy`, `business` or `first`. Defaults to `economy`. |
| `currency` | string | Three-letter currency code, like `USD`. Defaults to `USD`. |
| `stops` | string | How many stops to allow. One of `any`, `nonstop`, `oneStopOrFewer` or `twoStopsOrFewer`. Defaults to `any`. |
| `airlines` | string[] | Only these airlines, as codes like `KQ` or `EK`. Up to 10 values. |
| `carryOnBags` | integer | Include this many carry-on bags in the price. From 0 to 1. Defaults to `0`. |
| `checkedBags` | integer | Include this many checked bags in the price. From 0 to 2. Defaults to `0`. |
| `maxPrice` | integer | Highest price, in `currency`, for all adults. |
| `departureTime` | object | Limit the outbound departure to these hours of the day. An object with `earliest` and `latest`, each an hour from 0 to 24. |
| `arrivalTime` | object | Limit the outbound arrival to these hours of the day. An object with `earliest` and `latest`, each an hour from 0 to 24. |
| `maxDurationHours` | integer | Longest trip, in hours. From 1 to 48. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
