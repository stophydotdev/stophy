Scrape an App Store app's reviews. Pick the app by its URL or ID.

## Request

Send exactly one of `appUrl` or `appId`. Both, or none, fails with `invalidRequest`.

<Note>Works without an API key, for the first page only, up to 10 calls a minute and 50 a day.</Note>

## Response

`data.results` lists a page of the app's reviews.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "reviewId": "14626635924",
        "rating": 1,
        "title": "Junk",
        "text": "Way too many adds, shows more posts from people that i don’t know than the people im friends with. Oh and did i…",
        "authorName": "JmichaelA1981",
        "publishedAt": "2026-10-04T12:57:24.000Z",
        "isEdited": false
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |
| `rating` | integer | The average star rating, on a scale of 1 to 5. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. |
| `sort` | string | Which reviews come first. One of `newest`, `helpful`, `highest` or `lowest`. Defaults to `newest`. |
| `page` | integer | Page number, starting at 1. From 1 to 500. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 500.
