## Response

`data.results` lists the papers, books and cases, each with its authors, year and the number of works that cite it.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "title": "Seven-year efficacy of RTS, S/AS01 malaria vaccine among young African children",
        "url": "https://www.nejm.org/doi/abs/10.1056/NEJMoa1515257",
        "format": "pdf",
        "authors": ["A Olotu", "G Fegan"],
        "publication": "England Journal of …",
        "year": 2016,
        "publisher": "Mass Medical Soc",
        "snippet": "… In an analysis that was not prespecified, the malaria exposure of each child was estimated … of malaria among…",
        "citations": 618,
        "citesId": "15871362944033457094",
        "versions": 14,
        "pdfUrl": "https://www.nejm.org/doi/pdf/10.1056/NEJMoa1515257",
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `citesId` | string | Send as `citesId` to list the works that cite this one. |
| `citations` | integer | How many works cite this one. |
| `format` | string | Scholar's tag, like [PDF] or [BOOK]. |
| `publication` | string | Journal or venue; the case citation for case law. |
| `page` | integer | The page number of this response. |
| `position` | integer | The 1-based position of the result in the list. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `citesId` | string | A result's `citesId`. Lists the works that cite it. |
| `yearFrom` | integer | Only works from this year on. From 1700 to 2027. |
| `yearTo` | integer | Only works up to this year. From 1700 to 2027. |
| `sort` | string | How to order the results. `newest` lists recent additions first. One of `relevance` or `newest`. Defaults to `relevance`. |
| `type` | string | Any type, review articles or case law. One of `any`, `reviewArticles` or `caseLaw`. Defaults to `any`. |
| `includePatents` | boolean | Include patents in the results. Defaults to `false`. |
| `includeCitations` | boolean | Include works that Scholar knows only from citations. Defaults to `true`. |
| `page` | integer | Page number, starting at 1. From 1 to 20. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 20.
