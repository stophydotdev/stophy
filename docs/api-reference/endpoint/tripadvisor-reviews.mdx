## Response

`data` names the place, and `results` lists a page of its reviews.

| Field | Type | Description |

| `page` | integer | The page number of this response. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `language` | string | The language of the reviews, or `all`. Defaults to `en`. |
| `ratings` | integer[] | Only reviews with these star ratings, from 1 to 5. Up to 5 values. |
| `travelerTypes` | string[] | Only reviews from these travelers. One of `families`, `couples`, `solo`, `business` or `friends`. Up to 5 values. |
| `months` | string[] | Only reviews written in these months of the year. One of `marMay`, `junAug`, `sepNov` or `decFeb`. Up to 4 values. |
| `sort` | string | `mostRecent` puts the newest first. `detailed` orders by recency and by how much a review says. One of `mostRecent` or `detailed`. Defaults to `mostRecent`. |
| `page` | integer | Page number, starting at 1. From 1 to 500. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 500.
