## Response

`data.results` lists the ads, each with its advertiser and how many people it reached.

This real response is cut to one item per list.

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `total` | integer | How many ads match. Null when TikTok caps the count at 5000 for a large search. |
| `firstShownAt` | string (ISO 8601) | The first day the ad was shown. |
| `lastShownAt` | string (ISO 8601) | The last day the ad was shown. |
| `reachMin` | integer | With `reachMax`, the range for the number of people the ad reached. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | A keyword to find in ads. Send this or advertiser, not both. |
| `advertiser` | string | Only ads from this advertiser name. |
| `country` | string | Two-letter code of a European country, like `de`. TikTok shows ads for these countries only. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
