## Response

`data` has the person's headline, location, about text, roles and education.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "profileId": "satyanadella",
    "profileUrl": "https://www.linkedin.com/in/satyanadella",
    "name": "Satya Nadella",
    "headline": "Chairman and CEO at Microsoft",
    "location": "Redmond, Washington, United States",
    "about": "As chairman and CEO of Microsoft, I define my mission and that of my company as empowering every person and every…",
    "followers": 12205170,
    "roles": [
      {
        "title": "Chairman and CEO",
        "companyName": "Microsoft",
        "companyUrl": "https://www.linkedin.com/company/microsoft",
        "from": "Feb 2014",
        "isCurrent": true
      }
    ],
    "education": [
      {
        "school": "The University of Chicago Booth School of Business",
        "schoolUrl": "https://www.linkedin.com/school/universityofchicagoboothschoolofbusiness",
        "from": "1994",
        "to": "1996"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `roles` | object[] | The person's jobs. `isCurrent` marks the current one. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
