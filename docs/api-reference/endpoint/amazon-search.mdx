## Response

`data.results` lists the products, each with its price, rating and review count.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "productId": "B0HDB41H28",
        "productUrl": "https://www.amazon.com/dp/B0HDB41H28",
        "title": "Wireless Earbuds, Bluetooth 5.3 Headphones HiFi Stereo 50H Playback LED Digital Display Ear Buds with ENC Noise…",
        "imageUrl": "https://m.media-amazon.com/images/I/618n7fFdFXL._AC_UY218_.jpg",
        "price": 18.98,
        "originalPrice": 249.99,
        "priceCurrency": "USD",
        "rating": 4.6,
        "reviews": 270,
        "boughtPastMonth": 4000,
        "isSponsored": false
      }
    ],
    "total": 27654,
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `total` | integer | The total number of matching results, across all pages. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | The number of reviews the rating is based on. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `category` | string | The category to search in, by name or id. |
| `minPrice` | number | Lowest price. |
| `maxPrice` | number | Highest price. |
| `minRating` | number | Only products rated at least this high. |
| `brand` | string | Only products from this brand. |
| `sort` | string | How to order the products. `avgCustomerReview` puts the highest rated first, not the most reviewed. One of `relevance`, `priceLow`, `priceHigh`, `avgCustomerReview`, `newest` or `bestSelling`. Defaults to `relevance`. |
| `country` | string | Two-letter country code, like `us`. One of 21 values, like `us`, `gb` and `de`. Defaults to `us`. |
| `page` | integer | Page number, starting at 1. From 1 to 20. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 20.
