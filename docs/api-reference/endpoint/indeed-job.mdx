## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. One of 62 values, like `us`, `gb` and `ca`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
