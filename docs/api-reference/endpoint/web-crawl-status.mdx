## Response

`data` has the crawl's progress and its cost so far in `creditsUsed`, and `results` lists the pages read so far.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "id": "job_Qg9km6Ss5DAJktZgPYOUkA",
    "status": "completed",
    "total": 4,
    "completed": 4,
    "failed": 0,
    "creditsUsed": 4,
    "results": [
      {
        "url": "https://bun.com/docs",
        "title": "Welcome to Bun | Bun Docs",
        "depth": 0,
        "markdown": "[Bun RuntimeA fast JavaScript runtime designed as a drop-in replacement for Node.jsGet started with `bun…"
      }
    ]
  },
  "creditsUsed": 0,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `total` | integer | The total number of matching results, across all pages. |
| `depth` | integer | The nesting level of the comment in the thread. Top-level comments are 0. |

<Note>Send the cursor from the last answer to get only the pages finished since. total is the number of pages found so far and grows while the crawl runs. A crawl and its pages are kept for 24 hours.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

This call is free. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
