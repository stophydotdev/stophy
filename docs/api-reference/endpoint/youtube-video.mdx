Scrape a YouTube video page. Pick the video by its URL or ID.

## Request

Send exactly one of `videoUrl` or `videoId`. Both, or none, fails with `invalidRequest`.

<Note>Works without an API key, for the first page only, up to 10 calls a minute and 50 a day.</Note>

## Response

`data` has the video's title, channel, stats, description and tags, plus chapters and most replayed moments when it has them.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "videoId": "p0fybvFyOlM",
    "videoUrl": "https://www.youtube.com/watch?v=p0fybvFyOlM",
    "title": "A total disaster",
    "channelId": "UCUyeluBRhGPCW4rPe_UvBZQ",
    "channelName": "The PrimeTime",
    "channelUrl": "https://www.youtube.com/channel/UCUyeluBRhGPCW4rPe_UvBZQ",
    "channelUsername": "ThePrimeTimeagen",
    "durationSeconds": 799,
    "views": 699503,
    "thumbnailUrl": "https://i.ytimg.com/vi/p0fybvFyOlM/hqdefault.jpg",
    "isShort": false,
    "isLive": false,
    "publishedAt": "2026-10-03T03:48:31.000Z",
    "description": "Sandbox aren't enough. Your agents need a devbox. A full development environment with all your dependencies.…",
    "likes": 10482,
    "category": "Science & Technology",
    "tags": ["programming"],
    "comments": 1100,
    "channelSubscribers": 1170000
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `publishedAt` | string (ISO 8601) | When the video was published. |
| `durationSeconds` | integer | The duration, in seconds. |
| `likes` | integer | The number of likes. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
