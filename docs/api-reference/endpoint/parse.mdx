Best for a file you already hold. To read a page or a PDF by its address, use scrape.

<Note>Works without an API key, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits).</Note>

## Price

$0.50 per 1,000 pages or files whose text comes from a text layer, and $2.50 per 1,000 pages or pictures read from their picture, up to maxPages; summary and json with a schema or a prompt add $3 per 1,000 each; zero data retention adds $2 per 1,000 calls. costUsd shows what the call cost.

See [Pricing](/account/pricing).

```bash cURL
curl -X POST https://api.stophy.dev/v1/parse \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"file":"PGgxPkhvdyB0aWRlcyB3b3JrPC9oMT4=","filename":"tides.html"}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/parse", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    file: "PGgxPkhvdyB0aWRlcyB3b3JrPC9oMT4=",
    filename: "tides.html",
  }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/parse",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={
        "file": "PGgxPkhvdyB0aWRlcyB3b3JrPC9oMT4=",
        "filename": "tides.html",
    },
)
print(response.json())
```
