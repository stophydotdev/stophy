## Response

`data` has the ad's advertiser, text and images, and who paid for it.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "adId": "1585529084",
    "adUrl": "https://www.linkedin.com/ad-library/detail/1585529084",
    "creativeType": "SPONSORED_STATUS_UPDATE",
    "format": "Single Image Ad",
    "advertiserName": "SiteChief",
    "advertiserUrl": "https://www.linkedin.com/company/106013271",
    "advertiserAvatarUrl": "https://media.licdn.com/dms/image/v2/D560BAQH_lWh0hAuxAA/company-logo_100_100/B56aDOxwFkIQAI-/0/1790175543945/lifesafet…",
    "text": "We’ve rebranded, LifeSafety.AI is now SiteChief.\nSame team. Same UK-built platform.\nA name that matches what customers…",
    "headline": "AI Health & Safety Software for Workplace | SiteChief UK",
    "imageUrls": ["https://media.licdn.com/dms/image/sync/v2/D4E27AQGrtnvrN16TKA/articleshare-shrink_1280_800/B4EaDEgSaVJoAg-/0/1790003193…"],
    "paidBy": "PODTECH"
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `paidBy` | string | The entity that paid for the ad. |

<Note>Run dates, impressions and who paid show only for ads shown in the EU. Impressions by country show about 2 days after an ad starts, so a new ad has an empty countries list.</Note>

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
