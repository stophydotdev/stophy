## Pages

A full answer holds a `cursor`. Send it back as the `cursor` parameter, with the same filters, to read the next page. When the answer has no `cursor`, you have read everything.

<RequestExample>
```bash cURL
curl "https://api.stophy.dev/v1/team/activity?limit=3" \
  -H "Authorization: Bearer $STOPHY_API_KEY"
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/team/activity?limit=3", {
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
  },
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.get(
    "https://api.stophy.dev/v1/team/activity?limit=3",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
)
print(response.json())
```
