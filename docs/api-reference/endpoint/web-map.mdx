## Response

`data.results` lists the site's pages, each with its address and title.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "url": "https://bun.com/docs/runtime/sqlite",
        "title": "SQLite | Bun Docs"
      }
    ],
    "page": 1,
    "totalPages": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `totalPages` | integer | The number of pages that match the request. |

<Note>Add search to rank pages about one topic first.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `search` | string | Keep only addresses that mention these words, best matches first, such as pricing. |
| `includeSubdomains` | boolean | Also list pages on subdomains, such as docs.bun.com for bun.com. Defaults to `false`. |
| `page` | integer | Page number, starting at 1. From 1 to 100. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 100.
