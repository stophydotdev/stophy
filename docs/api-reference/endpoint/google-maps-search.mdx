## Response

`data.results` lists the places, each with its rating, address, contact details and opening hours.

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |
| `reviews` | integer | The number of reviews the rating is based on. |
| `openStatus` | string | The current opening status, as displayed by Google. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `minRating` | number | Only places rated at least this high. One of `2`, `2.5`, `3`, `3.5`, `4` or `4.5`. |
| `openNow` | boolean | Only places open at the time of the search. Defaults to `false`. |
| `country` | string | Two-letter country code, like `us`. Defaults to `us`. |
| `language` | string | Language code, like `en` or `pt-BR`. Defaults to `en`. |
| `page` | integer | Page number, starting at 1. From 1 to 10. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 10.
