## Response

`data` has what the video says as one block of `text`.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "videoId": "DdG4RIxIPyf",
    "videoUrl": "https://www.instagram.com/p/DdG4RIxIPyf/",
    "language": "en",
    "isAutoGenerated": true,
    "durationSeconds": 72.584118272,
    "transcribedSeconds": 73,
    "text": "Welcome to Africa. Welcome to Earth's wild home. See a new side to animals you know and meet some you've never seen…"
  },
  "creditsUsed": 10,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `text` | string | The whole transcript as one block. |
| `transcribedSeconds` | number | Seconds of audio that were transcribed when the video had no captions. The price depends on it. |
| `isAutoGenerated` | boolean | True when the captions were generated, not written by a person. |
| `durationSeconds` | number | The duration, in seconds. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `language` | string | Language code, like `en` or `pt-BR`. |
| `includeTimestamps` | boolean | Return each line with its start and end time, in `segments`. Defaults to `false`. |

## Price

$0.0015 plus $0.0015 for every 30 seconds of audio, up to 5 minutes. A call costs at most $0.0165. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
