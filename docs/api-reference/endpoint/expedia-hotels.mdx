## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `checkIn` | string (date) | The check-in date. Defaults to tomorrow. Format: `YYYY-MM-DD`. |
| `checkOut` | string (date) | The check-out date. Defaults to one night after `checkIn`. Format: `YYYY-MM-DD`. |
| `adults` | integer | The number of adults. Must be between 1 and 14. If unset, defaults to `2`. |
| `sort` | string | Specifies the order of the hotels: by Expedia's recommended order, lowest price first or guest rating. Acceptable values are `relevance`, `priceLow` and `rating`. If unset, defaults to `relevance`. |
| `page` | integer | The page to return. Pages are numbered from 1. Must be between 1 and 20. If unset, defaults to `1`. |

## Billing

Each successful request consumes 1 credit, regardless of the number of items returned. Requests that fail, or that return no items, are not billed.

## Pagination

Results are paginated. To retrieve the next page, increment `page`. An empty `data.results` indicates the last page. The maximum value of `page` is 20.
