## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `checkIn` | string (date) | The check-in date. Defaults to tomorrow. Format: `YYYY-MM-DD`. |
| `checkOut` | string (date) | The check-out date. Defaults to one night after `checkIn`. Format: `YYYY-MM-DD`. |
| `adults` | integer | How many adults. From 1 to 14. Defaults to `2`. |
| `sort` | string | How to order the hotels: by Expedia's recommended order, lowest price first or guest rating. One of `relevance`, `priceLow` or `rating`. Defaults to `relevance`. |
| `page` | integer | Page number, starting at 1. From 1 to 20. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 20.
