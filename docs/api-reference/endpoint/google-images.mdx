## Response

`data.results` lists the images, each with its full-size link and the page it comes from.

An example of the shape. The values are made up.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "imageUrl": "https://images.example.com/golden-retriever-puppy.jpg",
        "title": "Golden retriever puppy in the grass",
        "pageUrl": "https://www.example.com/dog-breeds/golden-retriever",
        "source": "example.com",
        "width": 1600,
        "height": 1067,
        "thumbnailUrl": "https://images.example.com/thumbs/golden-retriever-puppy.jpg",
        "position": 1
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `position` | integer | The 1-based position of the result in the list. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. |
| `language` | string | Two-letter language code, like `en` or `pt`. |
| `size` | string | Only images of this size. One of `large`, `medium` or `icon`. |
| `type` | string | The kind of image. One of `clipArt`, `lineDrawing` or `gif`. |
| `time` | string | Only images from this period. One of `past24Hours` or `pastWeek`. |
| `usageRights` | string | Only images with this license. One of `creativeCommons` or `commercial`. |
| `limit` | integer | Return at most this many images. You pay $0.0015 per 10 returned. From 1 to 100. |

## Price

$0.0015 per 10 images. A call costs at most $0.015. A call that fails or finds nothing is free. Send a smaller `limit` to get fewer items and pay less. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
