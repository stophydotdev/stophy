## Response

`data.results` lists the jobs, each with its budget or hourly rate, skills and posting date.

An example of the shape. The values are made up.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "jobId": "~021234567890123456789",
        "jobUrl": "https://www.upwork.com/jobs/~021234567890123456789",
        "title": "React developer for a dashboard",
        "description": "We need a React developer to build a reporting dashboard.",
        "skills": ["React", "TypeScript"],
        "type": "hourly",
        "experienceLevel": "intermediate",
        "workload": "partTime",
        "duration": "oneToThreeMonths",
        "hourlyRateMin": 30,
        "hourlyRateMax": 60,
        "publishedAt": "2026-10-05T09:30:00.000Z"
      }
    ],
    "total": 1250,
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `type` | string | Whether the job pays by the hour (`hourly`) or a fixed price (`fixed`). |
| `workload` | string | Upwork's hours needed. Empty when the job does not say, including fixed-price jobs and clients who are not sure. |
| `duration` | string | Upwork's project length. `underOneMonth` is under one month, `oneToThreeMonths` is one to three months, `threeToSixMonths` is three to six months, and `overSixMonths` is longer. |
| `page` | integer | The page number of this response. |
| `total` | integer | The total number of matching results, across all pages. |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |

<Note>`workload`, `duration` and the hourly rate filters apply to hourly jobs only.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `sort` | string | How to order the jobs. One of `newest` or `relevance`. Defaults to `newest`. |
| `jobType` | string | Hourly jobs or fixed-price jobs. One of `hourly` or `fixed`. |
| `experienceLevel` | string | Only jobs that ask for this level. One of `entry`, `intermediate` or `expert`. |
| `workload` | string | Hours needed: full time, part time or as needed. Only hourly jobs say this, so the search stays hourly. One of `fullTime`, `partTime` or `asNeeded`. |
| `duration` | string | Project length: under one month, one to three months, three to six months or over six months. Only hourly jobs say this, so the search stays hourly. One of `underOneMonth`, `oneToThreeMonths`, `threeToSixMonths` or `overSixMonths`. |
| `minHourlyRate` | integer | Lowest hourly rate in USD. A job matches when its posted range overlaps this minimum, so 25 to 50 matches a minimum of 50. The search stays hourly. From 1 to 999. |
| `maxHourlyRate` | integer | Highest hourly rate in USD. Send it with `minHourlyRate`. The job's posted range overlaps both, and the search stays hourly. From 1 to 999. |
| `page` | integer | Page number, starting at 1. From 1 to 100. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 100.
