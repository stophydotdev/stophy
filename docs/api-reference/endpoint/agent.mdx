Best for a question that needs several pages, like the pricing tiers of a few products or the CEO and headquarters city of a list of startups. Send prompt, and schema for the fields you want (any JSON Schema), and urls to start from. It answers at once with an id, threadId and threadTurn; ask agent.status for the result. The agent searches, reads pages and checks every value against the page text, in up to 3 rounds. It is charged step by step at the normal price of each search and page, plus $3 per 1,000 pages for each planning or answering step, and stops before maxCredits. A run that cannot finish inside maxCredits fails with stopReason credit_limit_reached and what it found in partial; what it spent is still charged. To ask a follow-up, send the threadId from agent.status.

## Price

Each search and page at its normal price, plus $3 per 1,000 pages for each planning or answering step that returns something, up to the limit you set with `maxCredits` ($5 when you leave it out). Starting the run is free.

See [Pricing](/account/pricing).
