## Response

`data` has the home's price, address, size, description, photos and facts.

| Field | Type | Description |
| --- | --- | --- |
| `price` | number | Asking price, monthly rent, or the sale price of a sold home. Left out when Zillow shows none, such as for sold homes in states that keep sale prices private. |
| `daysOnZillow` | integer | The number of days since the home was listed. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
