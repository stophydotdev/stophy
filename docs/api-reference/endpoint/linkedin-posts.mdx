## Request

Send exactly one of `profileUrl`, `profileId`, `companyUrl` or `companyId`. More than one, or none, fails with `invalidRequest`.

## Response

`data.results` lists the latest public posts, each with its text, likes and date.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "postId": "7509276499837902849",
        "postUrl": "https://www.linkedin.com/posts/satyanadella_the-motivation-behind-the-new-copilot-intelligence-activity-750927649983790…",
        "text": "The motivation behind the new Copilot: intelligence is accelerating fast. Now we need to diffuse it everywhere.",
        "publishedAt": "2026-09-25T15:43:53.171Z",
        "likes": 959,
        "authorName": "Satya Nadella",
        "authorUrl": "https://www.linkedin.com/in/satyanadella"
      }
    ]
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `publishedAt` | string (ISO 8601) | The publication time, in UTC. |
| `likes` | integer | The number of likes. |

<Note>Returns the most recent public posts that LinkedIn displays for the page, including reposts. This is typically at most 10 posts. Older posts are not available, and this method is not paginated.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
