## Response

`data.results` lists the ads, each with its advertiser and the days it ran.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "adId": "CR00462730911658541057",
        "adUrl": "https://adstransparency.google.com/advertiser/AR16735076323512287233/creative/CR00462730911658541057",
        "advertiserId": "AR16735076323512287233",
        "advertiserName": "Nike, Inc.",
        "advertiserUrl": "https://adstransparency.google.com/advertiser/AR16735076323512287233",
        "domain": "nike.com",
        "format": "text",
        "firstShownAt": "2022-11-30T14:47:52.000Z",
        "lastShownAt": "2026-10-05T20:27:35.000Z",
        "daysShown": 1350,
        "imageUrl": "https://tpc.googlesyndication.com/archive/simgad/5743239130676952852"
      }
    ],
    "totalMin": 100000,
    "totalMax": 200000,
    "cursor": "CgoAP7zmi4ohfCUHEhBNRhEc0rwv/RRMIVUAAAAAGgn8+Ghj+Osc6yI="
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"

```

| Field | Type | Description |
| --- | --- | --- |
| `cursor` | string | Send it back as `cursor` for the next page. The last page has none. |
| `totalMin` | integer | With `totalMax`, the range for the number of matching ads. |
| `firstShownAt` | string (ISO 8601) | When Google first showed the ad. |
| `lastShownAt` | string (ISO 8601) | The last day the ad was shown. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | A domain like `nike.com`. |
| `advertiser` | string | An advertiser id from Google ads advertisers. |
| `domain` | string | A domain like `nike.com`. |
| `country` | string | Two-letter country code, like `de`. Only ads shown there are returned. |
| `mediaType` | string | Only ads of this type. One of `text`, `image` or `video`. |
| `platform` | string | Google's own Platform filter: where the ad was shown. Google leaves out ads shown before 4 September 2023 when it is set. One of `search`, `youtube`, `play`, `maps` or `shopping`. |
| `shownFrom` | string (date) | Only ads shown on or after this day. Format: `YYYY-MM-DD`. |
| `shownTo` | string (date) | Only ads shown on or before this day. Format: `YYYY-MM-DD`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

<Note>The Google ad library does not support keyword search. To search by advertiser name, first resolve the advertiser ID with [Google advertisers](/api-reference/endpoint/google-ads-advertisers).</Note>

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
