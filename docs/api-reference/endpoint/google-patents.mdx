## Response

`data.results` lists the patents, each with its owner, inventor, dates and link.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "patentId": "WO2013104046A1",
        "title": "A system and method for assuring operational readiness of a mission critical …",
        "snippet": "A SYSTEM AND METHOD FOR ASSURING OPERATIONAL READINESS OF A MISSION CRITICAL BATTERY HAVING A LONG STORAGE PERIOD…",
        "assignee": "Panacis Inc.",
        "inventor": "Steve Carkner",
        "priorityDate": "2012-01-09",
        "filingDate": "2012-12-19",
        "publicationDate": "2013-07-18",
        "language": "en",
        "patentUrl": "https://patents.google.com/patent/WO2013104046A1/en",
        "pdfUrl": "https://patentimages.storage.googleapis.com/4f/16/c5/b5bc207e6ec556/WO2013104046A1.pdf",
        "thumbnailUrl": "https://patentimages.storage.googleapis.com/c6/b7/47/f2e1e172e74da8/pctca2012050916-appb-P000004-000001.png",
        "position": 1
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `patentId` | string | Publication number, like US11993294B2. |
| `page` | integer | The page number of this response. |
| `position` | integer | The 1-based position of the result in the list. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `inventor` | string | Only patents by this inventor. |
| `assignee` | string | Only patents owned by this company or person. |
| `office` | string | Patent office, like `US`, `EP`, `WO`, `CN` or `JP`. |
| `language` | string | The language of the patents. One of 16 values, like `english`, `german` and `chinese`. |
| `dateType` | string | Which date `before` and `after` compare to. One of `priority`, `filing` or `publication`. Defaults to `priority`. |
| `after` | string (date) | Only patents dated after this day. `dateType` picks which date counts. Format: `YYYY-MM-DD`. |
| `before` | string (date) | Only patents dated before this day. `dateType` picks which date counts. Format: `YYYY-MM-DD`. |
| `status` | string | Granted patents or applications. One of `grant` or `application`. |
| `type` | string | Patents or designs. One of `patent` or `design`. |
| `litigation` | string | Only patents with related litigation (`has`), or with none known (`none`). One of `has` or `none`. |
| `sort` | string | How to order the patents. One of `relevance`, `newest` or `oldest`. Defaults to `relevance`. |
| `page` | integer | Page number, starting at 1. From 1 to 100. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 100.
