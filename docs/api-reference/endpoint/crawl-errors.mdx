## Failed pages

Lists up to 1,000 failed pages with `url`, `code`, `message`, `retryable` and `at`. `isTruncated` is `true` when there are more. Retry a page when `retryable` is `true`. `robotsBlocked` lists up to 1,000 links that a robots.txt the crawl read did not allow. A link whose robots.txt could not be read is skipped and not listed.
