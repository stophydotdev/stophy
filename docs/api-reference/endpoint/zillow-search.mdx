## Response

`data.results` lists the homes, each with its price, address, size and status.

This real response is cut to one item per list.

| Field | Type | Description |
| --- | --- | --- |
| `price` | number | Asking price, monthly rent, or the sale price of a sold home. Left out when Zillow shows none, such as for sold homes in states that keep sale prices private. |
| `page` | integer | The page number of this response. |
| `totalPages` | integer | The number of pages that match the request. |
| `total` | integer | The total number of matching results, across all pages. |
| `statusText` | string | The listing status label as displayed by Zillow, such as `Active`. |
| `daysOnZillow` | integer | The number of days since the home was listed. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `status` | string | Homes for sale, for rent or sold. One of `forSale`, `forRent` or `sold`. Defaults to `forSale`. |
| `minPrice` | number | Lowest price. |
| `maxPrice` | number | Highest price. |
| `minBedrooms` | integer | Fewest bedrooms. From 0 to 20. |
| `maxBedrooms` | integer | Most bedrooms. From 0 to 20. |
| `minBathrooms` | number | Fewest bathrooms. From 0 to 20. |
| `minSqft` | integer | Smallest size, in square feet. |
| `maxSqft` | integer | Largest size, in square feet. |
| `minLotSize` | integer | Smallest lot, in square feet. |
| `maxLotSize` | integer | Largest lot, in square feet. |
| `minYearBuilt` | integer | Only homes built in or after this year. From 1600 to 2100. |
| `maxYearBuilt` | integer | Only homes built in or before this year. From 1600 to 2100. |
| `maxHoa` | number | Highest monthly HOA fee, in USD. `0` means no HOA fee. |
| `minParkingSpots` | integer | Only homes with at least this many parking spots. From 1 to 4. |
| `daysOnZillow` | string | Only homes listed in the last 1, 7, 14, 30 or 90 days, or 6, 12, 24 or 36 months. For sold homes, it means sold in that time. One of `1Day`, `7Days`, `14Days`, `30Days`, `90Days`, `6Months`, `12Months`, `24Months` or `36Months`. |
| `hasPool` | boolean | Only homes with a pool. Defaults to `false`. |
| `hasGarage` | boolean | Only homes with a garage. Defaults to `false`. |
| `hasAirConditioning` | boolean | Only homes with air conditioning. Defaults to `false`. |
| `isWaterfront` | boolean | Only waterfront homes. Defaults to `false`. |
| `singleStory` | boolean | Only single-story homes. Defaults to `false`. |
| `openHouse` | boolean | Only homes with an open house. Defaults to `false`. |
| `priceReduced` | boolean | Only homes with a price cut. Defaults to `false`. |
| `has3dTour` | boolean | Only homes with a 3D tour. Defaults to `false`. |
| `petsAllowed` | boolean | Only places that allow pets. Rentals only: set `status` to `forRent`. Defaults to `false`. |
| `homeTypes` | string[] | Zillow's own Home type filter. On rentals, apartment and condo are one Zillow category (apartments, condos and co-ops), so either one returns both. One of `house`, `townhouse`, `multiFamily`, `condo`, `land`, `apartment` or `manufactured`. |
| `sort` | string | How to order the homes. One of `relevance`, `newest`, `priceHigh`, `priceLow`, `bedrooms`, `bathrooms`, `squareFeet` or `lotSize`. Defaults to `relevance`. |
| `keywords` | string | Words the listing must mention, like "pool" or "fixer upper". |
| `page` | integer | Page number, starting at 1. From 1 to 20. Defaults to `1`. |

## Price

Each call costs $0.003, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 20.
