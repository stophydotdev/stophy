## Response

`data.results` lists the pages, each with its title and description, and its text when `scrapeResults` is on.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "results": [
      {
        "url": "https://www.paymoapp.com/blog/project-management-software/",
        "title": "20+ Best Project Management Software for 2026 • Paymo",
        "description": "3 weeks ago - Jira – best for software engineers & programmers · ProjectManager – a complex PM software geared towards…",
        "position": 1
      }
    ]
  },
  "creditsUsed": 2,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `position` | integer | The 1-based position of the result in the list. |

<Note>Turn on scrapeResults to get the text of the top pages in the same call.</Note>

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `country` | string | Two-letter country code, like `us`. |
| `language` | string | Only pages written in this language. Two-letter code like en or fr. |
| `includeDomains` | string[] | Only results from these domains. Up to 10 values. |
| `excludeDomains` | string[] | Leave out results from these domains. Up to 10 values. |
| `time` | string | Only pages from the past week, month or year. Leave out for any time. Not with after or before. One of `pastWeek`, `pastMonth` or `pastYear`. |
| `after` | string (date) | Only pages published on or after this day, as YYYY-MM-DD. Format: `YYYY-MM-DD`. |
| `before` | string (date) | Only pages published on or before this day, as YYYY-MM-DD. Format: `YYYY-MM-DD`. |
| `safeSearch` | boolean | Hide explicit results. Defaults to `false`. |
| `limit` | integer | Return at most this many results. You pay $0.0015 per 10 returned. From 1 to 100. Defaults to `10`. |
| `scrapeResults` | boolean | Also read the top results and add each page's text as markdown. Costs $0.0015 more for each result that comes back with its text. Defaults to `false`. |
| `scrapeLimit` | integer | How many of the top results to read when `scrapeResults` is on. From 1 to 5. Defaults to `3`. |

<Note>Use `after` and `before` together or alone. `time` cannot be sent with either, and `after` cannot be later than `before`. Both fail with `invalidRequest`.</Note>

## Price

$0.0015 per 10 results, plus $0.0015 for each result that comes back with its page text when scrapeResults is on. A call costs at most $0.0225. A call that fails or finds nothing is free. Send a smaller `limit` to get fewer items and pay less. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

One call returns everything. There are no more pages.
