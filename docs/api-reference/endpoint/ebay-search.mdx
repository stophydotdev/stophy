## Response

`data.results` lists the items, each with its price, shipping cost, total price, condition and location.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "total": 6400,
    "results": [
      {
        "itemId": "326350933758",
        "itemUrl": "https://www.ebay.com/itm/326350933758",
        "title": "Nintendo Switch OLED 64GB White Joy-Con 2021 Newest - Japan Import with US plug",
        "imageUrl": "https://i.ebayimg.com/images/g/Z94AAOSwTTJnQ-Bl/s-l500.jpg",
        "price": 350.99,
        "isPriceHidden": false,
        "priceCurrency": "USD",
        "shippingCost": 0,
        "isPickupOnly": false,
        "totalPrice": 350.99,
        "condition": "Brand New",
        "isAuction": false,
        "hasBestOffer": false,
        "itemLocation": "United States",
        "quantitySold": 71,
        "sellerName": "bestsellerssince1977",
        "sellerFeedbackPercent": 99.7,
        "sellerFeedbackScore": 4800
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"

```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `total` | integer | The total number of matching results, across all pages. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `condition` | string | Only `new` or only `used` items. One of `new` or `used`. |
| `auctionsOnly` | boolean | Only auctions. With sort `endingSoonest` this lists auctions about to end; [eBay Item](/api-reference/endpoint/ebay-item) then returns what each one sold for. Defaults to `false`. |
| `minPrice` | number | Lowest price. |
| `maxPrice` | number | Highest price. |
| `sort` | string | `priceLow` and `priceHigh` return each page in order of `totalPrice`: price plus shipping to New York 10001. Across pages the order is `eBay`'s, so a listing can belong on the neighbouring page. Listings with no `totalPrice` come last on their page: the price is hidden (`isPriceHidden`), the variation range is outside the price filter, or it is pickup only outside the United States. One of `bestMatch`, `priceLow`, `priceHigh` or `endingSoonest`. Defaults to `bestMatch`. |
| `page` | integer | Page number, starting at 1. From 1 to 100. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 100.
