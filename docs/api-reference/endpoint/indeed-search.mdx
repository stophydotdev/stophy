## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `query` | string | Words to search for. |
| `location` | string | City, region or postal code, like Kansas City, MO. |
| `country` | string | Two-letter country code, like `us`. One of 62 values, like `us`, `gb` and `ca`. Defaults to `us`. |
| `distanceMiles` | integer | How far from the location to look, in miles. `0` is the exact location only. One of `0`, `5`, `10`, `15`, `25`, `35`, `50` or `100`. Defaults to `25`. |
| `datePosted` | string | Only jobs posted in this period. A relisted job keeps its first `publishedAt` and shows the new date in `indexedAt`. One of `last24Hours`, `last3Days`, `last7Days` or `last14Days`. |
| `remote` | string | Only remote or hybrid jobs. One of `remote` or `hybrid`. |
| `jobType` | string | Only this type of job. One of `fullTime`, `partTime`, `contract`, `temporary` or `internship`. |
| `experienceLevel` | string | Only jobs for this level. One of `noExperience`, `entry`, `mid` or `senior`. |
| `education` | string | Only jobs that ask for this education. One of `highSchool`, `associate`, `bachelor` or `master`. |
| `sort` | string | How to order the jobs. One of `relevance` or `newest`. Defaults to `relevance`. |
| `cursor` | string | The `cursor` from the previous response. Send it back unchanged. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. For the next one, send `data.cursor` back as `cursor`. The last page has no `cursor`.
