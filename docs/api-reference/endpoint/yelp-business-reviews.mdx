## Response

`data.results` lists the reviews, each with its rating, text and any reply from the owner.

This real response is cut to one item per list.

```json
{
  "success": true,
  "data": {
    "businessId": "MGzro82Fi4LYvc86acoONQ",
    "businessName": "Franklin Barbecue",
    "businessUrl": "https://www.yelp.com/biz/franklin-barbecue-austin",
    "total": 6477,
    "results": [
      {
        "reviewId": "Q1kUFPnl5j3_0xrsLfLRYg",
        "reviewUrl": "https://www.yelp.com/biz/franklin-barbecue-austin?hrid=Q1kUFPnl5j3_0xrsLfLRYg",
        "rating": 5,
        "text": "Finally got back to Franklin bbq. Was here last year for a conference in round rock and made it there now back here…",
        "language": "en",
        "createdAt": "2026-10-04T00:58:20.000Z",
        "authorName": "Mike S."
      }
    ],
    "page": 1
  },
  "creditsUsed": 1,
  "requestId": "2fe9dbad-fc48-4890-9751-0b24b596035b"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `page` | integer | The page number of this response. |
| `total` | integer | The total number of matching results, across all pages. |
| `createdAt` | string (ISO 8601) | The creation time, in UTC. |
| `rating` | number | The average star rating, on a scale of 1 to 5. |

## Optional parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `sort` | string | relevance (Yelp Sort), newest, oldest, highest (Highest Rated) or lowest (Lowest Rated), the same as Yelp's own Sort menu. One of `relevance`, `newest`, `oldest`, `highest` or `lowest`. Defaults to `relevance`. |
| `page` | integer | Page number, starting at 1. From 1 to 250. Defaults to `1`. |

## Price

Each call costs $0.0015, however many items come back. A call that fails or finds nothing is free. Top-ups of $100 or more cost less. See [Pricing](/billing).

## Pages

Each call returns one page. Send `page: 2` for the next one. An empty `data.results` means you are past the last page. `page` goes up to 250.
