<RequestExample>
```bash cURL
curl -X PATCH https://api.stophy.dev/v1/browser/profiles/docs-example \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"docs-example-renamed"}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/browser/profiles/docs-example", {
  method: "PATCH",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ name: "docs-example-renamed" }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.patch(
    "https://api.stophy.dev/v1/browser/profiles/docs-example",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={"name": "docs-example-renamed"},
)
print(response.json())
```
