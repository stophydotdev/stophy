<RequestExample>
```bash cURL
curl -X POST https://api.stophy.dev/v1/search/research/papers \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"retrieval augmented generation","k":5}'
```
```typescript TypeScript
const response = await fetch("https://api.stophy.dev/v1/search/research/papers", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.STOPHY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ query: "retrieval augmented generation", k: 5 }),
});
console.log(await response.json());
```
```python Python
import os

import requests

response = requests.post(
    "https://api.stophy.dev/v1/search/research/papers",
    headers={"Authorization": f"Bearer {os.environ['STOPHY_API_KEY']}"},
    json={"query": "retrieval augmented generation", "k": 5},
)
print(response.json())
```
