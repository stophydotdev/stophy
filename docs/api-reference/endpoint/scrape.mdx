Best for reading a page as markdown, HTML, links or a screenshot. The page runs its JavaScript before it is read. Without formats you get markdown. Send formats as names, ["markdown","links"], or as objects, `[{"type":"screenshot","fullPage":true}]`, or mix them. For a site's own structured data (video, social, places, shopping, jobs, homes) send formats `[{"type":"json","parser":"<name>"}]`; GET /v1/parsers lists the parsers. A YouTube video link comes back as its title, channel, date, length, views, likes and description.

<Note>Works without an API key, up to 10 calls a minute and 50 a day per IP. See [Rate limits](/rate-limits).</Note>

## Price

1 credit for any page, however it is reached. json with a schema or a prompt, summary and highlights add 4 credits each when they return something. CSS rules and attributes add nothing. A PDF adds 1 credit for each page read. Each perform action adds 2 credits. An answer from a stored copy within maxAge is free. A page that comes back with a 404 or 410 status is charged like any page. A page that cannot be read costs nothing. Each page of a urls call is priced on its own. creditsUsed shows what the call cost.

See [Pricing](/billing) for what credits cost.
