Best for reading a page as markdown, HTML, links or a screenshot. The page runs its JavaScript before it is read. Without formats you get markdown. Send formats as names, ["markdown","links"], or as objects, `[{"type":"screenshot","fullPage":true}]`, or mix them. For a site's own structured data (video, social, places, shopping, jobs, homes) send formats `[{"type":"json","parser":"<name>"}]`; GET /v1/parsers lists the parsers. A YouTube video link comes back as its title, channel, date, length, views, likes and description. A CSV or Excel .xlsx file comes back as markdown tables. To read less, send query (what you look for) and get only the matching passages in page order, or maxChars with offset to read a long page, PDF or file part by part: each answer names nextOffset while text remains.

<Note>Works without an API key, up to 10 calls a minute and 50 calls a day per IP address. See [Rate limits](/production/rate-limits).</Note>

## Price

$1 per 1,000 pages, however they are reached. checkPromptInjection adds $2.50 per 1,000 pages when the scan runs, json with a schema or a prompt, summary, highlights, question, product, menu and changeTracking in json mode add $3 per 1,000 pages each when they return something. CSS rules and attributes add nothing. A PDF adds $0.50 per 1,000 pages of text from its text layer and $2.50 per 1,000 pages of text read from its picture that come back, so a PDF read with maxChars, offset or query is charged for the share of its pages that it returns, at least 1 page. Browser actions add nothing. An answer from a stored copy within maxAge costs $1 per 1,000 pages like any page. A page that comes back with a 404 or 410 status, or cannot be read, costs nothing. zeroDataRetention adds $2 per 1,000 scraped URLs, not per PDF page. metadata.costUsd shows what the call cost in dollars.

See [Pricing](/account/pricing).
