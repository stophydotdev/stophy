## Base URL

```text
https://api.stophy.dev
```

| Endpoint | What it does |
| --- | --- |
| [`POST /v1/search`](/api-reference/endpoint/search) | Searches the web, news and images |
| [`POST /v1/scrape`](/api-reference/endpoint/scrape) | Reads one page as markdown, HTML, links, a screenshot or JSON |
| [`POST /v1/map`](/api-reference/endpoint/map) | Lists the pages on a site |
| [`POST /v1/parse`](/api-reference/endpoint/parse) | Turns a PDF, Word, Excel, PowerPoint or HTML file into markdown |
| [`POST /v1/crawl`](/api-reference/endpoint/crawl) | Crawls a site in the background |
| [`POST /v1/batch/scrape`](/api-reference/endpoint/batch-scrape) | Scrapes many pages in the background |
| [`POST /v1/extract`](/api-reference/endpoint/extract) | Pulls the fields you name from pages |
| [`POST /v1/browser/task`](/api-reference/endpoint/browser-task) | Clicks through a site in a real browser |

A site's own data, like a Reddit search or a YouTube transcript, comes from scrape with a [parser](/guides/parsers). A field an endpoint does not take returns `400`.

## Authentication

Create a key at [stophy.dev/signup](https://stophy.dev/signup) and send it as a bearer token.

```bash
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://bun.com/docs/runtime/bunfig"}'
```

With no key, the endpoints that need one return `401` with code `apiKeyRequired`, a `signupUrl` for a person and a `signup` call for an agent. Search, scrape, map and parse also work without a key, within the [free limits](/rate-limits).

## Responses

Each endpoint answers in its own shape, and each endpoint's page shows a real response. Search returns `success`, `data` and `creditsUsed`:

```json
{
  "success": true,
  "data": {
    "web": [
      {
        "url": "https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2027",
        "title": "NVIDIA Announces Financial Results for Second Quarter Fiscal ...",
        "position": 1
      }
    ]
  },
  "creditsUsed": 4
}
```

Scrape and parse put the page in `data`, and scrape puts its cost in `data.metadata.creditsUsed`. Map returns `links`. Crawl, batch scrape and extract return a job `id`, and their status calls return `status`, the pages or fields in `data`, and `creditsUsed`. The account calls add `requestId`.

Empty values are left out. Every response has an `X-Request-ID` header and an `x-credits-used` header. To cut long text, add `?maxTextLength=<characters>` to the URL: longer text ends with `…`.

A failed call returns an error status and a flat body: `{ "success": false, "error": "<what went wrong>", "code": "<code>" }`. See [Errors](/api-reference/errors).

## Cost

`creditsUsed` is what the call cost in credits. Most calls cost 1 credit, and a call that fails costs nothing. See [Pricing](/billing).
