title: "Security questionnaire answers"
description: "Find answers to common security review questions and links to the supporting documentation."
---

| Question | Answer |
| --- | --- |
| How do users authenticate? | Dashboard sign-in uses Google or GitHub. API keys and MCP OAuth have different access paths. See [security](/trust/security). |
| Can a key be revoked? | Revocation disables the key in the database. See [security](/trust/security). |
| Are data encrypted in transit? | The privacy policy describes HTTPS. See [security](/trust/security). |
| How is customer data isolated? | The security model describes account and browser boundaries. See [security](/trust/security). |
| Who processes data and where? | See the [data map](/trust/subprocessors). |
| Is a DPA available? | [Enterprise agreements include a signed DPA](/trust/dpa). |
| How long is data retained? | See [retention](/trust/retention). |
| How are incidents handled? | See [incident response](/trust/incident-response). |
| How do researchers report vulnerabilities? | Email support@stophy.dev privately. See [security.txt](/trust/security-txt). |
| Is there an SLA? | The API target is 99.9% monthly; enterprise agreements include a contractual SLA. See [availability](/trust/availability). |
