## Access and keys

Google or GitHub can authenticate dashboard users. API keys act for an account and have no scopes. MCP also accepts OAuth tokens. The [security model](https://github.com/stophydotdev/stophy-api/blob/6b824524/SECURITY.md) describes the credentials and their boundaries.

Stophy hashes API keys before lookup. The verifier checks whether a key is enabled and has expired. To rotate a key, create a replacement, update clients, and revoke the old key. Revocation disables the key in the database. The verifier reads the database on authentication. See [key verification and revocation](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/server/src/users/apiKeys.ts) and [credential management](/get-credentials).
