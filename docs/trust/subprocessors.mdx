title: "Subprocessors and data map"
description: "See providers and destinations used by Stophy, the data they receive, and known processing locations."
---

This inventory describes known data flows. A code path does not establish that an optional provider is enabled. Provider locations below describe known observations, not a data residency guarantee. The locations of several flows and the complete proxy operator list are not established.

| Provider or destination | Purpose and data class | Location and evidence |
| --- | --- | --- |
| Railway | API, browser, and Redis hosting. Request data, temporary job state, and operational logs. | US East was observed for all three services on November 22, 2026. [Privacy policy source](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/web/src/app/%28marketing%29/privacy/sections.ts) |
| Neon | Postgres database for account, credential, and usage records. | US project indicated by recent ledger writes. [Privacy policy source](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/web/src/app/%28marketing%29/privacy/sections.ts), [Neon regions](https://neon.com/docs/introduction/regions) |
| Cloudflare | Website, email, object storage, and model processing on applicable paths. Data includes email addresses and messages, stored files, and model inputs. | Location depends on the service and configuration. [Email sender](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/server/src/sendEmail.ts), [object storage](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/server/src/clients/r2.ts), [R2 data location](https://developers.cloudflare.com/r2/reference/data-location/), [model path](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/server/src/extract/workersAi.ts) |
| Stripe | Payments. Checkout details and transaction identifiers. | Processing location is not established here. [Privacy policy source](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/web/src/app/%28marketing%29/privacy/sections.ts) |
| Google and GitHub | Optional sign-in. Identity and profile data. | Processing location is not established here. [Privacy policy source](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/web/src/app/%28marketing%29/privacy/sections.ts) |
| PostHog | Analytics and error reports. Usage metadata. | The website sends events to a US endpoint. [Website proxy](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/web/src/app/ingest/%5B...path%5D/route.ts), [server tracking](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/server/src/track.ts) |
| OpenAI and Anthropic | Model calls on applicable paths. Prompts and page content. Anthropic is optional in code. | Processing location is not established here. [Model routing](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/server/src/extract/askModel.ts) |
| Decodo | Residential, mobile, datacenter, and ISP proxy routes. Destinations and traffic visible to the proxy depend on the route and transport. | Exit location depends on the route. Production ISP and datacenter endpoints were observed in a proxy check. [Request routing](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/server/src/fetch/proxy.ts), [Decodo privacy policy](https://decodo.com/privacy-policy) |
| Better Stack | Status page and monitoring. Monitor results and incident history. | Processing location is not established here. [Status page](https://status.stophy.dev), [privacy policy](https://betterstack.com/privacy) |

Customer-selected sites and search providers receive requests as part of the service. They are separate destinations, and their role depends on the request. For example, the [Brave search path](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/server/src/sources/web/brave.ts) sends search queries to Brave.
