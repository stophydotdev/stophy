This draft is an inventory of observed code paths and public policy, not a verified complete register. A code path does not prove that a provider is enabled in production. Confirm contracts, subprocessors, transfers, regions, and retention before relying on it.

Customer-selected sites and search providers receive requests as part of the service. They are separate destinations, and their role depends on the request. For example, the [Brave search path](https://github.com/stophydotdev/stophy-api/blob/6b824524/apps/server/src/sources/web/brave.ts) sends search queries to Brave. Review each route, proxy operator, model, and observability destination before treating this map as complete.
