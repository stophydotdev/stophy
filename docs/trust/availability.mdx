## Uptime SLA

Stophy targets **99.9% API uptime per calendar month**. A contractual uptime SLA is included in enterprise agreements. Contact [hussein@stophy.dev](mailto:hussein@stophy.dev) for an enterprise agreement.

The [status page](https://status.stophy.dev) reports API monitor history. On November 23, 2026, at 11:08 UTC, it showed 100% uptime over 30 monitored days and approximately 99.9968% over 55 monitored days. The monitor does not test every API operation or dependency and can miss outages between checks.
