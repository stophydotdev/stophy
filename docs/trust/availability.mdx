The API availability target is **99.9% per calendar month**. The [status page](https://status.stophy.dev) reports the API monitor's history. The monitor checks every three minutes, so shorter outages can go undetected. The monitor does not establish availability for every API operation or dependency.

On November 22, 2026, the status page history showed API availability of 100% over 30 days and 99.997% over 54 monitored days. The longer figure covers the monitored period, not a full 90 days. These observations are subject to the three-minute check interval.

If availability falls below the target, email [hussein@stophy.dev](mailto:hussein@stophy.dev) to request a service credit. Approved credits are paid as account balance. Contact Stophy for the applicable credit terms.
