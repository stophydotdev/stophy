A parser reads one kind of page on one site and returns the site's own data as JSON. A Reddit search page comes back as posts, a YouTube video link as its transcript, a Google Maps search as places. There are 103 parsers.

## Call a parser

Send the page's URL to [scrape](/api-reference/endpoint/scrape) with a `json` format that names the parser. Parser options go in `options`.

```bash
curl -X POST https://api.stophy.dev/v1/scrape \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.youtube.com/watch?v=dQw4w9WgXcQ","formats":[{"type":"json","parser":"youtube-transcript","options":{"language":"en"}}]}'
```

The parser's data is in `data.json`. The URL must be the kind of page the parser reads, or the call fails with `invalidRequest`.

Your code or your agent can read the same list from [`GET /v1/parsers`](/api-reference/endpoint/list-parsers). It is free and needs no key.

```bash
curl -s https://api.stophy.dev/v1/parsers \
  | jq -r '.data.parsers[] | select(.name | startswith("youtube")) | "\(.name): \(.takes)"'
```

```text
youtube-search: A YouTube search results page with the search in search_query
youtube-video: A YouTube video link: watch, youtu.be, shorts or live
youtube-transcript: A YouTube video link: watch, youtu.be, shorts or live
youtube-comments: A YouTube video link: watch, youtu.be, shorts or live
youtube-channel: A YouTube channel link: @handle, /channel/, /c/ or /user/, with an optional tab
youtube-post: A YouTube community post link: /post/Ugkx... or a community page with ?lb=
youtube-playlist: A YouTube playlist page with list in the link
```

Each entry has `takes` (the page it reads), an `example` URL, its `options`, the fields it `returns`, its `price`, `keyless: true` when it works without a key, and a sample `response`. Some parsers read more than one kind of page and list each one in `views`. Set `options.view` to pick one where `takes` says so.

## Price and keys

Each parser has its own price, most of them 1 credit a call. A credit is $0.002. The parsers marked `keyless: true` work without a key, within the [free limits](/rate-limits). Paging through a parser's results needs a key. See [Page through results](/guides/paging).
