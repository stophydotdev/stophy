Use Parse to turn a file you have into Markdown. Send its bytes as base64 in JSON. If you have a public URL rather than the file, use [Scrape](/scrape/pdfs-and-documents).

## Make a request

Send a small file in the request body. Get an API key in the [Quickstart](/quickstart), and install the SDK with `npm install stophy` or `pip install stophy`. This request parses a tiny HTML file. To send a file from disk, encode it first, for example with `base64 -w0 report.pdf`.

<CodeGroup>
```bash cURL
curl -X POST https://api.stophy.dev/v1/parse \
  -H "Authorization: Bearer $STOPHY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "file": "PGgxPkhvdyB0aWRlcyB3b3JrPC9oMT4=",
    "filename": "tides.html"
  }'
```
```typescript TypeScript
import { Stophy } from "stophy";

const stophy = new Stophy();

const file = Buffer.from("<h1>How tides work</h1>").toString("base64");

const { data } = await stophy.parse({ file, filename: "tides.html" });
console.log(data?.markdown);
```
```python Python
import base64

from stophy import Stophy

stophy = Stophy()

file = base64.b64encode(b"<h1>How tides work</h1>").decode()

data = stophy.parse(file=file, filename="tides.html")["data"]
print(data["markdown"])
```
</CodeGroup>

You can try Parse without an API key, up to 10 calls a minute and 50 calls a day per IP address, with files up to 2 MB. Summaries, `json` and reading every page's picture need an API key. See [Rate limits](/production/rate-limits).

## Read the response

Read the text in `data.markdown`. `data.metadata` tells you what we identified and what the parse cost.

```json
{
  "success": true,
  "data": {
    "markdown": "# How tides work",
    "metadata": {
      "contentType": "text/html",
      "costUsd": 0.0005
    }
  }
}
```

`metadata.contentType` is the type Stophy found in the file, whatever its name says. For a PDF, `numPages` is the total page count and `ocrPages` counts pages read from their picture. If the file had more pages than `maxPages`, `data.warning` says `The file text was cut short.`

## Formats

Ask for another format if you need more than the text. We always return `markdown` and accept up to 8 items in `formats`.

| Format | What you get | Guide |
| - | - | - |
| `summary` | A short summary of the file | [Summary](/scrape/summary) |
| `links`, `images` | Every link and every image address in the Markdown | [Links](/scrape/links) |
| `html`, `rawHtml` | The cleaned HTML, or the HTML as sent. HTML files only | [HTML](/scrape/html) |
| `json` with `schema` or `prompt` | An object in the shape you describe | [JSON](/scrape/json) |

PDF page options, such as `pages`, `blocks` and the reading `mode`, are in [Formats](/parse/formats).

## Request fields

Use `file` for base64, or `uploadRef` if you already uploaded the bytes.

| Field | Type | Default | Effect |
| - | - | - | - |
| `file` | `string` | none | The file's bytes as base64, up to 36 MB. A `data:` prefix is accepted. Send `file` or `uploadRef`. |
| `uploadRef` | `string` | none | The `uploadId` of a file you sent with [Large files](/parse/large-files), instead of `file`. |
| `filename` | `string` | none | The file's name, such as `report.docx`. The type is read from the file itself. |
| `formats` | `array` | `[]` | What to send back besides `markdown`. |
| `maxPages` | `number` | 100 | Read at most this many PDF pages, sheets or slides, 1 to 100. |
| `parsers` | `array` | none | How to read a PDF. See [Formats](/parse/formats). |
| `onlyMainContent`, `includeTags`, `excludeTags`, `removeBase64Images` | | | Shape the Markdown of an HTML file. See [Formats](/parse/formats). |
| `zeroDataRetention` | `boolean` | `false` | Keep nothing from the call. Adds $2 per 1,000 calls. See [Zero data retention](/production/zero-data-retention). |

The same fields can sit inside an `options` object. The full field list is in the [API reference](/api-reference/endpoint/parse).

## Limits and errors

Check the file size and type before encoding it.

- A file can be up to 36 MB with an API key, and up to 2 MB without one. A larger file returns `400 invalidRequest`. Send a large file with [Large files](/parse/large-files).
- A body that is not base64 returns `400 invalidRequest` with `file: this is not base64. Send the file's bytes encoded as base64.`
- A file type that cannot be read returns `400 invalidRequest` with `file: this type of file cannot be read.` and the list of types. The older `.doc`, `.xls` and `.ppt` formats return `400 invalidRequest`: save them as `.docx`, `.xlsx`, `.pptx` or PDF.
- A password-protected file returns `400 invalidRequest` with `file: this file is password-protected. Remove the password, then send it again.`
- A call with neither `file` nor `uploadRef` returns `400 invalidRequest` with `Send file, or uploadRef from POST /v1/parse/upload-url.`
- A file with no readable text comes back as a `notFound` error, and costs nothing.
- Pages of a PDF with no text layer are read from their picture, up to 20 pages and only with an API key. The OCR rate below applies to those pages.

## Price

Estimate the charge from how much text we can read from the text layer and how many pages need OCR.

$0.50 per 1,000 pages or files whose text comes from a text layer, and $2.50 per 1,000 pages or pictures read from their picture, up to `maxPages`. `summary` and `json` with a schema or a prompt add $3 per 1,000 files each when they return something. Zero data retention adds $2 per 1,000 calls. `costUsd` shows what the call cost. See [Pricing](/account/pricing).

## Choose another API

Use a different call if the document is already online or you need fields rather than the full text.

- [Scrape](/scrape/pdfs-and-documents) reads a page or a document that is online, by its address.
- [Extract](/extract/overview) pulls the fields you name from pages, each checked against the page.
- [Search](/search/overview) finds pages from a query.
- [Agent](/agent/overview) searches and reads for you until your fields are filled.
