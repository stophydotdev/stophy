Each entry is named for its Monday.

<Update label="Week of November 16, 2026" description="Smaller answers, lower prices and new parsers">

- **Breaking: smaller answers.** Scrape, search, map and parse answers and job starts no longer carry `costUsd`, `creditsUsed` or `requestId` at the top, and search has no `id`. The cost is the `x-cost-usd` header and the request id is `X-Request-ID`. See [Errors](/api-reference/errors).
- **Breaking: result metadata and the agent cap.** Crawl, batch and search results no longer carry `scrapeId`. An agent run cut short by `maxCredits` ends `failed` with `credit_limit_reached`. See [Agent runs](/agent/runs).
- **Lower prices from November 18** for page reads, map, extract and search. See [Pricing](/account/pricing).
- **Nine new parsers** for Bluesky, link-in-bio pages, X communities, TikTok trending and live, Twitch and Facebook groups. See [Pre-built parsers](/scrape/prebuilt-parsers).
- **Webhooks carry `costUsd` and `eventId`.** See [Webhooks](/webhooks).
- **The MCP server has a tool for each product.** The generic `stophy_call` tools are gone. See [Install MCP](/install-mcp#what-your-agent-sees).
- **Removed:** GitHub search, now [developer search](/search/developer), and the `google-scholar` parser, now [papers search](/search/papers).

</Update>

<Update label="Week of November 9, 2026" description="Dollar billing, browser sessions and new limits">

- **Billing is in dollars.** A top-up adds what you paid. See [Pricing](/account/pricing).
- **Browser sessions** take network policies, extensions, recordings, uploads and downloads. See [Browser sessions](/browser/overview).
- **Rate limits are per endpoint** and `GET /v1/limits` shows yours. See [Rate limits](/production/rate-limits).
- **A stored copy costs the same as a live read**, and one older than `maxAge` is never returned. See [Freshness and caching](/scrape/freshness-and-caching).
- **Removed:** company, people and government search, and the `qdr:h` time window.

</Update>

<Update label="Week of November 2, 2026" description="API v1">

- **API v1.** On November 5, Stophy became scrape, search, map, crawl, batch and extract, with parse, agent, monitors and browsers beside them. See the [Introduction](/introduction).
- **Parsers replace the per-site endpoints.** Paths such as `/v1/google/search` answer `404`. Scrape the page with a parser instead. See [Pre-built parsers](/scrape/prebuilt-parsers).
- **No key needed to try it.** Search, scrape, map and parse work without one, within the [free limits](/production/rate-limits).
- **An agent can sign itself up.** See [API keys](/account/api-keys).

</Update>

<Update label="October 2026" description="Launch">

Stophy launched on October 5, 2026 with one endpoint per site, such as `google.search`. API v1 replaced it on November 5, and each site lives on as a [parser](/scrape/prebuilt-parsers).

</Update>
