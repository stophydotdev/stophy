Add live web search to an app that uses the OpenAI Responses API. When the model asks to search, your app calls Stophy and sends the results back.

## The search tool

Start with a function that accepts the model's query. Run `npm install stophy`, then put the function in `stophy.ts`. It asks for up to 5 web results and returns them as JSON. A failed search throws a `StophyError`.

```ts stophy.ts
import { Stophy } from "stophy";

const stophy = new Stophy();

export async function stophySearch(query: string): Promise<string> {
  const { data } = await stophy.search({ query, limit: 5 });
  return JSON.stringify(data?.web);
}
```

## Give it to an OpenAI model

Register the tool with the Responses API so the model can request a search. Run `npm install openai`. Set `OPENAI_API_KEY` in your environment, and `STOPHY_API_KEY` to go past the free limits.

For each `function_call`, read `query` and run the search. Send the JSON back as `function_call_output` with the matching `call_id`. Use `previous_response_id` to continue the same response. When the model sends no more calls, read `output_text`.

```ts
import OpenAI from "openai";
import { stophySearch } from "./stophy";

const openai = new OpenAI();

const tools: OpenAI.Responses.Tool[] = [
  {
    type: "function",
    name: "web_search",
    description: "Search the web. Returns the top results as JSON.",
    parameters: {
      type: "object",
      properties: { query: { type: "string", description: "What to search for" } },
      required: ["query"],
      additionalProperties: false,
    },
    strict: true,
  },
];

let response = await openai.responses.create({
  model: "gpt-6.1-terra",
  input: "What changed in the latest Bun release?",
  tools,
});

while (true) {
  const calls = response.output.filter((item) => item.type === "function_call");
  if (calls.length === 0) break;
  const outputs: OpenAI.Responses.ResponseInputItem[] = [];
  for (const call of calls) {
    const { query } = JSON.parse(call.arguments) as { query: string };
    outputs.push({ type: "function_call_output", call_id: call.call_id, output: await stophySearch(query) });
  }
  response = await openai.responses.create({
    model: "gpt-6.1-terra",
    previous_response_id: response.id,
    input: outputs,
    tools,
  });
}

console.log(response.output_text);
```
