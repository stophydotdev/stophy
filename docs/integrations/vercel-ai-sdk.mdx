Give your AI SDK model a live search tool. The model supplies the query and the tool calls Stophy.

## The search tool

Put the search in a function you can call from `execute`. Run `npm install stophy`, then save the function in `stophy.ts`. It asks for up to 5 web results and returns them as JSON. A failed search throws a `StophyError`.

```ts stophy.ts
import { Stophy } from "stophy";

const stophy = new Stophy();

export async function stophySearch(query: string): Promise<string> {
  const { data } = await stophy.search({ query, limit: 5 });
  return JSON.stringify(data?.web);
}
```

## Give it to the AI SDK

Pass the tool to `generateText` to let the model decide whether to search. Run `npm install ai @ai-sdk/openai zod`. Set `OPENAI_API_KEY` in your environment, and `STOPHY_API_KEY` to go past the free limits.

Use `inputSchema` to ask the model for a `query` string, then call the search function from `execute`. `stopWhen` caps the tool and answer loop at five steps. To use another AI SDK provider, replace `openai(...)` with its model and set that provider's API key.

```ts
import { openai } from "@ai-sdk/openai";
import { generateText, isStepCount, tool } from "ai";
import { z } from "zod";
import { stophySearch } from "./stophy";

const { text } = await generateText({
  model: openai("gpt-6.1-terra"),
  prompt: "What changed in the latest Bun release?",
  tools: {
    webSearch: tool({
      description: "Search the web. Returns the top results as JSON.",
      inputSchema: z.object({ query: z.string().describe("What to search for") }),
      execute: async ({ query }) => stophySearch(query),
    }),
  },
  stopWhen: isStepCount(5),
});

console.log(text);
```
