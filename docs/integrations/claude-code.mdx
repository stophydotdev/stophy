Connect [Claude Code](https://code.claude.com) to Stophy to search or read pages from a conversation. Start with the free endpoints and no key.

```bash
claude mcp add --transport http stophy https://api.stophy.dev/mcp
```

Run `claude mcp get stophy` to check it.

## Sign in with your browser

Choose browser sign-in to use every tool without storing an API key. Use `https://mcp.stophy.dev/mcp` in place of the URL in the install command.

Type `/mcp` in Claude Code, choose `stophy`, and pick **Authenticate**. After you sign in, every tool works.

## Use an API key

Use a key if you do not want to sign in from Claude Code. Set `STOPHY_API_KEY`, then add `--header "Authorization: Bearer $STOPHY_API_KEY"` to the original install command. [Get an API key](https://stophy.dev/signup). Your shell fills it in, and Claude Code saves it on your machine. Add `--scope user` to use Stophy in every project.

## Try it

To check the connection, ask Claude Code to find the top Reddit posts about Bun this week with Stophy and summarize them.

If you see two `stophy` servers, run `claude mcp remove stophy` and add the one you want.
