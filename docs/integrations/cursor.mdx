Connect [Cursor](https://cursor.com) to Stophy to use live web data in its agent. Put this in `~/.cursor/mcp.json` to start without a key.

```json
{
  "mcpServers": {
    "stophy": {
      "url": "https://api.stophy.dev/mcp"
    }
  }
}
```

Restart Cursor, and its agent can call the free endpoints.

## Sign in with your browser

Use browser sign-in to get every tool without saving a key. Change `url` to `https://mcp.stophy.dev/mcp`. Cursor opens your browser to sign in.

## Use an API key

[Get an API key](https://stophy.dev/signup) and set it as `STOPHY_API_KEY`. Cursor reads the variable into the header, so the key stays out of the file.

Keep the original `url` and add `"Authorization": "Bearer ${env:STOPHY_API_KEY}"` inside a `headers` object under `stophy`.

## Try it

To check the connection, open **Customize** in Cursor and make sure `stophy` is on. Ask the agent to find coffee shops near Austin, TX with their ratings using Stophy.
