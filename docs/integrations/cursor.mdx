Add Stophy to [Cursor](https://cursor.com). Put this in `~/.cursor/mcp.json`.

```json
{
  "mcpServers": {
    "stophy": {
      "url": "https://api.stophy.dev/mcp"
    }
  }
}
```

Restart Cursor, and its agent can call the free endpoints.

## Sign in with your browser

Use this URL instead. Cursor opens your browser to sign in, and then every endpoint works.

```json
{
  "mcpServers": {
    "stophy": {
      "url": "https://mcp.stophy.dev/mcp"
    }
  }
}
```

## Use an API key

[Get an API key](https://stophy.dev/signup) and set it as `STOPHY_API_KEY`. Cursor reads the variable into the header, so the key stays out of the file.

```json
{
  "mcpServers": {
    "stophy": {
      "url": "https://api.stophy.dev/mcp",
      "headers": {
        "Authorization": "Bearer ${env:STOPHY_API_KEY}"
      }
    }
  }
}
```

## Try it

Open **Customize** in Cursor and check that `stophy` is on. Then ask the agent this.

```text
Use Stophy to find coffee shops near Austin, TX with their ratings.
```
