Add live web search to an app that uses the Anthropic SDK. When Claude asks to search, your app calls Stophy and passes the results back to Claude.

## The search tool

Start with a function that takes only a query. Install `stophy` with `npm install stophy`, then put the function in `stophy.ts`. It asks for up to 5 web results and returns them as JSON. A failed search throws a `StophyError`.

```ts stophy.ts
import { Stophy } from "stophy";

const stophy = new Stophy();

export async function stophySearch(query: string): Promise<string> {
  const { data } = await stophy.search({ query, limit: 5 });
  return JSON.stringify(data?.web);
}
```

## Give it to Claude

Use the tool runner if you want the SDK to make the tool calls for you. Run `npm install @anthropic-ai/sdk zod`. Set `ANTHROPIC_API_KEY` in your environment, and `STOPHY_API_KEY` to go past the free limits.

Define `web_search` with `betaZodTool`. Its schema tells Claude to supply a string named `query`. The tool runner passes that string to your function and returns the final message. Read its text blocks for the answer.

```ts
import Anthropic from "@anthropic-ai/sdk";
import { betaZodTool } from "@anthropic-ai/sdk/helpers/beta/zod";
import { z } from "zod";
import { stophySearch } from "./stophy";

const client = new Anthropic();

const webSearch = betaZodTool({
  name: "web_search",
  description: "Search the web. Returns the top results as JSON.",
  inputSchema: z.object({ query: z.string().describe("What to search for") }),
  run: async ({ query }) => stophySearch(query),
});

const message = await client.beta.messages.toolRunner({
  model: "claude-sonnet-5-5",
  max_tokens: 16000,
  tools: [webSearch],
  messages: [{ role: "user", content: "What changed in the latest Bun release?" }],
});

for (const block of message.content) {
  if (block.type === "text") console.log(block.text);
}
```
