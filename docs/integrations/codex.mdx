Connect [Codex](https://developers.openai.com/codex) to Stophy so it can search and read pages for you. This command gives it the free endpoints without an API key.

```bash
codex mcp add stophy --url https://api.stophy.dev/mcp
```

Run `codex mcp list` to check it.

## Sign in with your browser

To use every tool without an API key, replace the URL in the install command with `https://mcp.stophy.dev/mcp`. Then run `codex mcp login stophy` and sign in.

## Use an API key

Use an API key if you do not want browser sign-in. Set `STOPHY_API_KEY`, then add `--bearer-token-env-var STOPHY_API_KEY` to the original install command. [Get an API key](https://stophy.dev/signup). Codex reads the variable each time it starts, so the key itself is never saved to `~/.codex/config.toml`.

## Try it

To check the connection, ask Codex to get the transcript of `https://www.youtube.com/watch?v=dQw4w9WgXcQ` with Stophy and summarize it.
